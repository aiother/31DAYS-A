# 《末日前31天》V0.1 策划案：T3 可能性 / 基础属性 / 成长 / 死亡

版本：V0.1｜状态：主体规则与数值已冻结，未决边界见第12节｜整理日期：2026-10-07｜现行版更新：2026-10-24

本文是现行规格：正文只写当前有效的资源、属性、成长与死亡规则，历次修订已并入对应章节，来源见第14节变更记录。本文是资源、伤害与成本数值的权威位置；战斗细则见T2，日期与计时规则见T4，Room与Node配置见T5.3、T5.4。实施说明（`game/docs`）记录参数与验证方法，不改变本文规则。

## 1. 系统目标与资源循环

可能性是人与世界产生连接后获得的未来可能。战斗是基础获取方式，帮助NPC提供额外资源与永久成长。可能性同时用于滑步与生命恢复，让玩家在机动与生存之间做选择。

资源闭环：战斗/帮助NPC → 获得可能性 → 闪避/恢复消耗 → 继续探索与战斗。

成长闭环：完成7事件 → 获得7的注视 → 有效帮助不同NPC → 提高可能性上限 → 增强持续探索能力。

死亡闭环：HP归零 → 倒地与死亡反馈 → 死亡菜单 → 检查点复活 → 资源损失与敌人重置 → 重新挑战。

本节冻结设计与初始平衡基准，不表示游戏实现或运行测试已完成。T0范围、T1操作和T2战斗规则继续有效。

## 2. 基础属性与透支额度

| 设计项 | 冻结值/规则 |
| --- | --- |
| 玩家基础生命上限 | 5 |
| 开场生命值 | 3，高空坠落后的低生命状态 |
| 生命最低值 | 0，HP归零进入死亡流程 |
| 玩家基础可能性上限 | 10；成长后最高15 |
| 开场可能性 | 3 |
| 可能性最低值 | 改称“可能性透支额度”；余额下界为-9 |

正常可能性区间为0至当前上限，初始为0～10；负数表示提前消耗尚未发生的未来，允许的透支区间为-9～0。成长提高正常储存上限，不改变已冻结的-9透支下界。死亡后负数清零，不执行负数乘50%的保留计算。

V0.1的永久成长有三类：可能性上限（第8节）；近战攻击范围（击败渴望俯视+20%，四颗珍珠各+5%，加算后最高为基础的140%，规则与保存方式见T2第2节）；闪避速度（击败寄生同伴者后提高，见第4节）。永久成长不增加生命上限，10的生命上限成长不正式开放。不新增独立体力系统。

画面表现（UI-002）：HUD中生命只显示现有数量；可能性为环形格，从顶部顺时针填充，成长上限是外圈附加段，透支从顶部逆时针反向变暗红。尝试恢复或闪避而可能性不足时，环发红闪烁（A-018）；可能性低于0时，HUD之下的游戏画面蒙上失真滤镜（波动、色散、去色、暗角），透支越多越强，回到0及以上后消退，HUD本身不失真。最后1点生命时画面边缘朱红脉动。表现只改变显示方式，不改变消耗、透支下限或其他规则；实现见[正式HUD实施说明](../game/docs/formal_hud_implementation.md)。

## 3. 可能性获取与上限

| 设计项 | 获得值/规则 |
| --- | --- |
| 击杀无色实体 | +2 |
| 击杀单色实体 | +7 |
| 击杀天人战士 | +11 |
| 帮助NPC | 一次有效帮助获得+4可能性，每位NPC只发一次；永久上限成长另按第8节结算 |
| 7剧情奖励 | 7剧情（TY_10001_1_N002）结束后补满可能性；之后返回7完成注视结算时上限10→12，余额不额外补满。不另发固定+10，两种奖励不叠加 |
| 超出上限 | 超过当前可能性上限的部分浪费，不转化为货币或其他资源 |

击杀奖励直接进入玩家资源并播放获得特效，沿用T1/T2。不新增随机战利品玩法，指定固定掉落仍按T2处理。

获得可能性时按当前余额增加，并受当前上限约束；负余额可由获取资源逐步偿还。正常击杀与救助收益不会扩大-9透支额度。敌人重置后再次击杀仍获得可能性，允许反复往返不同场景补充战斗资源；单个死亡实例只结算一次，此规则不开放NPC一次性事件重复领奖。

## 4. 可能性消耗与连闪

| 设计项 | 冻结值/规则 |
| --- | --- |
| 恢复生命 | 一次完整恢复消耗3可能性 |
| 恢复量 | 一次完整恢复2生命 |
| 闪避基础消耗 | 第一次连续滑步消耗1可能性 |
| 连续闪避递增 | 每次递增1；第一、第二、第三次分别消耗1、2、3可能性 |
| 连闪重置 | 1.3秒没有闪避后，恢复为第一次消耗 |
| 可能性不足 | 仍可进入资源不足的闪避状态：前摇较大、无敌帧减少 |
| 恢复不足 | 可能性不足一次完整恢复成本时，不能启动恢复 |

连续滑步最多3次，三次合计消耗6可能性。1.3秒从上一次实际滑步发动起计算，无效按键不重置计时。支持地面/空中左右闪避，共用连闪成本、计数、重置与透支规则；能穿越体型较小敌人，不作为任何必经地形的通行条件。空中闪避不重置跳跃、不悬空，其余生命/恢复/收益规则不变。

恢复不使用透支：当前可能性小于3时禁止启动。滑步可在低资源时以较大前摇和较少无敌帧维持操作能力；不能据此把余额扣到-9以下：扣费会低于-9时拒绝本次滑步（不扣费、不发动），到达-9后不能继续滑步。余额小于当次完整成本即视为资源不足。

闪避速度成长：击败寄生同伴者后自动永久获得地面/空中闪避速度720→900；持续时间、无敌、消耗、最多三连、1.3秒重置、透支下界和重力不变。与胜利同次保存；旧存档已有击败记录时自动补发一次；保存失败不启用并可E / RB重试。死亡保留、存档槽隔离、新游戏重置。不增加生命、伤害或可能性上限。详见[闪避成长实施说明](../game/docs/dodge_growth_implementation.md)。

## 5. 恢复系统

| 设计项 | 冻结规则 |
| --- | --- |
| 恢复判定 | 按下恢复键立刻进入状态，并在开始时扣除3可能性；持续长按2.8秒 |
| 被打断消耗 | 被攻击打断时，本次已扣除的3可能性全部损失，不恢复生命；不再重复扣除 |
| 满血限制 | 满血禁用恢复动作 |
| 恢复上限 | 不允许超过最大生命值，完成时最多恢复至5生命 |

恢复期间不能移动，战斗中允许使用；必须寻找明显安全窗口。2.8秒完成后一次性恢复2生命，不在过程中分段回血。当前生命为4时完成恢复只到5，溢出的恢复量不增加生命上限。

闪避可取消恢复动作，沿用T2。主动滑步取消、提前松键均不退还已扣3可能性，未完成则不回血，与受击打断一致。

### 5.1 应急药包

应急药包是一种固定消耗品，不属于永久成长：每次消耗1个恢复2生命，按生命上限5截断；满血时不消耗；不扣可能性、不提供无敌。携带上限3、初始0，死亡保留。四处固定来源各1个（位置见T5.3），每个存档槽各拾取一次；旧存档不补发。拾取与使用的保存失败时整体回滚。使用按键与可用时机见T1第5节。长按恢复的规则不因药包改变。详见[药包实施说明](../game/docs/medkit_implementation.md)。

## 6. 玩家受伤

| 设计项 | 冻结值/规则 |
| --- | --- |
| 基础伤害档位 | 采用轻、中、重攻击档位 |
| 轻攻击伤害 | 1点，占基础最大生命的20% |
| 中等攻击伤害 | 2点，占基础最大生命的40% |
| 重攻击伤害 | 3点，占基础最大生命的60% |
| 环境伤害 | 1-2点，陷阱与高空坠落等沿用受击体系 |

普通受击轻硬直、轻微击退，硬直期间短暂无敌。重攻击危险度较高，需要可读的前摇与可应对窗口；具体哪些攻击可打断仍遵守T2第3节“符合条件”规则，不由数值章节改成所有重攻击均可打断。

## 7. 玩家输出与敌人生命

| 设计项 | 冻结值 |
| --- | --- |
| 基础伤害单位 | 普通攻击第一段5点 |
| 第二段倍率 | 第二段仍为5点，相对第一段为1倍；击退更强、后摇更长 |
| 上攻击伤害 | 5点，保留较高击退 |
| 下落攻击伤害 | 5点，命中后向上弹起，弹起高度为长按跳跃最大高度的50%（见T2第2节） |
| 投掷物反弹伤害 | 5点，符合条件的非子弹投掷物可反弹 |
| 无色实体生命定位 | 13点，理论需要3次普通攻击 |
| 单色实体生命定位 | 21点，理论需要5次普通攻击 |
| 天人战士生命定位 | 31点，理论需要7次普通攻击 |

无色实体13生命是第1日基准：普通探索与营帐围攻的无色单位在第2/3日新生成时为15/17生命，伤害1与重复击杀+2不变；随日期的移速与攻击间歇见T2第8.1节。

理论击杀次数为生命值除以5后向上取整，前提是每次攻击命中并结算完整伤害，不计格挡、闪避或特殊减伤。每次攻击动作对同一目标只结算一次伤害，可同时命中多个目标，沿用T2。

三类敌人分别教授操作、判断、博弈；数值不替代AI与攻击模式差异。不新增正式削韧数值系统。V0.1另有渴望俯视与寄生同伴者两场Boss战（见T0），其数值不在本节。

## 8. 成长系统

| 设计项 | 冻结值/规则 |
| --- | --- |
| V0.1成长核心 | 永久提高可能性上限 |
| 7首次奖励 | 完成首次救助任务、获得7的注视后，上限+2，10→12 |
| 后续成长条件 | 每一次有效帮助不同NPC，触发一次后续成长 |
| 单次成长量 | 每次上限+1 |
| V0.1成长次数上限 | 首次+2之后，再允许3次+1；包含首次奖励共4次上限成长，最终上限15 |
| 重复救助 | 同一NPC不能反复触发成长计数 |

V0.1可能性上限最高15：10 → 12 → 13 → 14 → 15，不采用上限16或17。

帮助奖励+4可能性与永久上限成长属于不同奖励；达到成长上限后不再提高上限。V0.1可帮助的NPC共四位：麦秆镇幸存者、沟壑第二间（HD_20001_2）幸存者、沟壑第三间（HD_20001_3）幸存者、战场外围（NSZC_10001_1）门内NPC。每位各发一次+4、各计一次成长，成长按NPC来源分别记录与校验；同一NPC不能用两种帮助方式各领一次，重复互动不再发资源或成长。

结算规则：

- 麦秆镇救助完成后返回7完成注视结算，上限10→12，余额不额外补满。
- 已有7的注视时，其他三位每完成一次有效帮助上限+1：先提升上限，再把+4资源按新上限截断，不额外补满。任一位沟壑幸存者可使12→13，两位沟壑幸存者完成为14，再加外围NPC为15。
- 尚未获得注视时，有效帮助先保存记录、发放+4，上限的+1延迟到首次获得注视时统一结算，不让每次救助重新发首次奖励。
- +4在余额为零或负数时同样发放，溢出部分截断。
- 救助与注视分别与各自奖励同次保存，保存失败整体回滚并可重试；死亡与读档保留，存档槽隔离，新游戏重置。

## 9. 7的注视与任务选择

| 设计项 | 冻结规则 |
| --- | --- |
| 生效时间 | 完成7剧情后立即永久生效 |
| 有效行为 | 恢复NPC生命；在NPC面前击杀当前场景全部敌方单位 |
| 失败任务 | 玩家选择不帮助并离开，任务永久失败 |
| 失败后补救 | 不能返回补救 |

离开前增加明确提示与确认，说明这是会失去救助机会的选择。聊天示例“前方的人们已经没有多少时间了”用于说明提示意图，具体台词和UI见T7（当前为临时台词）。

救助行为通过NPC与事件记录判定，死亡不会回滚已完成事件或重复发放成长。两种帮助行为对同一NPC不能各刷一次成长。

各NPC的帮助方式：

- 麦秆镇幸存者、沟壑第二间幸存者：按E / RB完成临时对话即免费救助。
- 沟壑第三间幸存者：在其面前清空敌人即自动视为有效帮助；清敌前可确认永久放弃并撤回。
- 战场外围门内NPC：先通过外围上层可选支路的尖刺窄道开门，再按E / RB免费救助，一次+4可能性、不回血。

放弃与豁免：见到NPC后未救助而主动离开时，须明确确认，确认后永久失败；死亡与读档不视为主动放弃。外围的开门、救助、确认放弃均保存成功才生效，失败时奖励整体回滚并可重试。

外围尖刺挑战：NSZC_10001_1既有上层可选支路为80像素宽尖刺窄道，顶板防跳越，需一次强化闪避无伤穿过，入口建议至少有1可能性。失败扣1生命并返回支路入口（沿用全局受击保护与死亡），保留本次闪避消耗及连闪计时，可重试；通过后永久关闭尖刺。下层主路普通走跳通行。不新增Room或检查点，沿用HD_20003_1_N003。T5尚无此NPC的正式Node编号，工程中使用事件 `gate:NSZC_10001_1:spikes_cleared` 与 `rescue:NSZC_10001_1:seen/completed/failed`，不补造策划编号。

随日期过期：麦秆镇与沟壑第二、三间的救助在进入第3日时过期；外围救助在第3日剩余时间归零时过期。已完成的救助与已获得的成长永久保留；过期的救助不发+4、不提高上限。这一期限适用于新游戏，以及旧存档中尚未见过的NPC；旧存档首次迁移时，已见过、尚未救助且未主动放弃的NPC永久保留一次救助机会，不因升级立即失救。日期推进本身见T4。

实施说明：[麦秆镇](../game/docs/town_rescue_implementation.md)、[沟壑第二间](../game/docs/ravine_rescue_implementation.md)、[沟壑第三间](../game/docs/ravine_depth_implementation.md)、[外围](../game/docs/outskirts_implementation.md)、[日期影响](../game/docs/world_day_rules_implementation.md)。

## 10. 死亡系统与复活保护

| 设计项 | 冻结值/规则 |
| --- | --- |
| 死亡判定 | HP归零后禁止移动、攻击、恢复等操作；仍可打开菜单；播放倒地与死亡动画 |
| 倒地时间 | 1秒；死亡动画结束后显示死亡菜单 |
| 复活生命 | 检查点复活后恢复满生命，即5 |
| 复活可能性 | 非负余额保留死亡时当前可能性的50%；负数清零为0 |
| 可能性损失比例 | 非负余额损失50%；不对永久上限扣减 |
| 敌人状态 | 非Boss敌人重置；Boss未击败时死亡重置该场Boss战，击败后永久保留击败记录 |
| NPC/剧情状态 | 已完成NPC事件不回滚 |
| 检查点状态 | 保存地图进度、剧情、成长与已获得物品 |
| 复活无敌 | 3秒，沿用T1冻结值 |
| 无敌解除 | 主动攻击不提前解除复活无敌 |

流程：HP归零 → 1秒倒地 → 死亡动画 → 死亡菜单 → 选择返回检查点 → 满生命复活 → 按规则保留可能性 → 敌人重置 → 3秒无敌 → 重新挑战。

“死亡菜单”与V0.1胜利后的通关结束菜单区分。死亡菜单包括从检查点继续、返回标题、设置、退出游戏（A-014）；倒地1秒不等于死亡动画与菜单等待总时长。

非负可能性的50%保留向下取整，例如3→1、5→2；负数清零。资源不按检查点历史余额全量恢复；地图、剧情、成长与物品的持久保存避免死亡后重复刷奖励。正常退出后重进保留资源，不执行死亡扣减，也不发放复活无敌（沿用T7）。

计时与死亡：死亡动画与死亡菜单期间停表。第3日最终战尚未正式开战就耗尽当日时间时，显示独立的探索超时反馈，明确确认后保存并返回当前检查点、恢复本日30分钟；保留当前生命、可能性和永久进度，不补满、不执行死亡扣减，普通敌人重置。最终战已开始时继续原有的最终战预算（15分钟与第3日剩余取较小值）及既定重试规则，不赠送30分钟；死亡与读档不回补该预算。完整计时规则见T4，最终战见T2第11节与T5.4。

## 11. 资源防卡死

| 设计项 | 冻结规则 |
| --- | --- |
| 零可能性状态 | 攻击、移动、资源不足状态下的闪避、救助NPC仍可用；移动与攻击不能被资源锁死 |
| 无法恢复状态 | 低生命且无法恢复时，通过救助NPC或击杀敌人重新获得可能性 |
| 最低生存保障 | -9透支额度提供缓冲，死亡时负数重置为0；强制战斗低资源情形提供残存可能性实体 |

保底表现命名为“残存可能性实体”：无伤害的空中无色实体，供玩家击杀恢复可能性。不将此机制扩大为随处刷新或无限刷资源的系统。

| 设计项 | 规则 |
| --- | --- |
| 适用战斗 | 只在强制战斗中出现：营帐围攻、渴望俯视与寄生同伴者两场Boss战、中心战场救场与最终战；不含堑壕 |
| 触发条件 | 当前可能性余额低于当前可能性上限的50%（含负数） |
| 生成节奏 | 满足触发条件时，每10-15秒生成1-2个 |
| 存活上限 | 场上同时最多3只 |
| 击杀奖励 | 与普通无色实体相同，+2可能性 |

以上规则由用户于2026-10-19裁决（待决事项总表A-002）。

## 12. 实现前需明确的边界

以下事项尚未形成唯一结论，保留为实现细则；不从示例推定新冻结值：

- 保底实体：生成位置、每次生成1个还是2个的选择方式，以及余额回到阈值以上时已在场实体如何处理，由灰盒确定；仍需避免形成无限刷资源或仍然无法恢复的状态。
- 资源不足的闪避：前摇与无敌帧的具体时长只作Resource灰盒调校，未冻结。
- 随日期的内容变化：敌人构成随日期变化与日期地形变体方向已定（待决事项总表A-004、A-005），具体内容待设计稿，不在本文冻结。

这些细则必须在对应功能实现验收前明确并验证，不将存在未决边界等同于已经证明无软锁。

## 13. 设计验收与验证重点

- 资源闭环：战斗获取的可能性支持滑步与恢复，消耗后仍有重新获取资源的途径。
- 成长闭环：帮助NPC → 7的注视 → 可能性上限成长成立；10→12→13→14→15，不重复计数。
- 死亡闭环：死亡 → 50%非负资源损失或负数清零 → 检查点满生命复活 → 敌人重置 → 再次挑战；剧情、成长、物品不回滚。
- 无软锁：低生命、零或负可能性下，核心操作和必要通行可用；强制战斗保底实际可击杀并提供恢复路径。

灰盒验收应覆盖满血与不足资源禁用恢复、2.8秒一次性回血、开始扣费及攻击打断、1/2/3连闪成本与重置、透支下界、收益溢出、奇数与负数死亡结算、NPC重复事件、永久失败确认、复活攻击不解除无敌及保底实体行为。

当前文档验证只检查策划内容、数值关系和规则一致性；游戏运行验收须在实现后完成。
