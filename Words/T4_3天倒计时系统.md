## 1. 时间系统目标

时间不是单纯的UI数字，而是玩家压力、世界变化与剧情推进的共同变量。V0.1只验证3天框架，保留未来扩展到31天阶段系统的结构，不制作完整31天内容。

时间存在意义：暗室侵蚀随时间增强，敌人更加危险、环境更加恶劣，可帮助NPC减少，敌人数量与构成变化，剧情机会随之改变。

已接受修订将“玩家受到伤害提高”调整为暗室侵蚀导致敌人更危险。主要反馈来自敌人攻击欲望、攻击方式和世界变化，不以同一攻击暗中加伤作为核心时间规则。攻击频率、范围、追击距离等是评审提出的表现方向，具体参数未冻结；不据此自行修改T3伤害数值。

## 2. 时间核心与暂停

| 设计项 | 冻结规则 |
| --- | --- |
| 玩家是否知道剩余时间 | UI显示当前时间，地图背景随时间变化；每经过一天出现当前天数提示。剩余时间的具体HUD格式由T7细化 |
| 时间单位 | 游戏内时间+事件推进，不按玩家离线现实时间直接推进 |
| 一天长度 | V0.1一天为半小时；原表另记完整版一天约1小时，作为未来扩展基准，不用于当前版 |
| 时间推进方式 | 基础时间自动流逝，同时关键事件强制推进日期 |
| 时间暂停 | 剧情进行时暂停时间，打开菜单时暂停时间；普通战斗没有暂停时间的特殊规则，沿用基础流逝 |
| 时间显示方式 | 数字+环境变化；具体界面样式不在本阶段展开 |

原表“剧情进行时暂停事件”按已确认评审中的“剧情暂停”整理为时间暂停。10救场的时间暂停沿用T2，剧情暂停与随后启动临界倒计时的先后边界见第9节。

三天并非固定一张地图对应一天：Day1覆盖坠落、荒地生存和田野认识7；Day2探索并寻找10线索；Day3进入逆时战场最终高潮。区域与日期的关系由关键事件及自然流逝共同决定。

## 3. V0.1三天结构

### 3.1 Day 1：生存

- Day 1主题：生存。坠落 → 荒地 → 认识7 → 学习可能性，玩家主要目标是活下来。
- 时间结束条件：结束与7的相遇剧情，并离开7所处区域，推进到第二天；不能将仅开始对话当作已完成推进条件。
- 世界变化：开始出现单色实体，无色实体移动速度与生命提高。T3的13生命是初始基准；具体时间阶段修正未给出数值，不能直接写死新生命值。

### 3.2 Day 2：探索

- 第二天玩家体验目标：探索并找到关于10的线索。
- 时间结束条件：原表为“击败掌握线索的BOSS”，评审延续该触发描述。它与T0/T2现有不新增Boss范围存在冲突，按第9节处理，不能直接替换成未经确认的新事件。
- 世界变化：地图开始出现少量天人战士，单色实体增多，无色实体减少。

### 3.3 Day 3：反抗与末日临界阶段

- 第三天玩家体验目标：前往逆时战场，完成10剧情并取得首次大战胜利。
- 时间结束条件：触发10剧情时启动15分钟倒计时。已接受修订将其解释为“暗室侵蚀进入临界状态”，而非普通第三天自然结束。
- 世界变化：地图出现更多空缺与陷阱，敌人增加突进攻击，攻击欲望更强。

临界流程：进入逆时战场 → 触发10剧情 → 进入末日临界阶段 → 在15分钟战斗窗口内推进最终战 → 按战斗结果与时间状态进入阶段结算。

取得最后一批敌军清除后的大战胜利，仍按T0/T2进入胜利剧情与V0.1结束。倒计时归零本身不等于已清除敌军，不自动授予战斗胜利。

## 4. 时间压力与资源刷新

| 设计项 | 冻结规则 |
| --- | --- |
| 是否强制失败 | 不直接Game Over。最终战倒计时耗尽时显示“未来已失”界面，提供重试与返回标题，重试恢复本次开战预算与所需第3日窗口（原预算为0时只能换槽或新游戏）；第3日正式开战前时间耗尽为探索超时，显示独立的探索超时反馈，确认后回检查点并恢复本日30分钟。超时界面由用户于2026-10-19裁决（待决事项总表 A-011） |
| 玩家拖延 | 【2026-10-15用户修订】允许玩家反复往返场景击杀重置敌人，以获取足够的可能性进行战斗 |
| 刷怪机制 | 【2026-10-15用户修订】普通敌人重置后仍可再次获得击杀可能性，不设一次性奖励上限；时间推进导致的危险变化仍沿用原方向：无色实体减少、单色实体增多，非战场区域出现少量天人战士 |
| 时间奖励 | 更早前往后续区域，可遇到更多可帮助NPC与较低敌人难度；未冻结额外货币或数值奖励 |

快速推进：敌人较弱、可帮助NPC较多，但可能探索不足、资源不足。慢慢探索：可获得更多资源和故事信息，但世界恶化、NPC死亡、敌人增强。

评审中的“支线更多”在本版仅指已纳入的NPC交互机会，不扩展完整支线系统。【2026-10-15用户修订】普通敌人在往返Room、死亡或正常读档后重置，再次击杀仍发放对应可能性；覆盖此前有限刷新/限制刷取方向。单个死亡实例不得重复结算。普通敌人收益与NPC一次性事件奖励分开，后者仍不能重复领取。

## 5. 世界变化

| 设计项 | 冻结方向 |
| --- | --- |
| 环境变化 | 背景随时间变化，后期崩毁、空缺与陷阱增加 |
| NPC变化 | 状态与存活机会受时间影响，可帮助NPC数量减少 |
| 敌人变化 | 攻击欲望、移动与生命、类型构成、数量和攻击方式随阶段变化 |
| 资源变化 | 可通过重置敌人补充可能性；仍受储存上限及获取所需战斗过程约束，时间系统接入后计时照常推进 |

时间至少对V0.1流程产生可见影响。变化涉及当前三张地图内的已有内容，不新增后续地图、完整装备、随机战利品或复杂经济系统。

具体阶段配置表、敌人修正值、日期切换的敌人配置、NPC时间窗口与地形变体留到关卡和制作配置；不据此重新引入重复击杀收益次数上限。改变地形后仍需满足T1必经路线不依赖消耗可能性的滑步，以及T3低资源可重新投入战斗的要求。

## 6. 剧情时间与玩家认知

- 主角心理变化：第一天轻盈试探并学习生存；第二天发现更多不幸者死亡，随敌人变强而紧张；第三天大范围地图崩毁与场景变化带来紧迫感。
- 玩家认知变化：知道当前时间与世界恶化的关系；在已无法拯救的NPC处，提示更早到来曾有救助机会，让错失机会成为可理解结果。
- NPC记忆：NPC知道时间推进，状态与对话可反映已过去的时间。

7的帮助与成长机制、永久失败确认沿用T3。时间造成的NPC失救与玩家主动放弃是不同触发，具体窗口及交互优先级需配置，不让对话或剧情暂停造成时间误扣。

## 7. 31天扩展方向（不纳入V0.1制作）

- 完整版时间结构：划分为若干阶段，基础天数依赖游戏内游玩时间，固定关键战斗与NPC交互强制推进日期；与后续存档机制衔接，不在此冻结离线计时规则。
- 扩展变化：更多强敌、解谜与收集品出现或消失、部分Boss演出变化、玩家自身debuff，以及更多规避战斗的手段。它们是完整版本方向，不能据此给V0.1新增Boss或角色debuff。
- 时间与结局：结合友人的注视与初见时间，不同友人随日期变化，过晚可能无法互动，部分友人晚期可能带来反面作用；具体结局分支未在本阶段设计。
- 时间与友人：十二位友人的事件具有时间窗口，但V0.1角色范围仍遵守T0，不制作十二位友人的完整事件。

扩展不应只是“越晚越差”：早期机会多但信息少，晚期更危险但可能获得更多真相、遗物或新的探索机会。评审的Day5/Day20/Day25仅为设计示例，不作为正式日期配置。

## 8. T4设计验收

以下是已确认的设计验收目标，游戏实现后仍须运行验证：

- 时间可感知：玩家通过HUD、环境变化、敌人变化与NPC减少感受到时间压力。
- 时间推动剧情：时间改变NPC存活、地图状态、敌人类型与剧情机会。
- 可扩展性：3天规则可自然扩展为31天阶段系统，不需要本版提前制作完整内容。

后续验证应覆盖自然流逝、关键事件推进、防止日期倒退或重复推进、剧情/菜单暂停、跨日UI、10临界倒计时、超时与击杀同时发生、敌人重置后重复收益与单次死亡不重复结算，以及时变地形的通行和低资源保障。

本文档测试验证内容覆盖与冻结修订，不代表上述游戏运行验证已经完成。

## 9. 实现前需明确的衔接边界

- 日期推进：自然半小时耗尽与关键事件强制推进的关系，超时未完成7或线索事件时如何处理，事件晚完成是否重复加天；当前阶段不会据此回退日期。
- Day2线索BOSS：原表及已接受评审均写Boss，T0/T2策划案却不新增Boss。需要明确是否替换为已有敌人/固定事件，或正式调整范围；本次不擅自新增制作项。
- 临界计时：15分钟与Day3半小时基础时钟如何并行或替代，起点位于10剧情触发还是暂停剧情结束，菜单/剧情暂停对临界时钟的精确作用。
- 超时结算：已确定不直接Game Over，但未给出未到战场、战斗未结束、玩家死亡、最终胜利等状态的V0.1映射。T0不做多结局，不能直接扩展完整分支；评审“第三日结束→战斗胜利”不作为无条件自动胜利规则。
- 刷新额度【2026-10-15已修订】：允许反复往返场景击杀重置敌人，重置后照常获得可能性，不设单个固定敌人的一次性奖励上限。日期变化时的敌人配置及残存可能性实体仍在对应系统阶段确认。
- 配置与存档：世界变化阈值、NPC窗口、修正参数、时间保存与读档恢复，由后续阶段明确；不推定退出游戏后的现实时间继续计时。

这些衔接项需要在对应功能实现验收前明确，不用未确认参数填补冻结记录。

## 2026-10-18实施修订：三日自然计时（用户已确认）

主入口接入每天30分钟自然流逝，第一日归零进入第二日、第二日归零进入第三日；物理时间推进，不计算离线时间。剧情事件取较晚日期，仅真正跨日时初始化新一天；自然日期已到达后，沟壑入口、寄生同伴者胜利、回访与重复检查点均不重复补时或倒退。菜单、剧情、普通对话、救助放弃确认、死亡动画/菜单停表；普通战斗和不锁操作的敌人首见卡片照常计时。

第三日尚未正式开战就耗尽时，显示独立探索超时反馈，明确确认后保存并返回当前检查点、恢复本日30分钟；保留当前生命、可能性和永久进度，不补满、不发死亡奖励，普通敌人重置。若最终战已经开始，继续原min(15分钟,第三日剩余)预算及既定重试规则，不赠送30分钟；死亡/读档不回补，最终胜利停表。超时/结束界面的Esc与通用继续入口不能绕过明确重试。

版本1存档增加可选day_remaining，day3_remaining和最终预算字段继续兼容。旧第一/二日档从本版采用时获得当前日30分钟，不倒推历史play_seconds；已有第三日/最终战计时原样保留。每0.5秒及跨日、检查点、资源、死亡、正常选槽/退出保存。剧情跨日事务失败回滚时钟；探索重试保存失败继续保持超时与0余量。

时间显示采用 EXP-001 方案四（用户2026-10-20第2轮试玩选定），代替 A-015 原“按键或地图界面展开”的做法，也不再比较“常驻右下角”“按键展开”两个候选：日常游玩时画面底部为一条地平线，太阳随当日进度从左向右移动，太阳上方纸签显示游戏内时刻（每日30分钟映射为06:00～24:00）；右下角小字“第N日 · 末日前N天”。换日时中上部出现“第N日 / 末日前N天”纸签；换日前3分钟右下角提示“即将进入第N+1日”与剩余分秒；第三日没有该提示。完整时间与三天进度放在暂停菜单右侧时钟（第四批暂停菜单任务实现，本修订不改菜单）。
