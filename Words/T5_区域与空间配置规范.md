# 《末日前31天》T5 区域与空间配置规范

版本：V1.0｜整理日期：2026-10-10｜阶段：区域架构已确认，具体房间与节点仍待T5.3细化

## 1. 使用范围与规则优先级

本文件整理T5填写中的整体地图、三大区域、Scene、Room与Node配置，并纳入随后确认的架构收束。它与[T5.1地图结构规范](T5.1_地图结构设计规范_V1.0.md)、[T5.2区域架构收束](T5.2_区域架构收束规范.md)共同使用。

地图层级继续采用World → Region → Scene → Room → Node。Region是生态与剧情空间，Scene组织连续视觉空间与叙事，Room承担空间分区管理，Node记录最小功能点。玩家体验连续世界，不按固定出口或固定进入状态组织普通房间。

最终确认修订优先于早期填写；早期Room与Node记录是T5.3的结构基础，不等于已完成具体配置验收。T5.3仍只设计，不进入程序和美术生产。

## 2. 地图整体规范

| 设计项 | 规范 |
| --- | --- |
| 地图类型 | 横向探索的区域连接，类银河恶魔城连续空间 |
| 区域连接方式 | 区域内多路线探索；V0.1主体验按荒地 → 田野 → 逆时战场 → V0.1结束组织，不推定所有路线必须单向 |
| 地图规模 | 每张地图预计探索约20分钟，作为初步规模目标，不改写T4时间推进规则 |
| 检查点分布 | 按玩家心理节点设置，取消原表“每个房间各一个”；按Room数量设置上限，再按预期体验配置 |
| 隐藏区域 | 存在少量隐藏路线与收集，遵守T0最低范围 |
| 返回机制 | 允许返回旧区域，具体可达性由Connection条件和Time State决定 |
| 地图叙事方式 | NPC对话、环境布置、道具描述等碎片化叙事 |

## 3. 三大区域的体验职责

### 荒地：人类文明残骸

主题为荒凉、破败、颓废与混乱，情绪为低落、寂寥。承担操作教学、战斗教学与世界展示，主要敌人为无色实体、单色实体。结构基础包括无顶深谷、瓦砾塔、瓦砾塔连结处、荒地巢都、逃兵营帐、寄生同伴者相关空间。

出生位置原表为荒地最左下角；首个敌人在起始房间相连的下一房间，初始数量1；第二房间前半段战斗、中部安全点，是待T5.3审核的初稿节奏，不直接固化最终房间摆放。

荒地区域奖励改为基础战斗能力提升，即玩家对基础操作和战斗的掌握，不增加攻击力数值。原表攻击力成长与武器强化资源没有在T3冻结，不作为本版已授权成长系统。

### 田野：末日中的虚假和平

主题为丰收、希望、末日下的夕阳，情绪为希望、光明与不切实际。承担7剧情、可能性理解和第一次善意选择；黄金湖以灰暗天空、金黄小麦与劳作者形成情绪转折，麦秆镇承载救助与交互。

田野是初步枢纽与恢复学习点；原表入口为与荒地接合处的低矮篱笆缺口。7位于指定田野房间中央，救助目标在相连房间的必经路线上。到NPC面前使用恢复、返回7对话取得可能性并帮助新的NPC，是原表任务流程意图；具体消耗与奖励结算继续遵守T3，未明确部分不追加数值。

### 逆时战场：人类最后的反抗

主题为战争、血腥与纷争，情绪为抵抗、战斗、抗争。承担10剧情、群战系统验证和V0.1高潮，结构基础为战场外围、堑壕、中心战场。

原表描述前置房间的地下突袭遭遇、连续战斗与平台陷阱、幸存者参战，以及中心战场中后段的最终胜利与结束剧情。幸存者不对玩家造成友伤。10首次救场、波次与胜负仍按T2冻结规则执行，不由地图配置新增重复救场或额外Boss。

## 4. 已确认的配置收束

- 区域奖励：荒地不增加攻击力成长；田野7的注视按T3提升可能性上限；逆时战场10的注视保留剧情奖励定位，不开启生命上限成长。
- Connection：连接记录对象、类型、状态和条件，任何层级均可有空间连接，外观不决定类型。不能用旧“出口方向”字段替代。
- Time State：作为独立状态维度影响地图；已完成事件永久保存，时间变化不能重复发奖。V0.1只实现Before Day3、Day3 Event、After Day3三个状态节点。
- Checkpoint：根据心理节点配置，自动激活，最后激活位置用于复活；不把检查点当作全部玩家状态的回档快照。
- Node Scope：Node直接属于Room，不跨级；具有唯一编号。默认不保存，由类型决定持久化。
- 死亡与时间：V0.1死亡不额外推进时间，不新增死亡次数影响侵蚀的机制；自然游玩时间仍遵守T4。

## 5. 与既有冻结范围的衔接边界

原表包含以下未收束条目。保留其记录便于后续核对，但不能将其视为已解除T0～T4限制：

- Boss：BOSS1、寄生同伴者BOSS战与“击杀荒地特定Boss开启战场入口”等原稿，与现有不新增Boss范围冲突；需在T5.3明确替代或正式调整范围，本次不新增Boss制作任务。
- 能力门：寄生同伴者Room记录了闪避门，战场外围记录闪避能力解锁。T1禁止必经地形依赖消耗可能性的滑步；需明确可选路线与能力获取时点，不能直接使核心通行依赖资源。
- 道具与成长：宝珠、珍珠、增益成长道具及强化资源名称保留为原稿，不推定数值效果、完整背包或武器成长。
- 检查点：原Room中的数量是旧稿配置，已被心理节点原则覆盖，不能照表全部放置。
- 编号与所属：原表逃兵营帐第二记录的Room编号含Scene_20003，但所属为Scene_20002；寄生同伴者Room编号含Scene_20002，但所属为Scene_20003。保留原编号，不静默改号，后续统一身份与引用。
- 节点与奖励：可救助NPC节点原写“获得7的注视效果”，需按T3先后条件与上限15解释，不让每次救助重新发首次奖励。物品入背包仅为原稿表述，不新增复杂背包系统。
- 救场演出：原表范围击杀当前波次全部敌人是演出意图，T2确认的秒杀威胁单位与首次一次事件仍有效；清除范围需在具体节点设计确认。
- 未填写与“无”：Scene用途空白、Region核心事件写“无”等按原表保留，不据此删除7/10既定剧情或伪造完整配置。

## 8. 初稿流程参考（Sheet7）
本节为早期流程填写，检查点、Boss、成长等冲突项按第4、5节处理，不覆盖最终架构规则。

### 地图整体原稿
- 地图类型：横向探索的区域连接
- 区域连接方式：多路线探索
- 地图规模：20分钟左右
- 检查点分布：每个区域的房间级单位各一个
- 隐藏区域：存在
- 返回机制：允许
- 地图叙事方式：依靠npc对话、环境布置、道具描述等碎片化

### 荒地流程原稿
- 区域定位：移动、攻击、战斗，跳跃东基础操作熟悉、很少的探索
- 视觉主题：整体色调灰暗，环境荒芜，四处都有破败的棚户与骸骨
- 玩家出生点：整个荒地地图的最左下角
- 第一目标：离开当前位置，前往下一场景
- 教学内容：移动、跳跃、攻击
- 第一敌人：与当前房间相连的下一房间
- 敌人数量：1
- 第一个战斗场：荒地的第二个房间前半段
- 第一个安全点：荒地的第二个房间中部
- 隐藏内容：有
- 离开条件：通过跳跃、战斗离开指定房间进入
- 玩家离开时认知变化：这个世界很危险，有很多无法沟通完全敌对的敌人

### 田野流程原稿
- 区域定位：第一个枢纽点，恢复技能学习点，7剧情触发点
- 视觉主题：一片汪洋般的麦田，灰暗的天空与金黄的小麦，田野中有零散劳作的人
- 入口设计：与荒地的接合点进入，表现上是一处低矮的篱笆缺口
- 7出现位置：指定田野房间的中央
- 安全区域：安全
- 幸存者位置：与7所在房间相连的下一个田野房间
- 第一次任务：来到npc正前方使用恢复技能帮助npc恢复生命
- 任务路线：进入房间后再必经之路上
- 第二次任务：返回7所在的房间重新对话获得可能性，并返回帮助新的npc
- 成长触发点：指定房间中所有待救助的npc全部恢复完成
- 探索奖励：存在
- 离开理由：从一位npc处得到了情报

### 逆时战场流程原稿
- 区域定位：打战场及周边地区，战斗、探索、剧情
- 入口方式：击杀位于荒地的特定boss开启入口
- 第一印象：坑洼的地面，陷阱、爆炸物、坍塌的建筑
- 战场结构：多个区域
- 天人战士首次出现：玩家会在进入战场大区域的前一个房间中遇到第一个天人战士，房间内的敌人全部只剩下尸体，当玩家走到房价内正中间时从地下触发天人战士的突袭，随后强制开启遭遇战
- 第一阶段目标：在进入正式的战场区域后，玩家会一次闯过连续的数个房间战斗以及平台跳跃陷阱等，在前部的数个房间中玩家需要面对较少的血量较低的天人战士，主要目的为存活/击败/推进
- 第二阶段目标：达到指定房间后会与天人战士一同出现幸存者战士，幸存者战士不会对玩家造成友伤，仅对天人战士造成伤害，而同时会出现少量单色实体
- 10登场位置：在达到中心战场，该区域最后一个房间时，玩家会遭遇一场更长更有难度的战斗，10会在这里登场
- 10登场演出：当10登场时，会优先直接处决即将对玩家造成致命伤害的敌人，随后播放一段黑屏斩击演出并范围击杀当前波次的全部敌人，同时恢复满玩家的可能性
- 第三阶段战斗：10会以压倒性的攻击力与攻击范围击杀单向的敌人，而玩家需要解决其余零散敌人并保证自己的生存
- 战斗波次：少量近战、少量远程、少量飞行+少量近战、混编出战、会召唤各类敌人的精英敌人决战
- 最终胜利地点：中心战场房间的中后段
- 结束剧情地点：中心战场房间的中后段
