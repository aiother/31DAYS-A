## 1. 体验与核心循环

操作关键词：灵活、危险、连贯。玩家优势是灵活、攻击范围与流畅滑步；主要风险是攻击后摇、受击硬直及多敌战斗。

基础循环为移动、探索、战斗、生存，反复发生在约30秒至2分钟的体验单元中。完整行为链为：探索 → 遭遇 → 战斗/互动 → 获得可能性 → 恢复/成长 → 继续探索。

战斗循环为判断敌人 → 躲避/攻击 → 受击/击杀 → 必要时恢复 → 再次进攻或前进。快速移动寻找位置，利用四方向攻击寻找窗口；击杀敌方单位补充可能性，恢复与闪避共同消耗可能性。

探索由逃生、NPC线索、剧情推进、发现收集品与角色提升驱动，收集范围遵守T0。帮助NPC获得可能性；持续帮助NPC触发7的注视，提高可能性上限。具体收益与成长条件留到T3。

失败后经短暂倒地阶段，在检查点复活并获得3秒无敌，再次挑战；不采用早期“直接在上一场景复活”的模糊位置规则。

## 2. 移动、转向与跳跃

| 设计项 | 冻结规则 |
| --- | --- |
| 基础移动 | 横向移动，支持转向、跳跃和下落；有行走/跑步区别，强调速度感 |
| 转向 | 转向存在短暂前摇；已经发动的单次攻击方向锁定，攻击间隙允许转向，下一击按新方向发动 |
| 空中控制 | 起跳后可改变朝向并输入反向移动；不会瞬间反向，原速度先衰减，再向新方向加速 |
| 跳跃高度 | 按住跳跃键越久，跳跃高度越高；上升接近顶点时变慢；具体参数待后续调校 |
| 下落 | 达到跳跃顶点后开始下落，下落速度随时间加快，并存在最大下落速度 |
| 高空坠落 | 有高空落地硬直与特殊动作；环境伤害沿用T2受击规则，具体伤害由T3确定 |
| 边缘宽容 | 给予接近平台边缘时的跳跃容错，填写的尺度为1/3角色身高；具体实现方式后续落实 |
| 墙体互动 | V0.1不做墙跳、贴墙、蹬墙 |

基础跳跃次数、速度、加速度、容错时间等未给出明确冻结值，不从表格示例推定。

## 3. 基础攻击

普通攻击通过连续单击循环；间隔过长或被其他动作打断时重置。T2将循环细化为2段，第二段击退更强、后摇更长。

| 设计项 | 冻结规则 |
| --- | --- |
| 左右攻击 | 攻击左右敌人并弹开符合条件的飞行物 |
| 向上攻击 | 按住上方向键并单击攻击键；可打空中敌人、弹开飞行物，击退较高 |
| 向下攻击 | 地面不可用，只能空中发动；【2026-10-15追加修订】命中弹起高度为长按跳跃最大高度的50%，随跳跃参数调整；按住或松开跳跃键不改变该弹起 |
| 空中攻击 | 基础攻击方式沿用地面规则；空中下落攻击不改变滞空时间，命中弹起为独立效果 |
| 攻击中移动 | 【2026-10-15追加修订】保持正常行走/跑步速度；跑步出招的前摇与后摇各翻倍，判定持续时间不变；攻击中可跳跃且不打断攻击，方向、计时、命中记录与连击记录保留 |
| 攻击中转向 | 当前单次攻击方向锁定；攻击间隙转向后，下一击使用新方向 |
| 攻击取消 | 只能由闪避取消，其他动作不能取消；地面/空中均可闪避，仍受资源条件约束；跳跃可与攻击并行 |

投掷物类型、命中次数、受击与反馈等详细规则见T2。

【2026-10-15修订】两段连击按有效攻击按键的时刻计算，间隔不超过0.5秒才能衔接第二段，超过则重新从第一段开始；输入缓冲不重新起算该间隔。跑步出招指发动时按住跑步并有水平移动输入，本次动作锁定前后摇倍率，中途松开跑步不缩短后摇。

## 4. 滑步、受击与恢复

### 4.1 滑步

【2026-10-15追加修订】V0.1支持地面/空中左右闪避，覆盖原仅地面限制。无方向输入沿当前面向；空中保留竖直速度、继续受重力与跳跃松键影响，不悬空、不重置跳跃。滑步同时用于规避攻击与调整站位，拥有短暂无敌，消耗可能性，没有独立体力系统。地面与空中共用最多连续3次、1/2/3成本、1.3秒重置及-9透支下界；其余结算沿用T3。

闪避是战斗能力，不作为V0.1任何必经地形的通行条件。资源不足时的行为由T3确定，不预设免费闪避或可透支。

### 4.2 受击

玩家普通受击有轻硬直与轻微击退；受击硬直期间短暂无敌，以避免同一窗口连续受伤。仍保留多敌协同、后续攻击与站位风险，群战进攻名额规则见T2。

致命攻击仅在逆时战场首次登场事件中可能触发10的特殊救场。事件为一次性，触发后再次死亡正常进入死亡流程；其他场景正常死亡。

### 4.3 恢复

玩家长按恢复键；按下立刻进入恢复状态，持续2.8秒，完成时一次性恢复生命。恢复期间不能移动，可被攻击打断并受到伤害；被攻击打断仍消耗可能性且不恢复生命。允许战斗中恢复，满血不可使用，需要寻找明显安全窗口。

恢复量、成本、扣除时点、闪避主动取消恢复时的资源结算、资源不足时能否启动等留到T3，不在本阶段补造。

## 5. 互动、拾取与状态

| 设计项 | 冻结规则 |
| --- | --- |
| NPC互动 | 强制剧情自动触发；普通NPC与可选对话手动互动 |
| 门 | 已开启的门不阻拦；未开启的门手动触发 |
| 机关 | 陷阱机关可手动或自动触发；功能机关需角色交互 |
| 剧情点 | 自动触发；剧情期间限制移动、攻击等操作 |
| 普通资源拾取 | 靠近自动吸收 |
| 关键/剧情物品 | 手动互动，并播放拾取动作 |
| 战斗可能性 | 击杀后直接获得，播放获得特效 |
| 战斗状态进入 | 敌人主动锁定玩家或强制战斗开始 |
| 探索状态恢复 | 敌人清除或脱离警戒；普通遭遇中敌人切换场景前持续追击，强制战斗不可逃离 |
| 使用道具 | 属于T0冻结的基础能力；T1未给出道具清单、按键或效果，不新增规则 |

普通敌人奖励与剧情固定掉落遵守T2，不实现随机战利品系统。

## 6. 死亡重来与镜头

生命归零 → 短暂倒地 → 检查点复活 → 3秒复活无敌 → 重新挑战。

死亡后敌人重置，损失部分当前可能性；具体百分比、复活生命/可能性、剧情与成长状态保存规则留到T3。V0.1只实现基础复活功能，不加入12的完整死亡叙事。

镜头动态跟随玩家，大型战斗允许拉远，以保证多人战场可读性。具体镜头参数留到后续实现验证。

## 7. 设计验收与待定事项

以下是冻结的验收要求，尚需游戏实现后运行验证：

- 核心玩法闭环：只依靠已冻结操作，即可完成探索 → 遭遇 → 战斗/互动 → 获得可能性 → 恢复/成长 → 继续探索。
- 操作无缺口：荒地、田野、逆时战场均有明确可执行操作，不依赖墙体能力、空中闪避或其他后期能力。
- 资源边界：必经地形不要求消耗可能性的闪避，避免因资源不足造成地形通行软锁。

T3处理生命、可能性、成长与死亡经济；后续灰盒测试处理速度、前后摇、判定范围、无敌时长与容错实现。T7细化UI表现。未冻结具体键位，不从操作描述推定完整键位表。
