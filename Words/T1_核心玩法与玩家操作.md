# 《末日前31天》V0.1 策划案：T1 核心玩法与玩家操作

版本：V0.1｜状态：设计规则已冻结｜整理日期：2026-10-07｜现行版更新：2026-10-19

本文是现行规格：正文只写当前有效的操作规则，历次修订已并入对应章节，来源见第9节变更记录。资源、伤害与成本数值的权威位置是T3，战斗细则是T2；本文引用时注明出处。

## 1. 体验与核心循环

操作关键词：灵活、危险、连贯。玩家优势是灵活、攻击范围与流畅滑步；主要风险是攻击后摇、受击硬直及多敌战斗。

基础循环为移动、探索、战斗、生存，反复发生在约30秒至2分钟的体验单元中。完整行为链为：探索 → 遭遇 → 战斗/互动 → 获得可能性 → 恢复/成长 → 继续探索。

战斗循环为判断敌人 → 躲避/攻击 → 受击/击杀 → 必要时恢复 → 再次进攻或前进。快速移动寻找位置，利用四方向攻击寻找窗口；击杀敌方单位补充可能性，恢复与闪避共同消耗可能性。

探索由逃生、NPC线索、剧情推进、发现收集品与角色提升驱动，收集范围遵守T0。帮助NPC获得可能性；完成7的事件获得7的注视后，有效帮助不同NPC可提高可能性上限；获得注视前完成的有效帮助先记录，首次获得注视时统一结算。收益与成长条件见T3。

失败后经短暂倒地与死亡菜单，在检查点复活并获得3秒无敌，再次挑战；不采用早期“直接在上一场景复活”的模糊位置规则。

## 2. 移动、转向与跳跃

| 设计项 | 冻结规则 |
| --- | --- |
| 基础移动 | 横向移动，支持转向、跳跃和下落；有行走/跑步区别，强调速度感 |
| 转向 | 转向存在短暂前摇；已经发动的单次攻击方向锁定，攻击间隙允许转向，下一击按新方向发动 |
| 空中控制 | 起跳后可改变朝向并输入反向移动；不会瞬间反向，原速度先衰减，再向新方向加速 |
| 跳跃高度 | 按住跳跃键越久，跳跃高度越高；上升接近顶点时变慢；具体参数由灰盒调校 |
| 下落 | 达到跳跃顶点后开始下落，下落速度随时间加快，并存在最大下落速度 |
| 高空坠落 | 有高空落地硬直与特殊动作；环境伤害沿用T2受击规则，伤害值见T3（环境伤害1-2点） |
| 边缘宽容 | 给予接近平台边缘时的跳跃容错，填写的尺度为1/3角色身高；具体实现方式由灰盒落实 |
| 墙体互动 | V0.1不做墙跳、贴墙、蹬墙 |

基础跳跃次数、速度、加速度、容错时间等未给出明确冻结值，不从表格示例推定。

## 3. 基础攻击

普通攻击为2段连击：相邻两次有效攻击按键的间隔不超过0.5秒（含边界）时衔接第二段，超过则重新从第一段开始；间隔按按键时刻计算，输入缓冲不重新起算该间隔；被其他动作打断时同样重置。第二段击退更强、后摇更长。

| 设计项 | 冻结规则 |
| --- | --- |
| 左右攻击 | 攻击左右敌人并弹开符合条件的飞行物 |
| 向上攻击 | 按住上方向键并单击攻击键；可打空中敌人、弹开飞行物，击退较高 |
| 向下攻击 | 地面不可用，只能空中发动；命中弹起高度为长按跳跃最大高度的50%，随跳跃参数调整；按住或松开跳跃键不改变该弹起；不能弹开飞行物 |
| 空中攻击 | 基础攻击方式沿用地面规则；空中下落攻击不改变滞空时间，命中弹起为独立效果 |
| 攻击中移动 | 取消攻击时的移动减速，保持正常行走/跑步速度；跑步出招时前摇与后摇各乘2，判定持续时间不变；攻击中可跳跃且不打断攻击，方向、计时、命中记录与连击记录保留 |
| 攻击中转向 | 当前单次攻击方向锁定；攻击间隙转向后，下一击使用新方向 |
| 攻击取消 | 只能由闪避取消，其他动作不能取消；地面/空中均可闪避，仍受资源条件约束；跳跃可与攻击并行 |

跑步出招指发动时按住跑步并有水平移动输入；本次动作锁定前后摇倍率，中途松开跑步不缩短后摇。灰盒前后摇数值见T2第2节。

近战攻击范围可通过永久成长扩大（击败渴望俯视、拾取珍珠），弹反方向限制不变，伤害与动作时序不变，见T0第3.4节与T3。投掷物类型、命中次数、受击与反馈等详细规则见T2。

## 4. 滑步、受击与恢复

### 4.1 滑步

V0.1支持地面/空中左右闪避。无方向输入时沿当前面向；空中闪避保留竖直速度、继续受重力与跳跃松键影响，不悬空、不重置跳跃。滑步同时用于规避攻击与调整站位，拥有短暂无敌，消耗可能性，没有独立体力系统。

地面与空中共用连闪规则：最多连续3次，第一、第二、第三次分别消耗1、2、3可能性；距上一次实际发动滑步1.3秒后恢复为第一次消耗。可能性不足一次完整成本时仍可滑步，但进入资源不足状态（前摇较大、无敌帧减少）；扣费会使余额低于-9时拒绝本次滑步。数值见T3第4节。

闪避是战斗能力，不作为V0.1任何必经地形的通行条件。

### 4.2 受击

玩家普通受击有轻硬直与轻微击退；受击硬直期间短暂无敌，以避免同一窗口连续受伤。仍保留多敌协同、后续攻击与站位风险，群战进攻名额规则见T2。

10的特殊救场只发生在逆时战场首次登场事件中，由三个条件中任一满足时触发：玩家即将受到致命攻击、两名幸存者均到达后全部倒下、首段清空后的第二波兜底；三者共享同一次事件，细节见T2“2026-10-16追加修订：10一次性救场与协同测试”。事件为一次性，触发后再次死亡正常进入死亡流程；其他场景正常死亡。

### 4.3 恢复

玩家长按恢复键；按下立刻进入恢复状态并扣除3可能性，持续2.8秒，完成时一次性恢复2生命，不超过最大生命。恢复期间不能移动，可被攻击打断并受到伤害；被攻击打断、主动滑步取消或提前松键时，已扣的3可能性都不退还，也不恢复生命。允许战斗中恢复，满血不可使用；当前可能性不足3时不能启动，恢复不使用透支。需要寻找明显安全窗口。数值见T3第4、5节。

## 5. 互动、拾取与状态

| 设计项 | 冻结规则 |
| --- | --- |
| NPC互动 | 强制剧情自动触发；普通NPC与可选对话手动互动 |
| 门 | 已开启的门不阻拦；未开启的门手动触发 |
| 机关 | 陷阱机关可手动或自动触发；功能机关需角色交互 |
| 剧情点 | 自动触发；剧情期间限制移动、攻击等操作 |
| 普通资源拾取 | 靠近自动吸收 |
| 关键/剧情物品 | 手动互动，并播放拾取动作 |
| 战斗可能性 | 击杀后直接获得，播放获得特效 |
| 战斗状态进入 | 敌人主动锁定玩家或强制战斗开始 |
| 探索状态恢复 | 敌人清除或脱离警戒；普通遭遇中敌人切换场景前持续追击，强制战斗不可逃离 |
| 使用道具 | 应急药包：按Q / Back，消耗1个立即恢复2生命，不超过最大生命；满血不消耗；地面、空中均可使用 |

应急药包不扣可能性、不提供无敌；攻击、闪避、恢复、受击硬直、死亡、剧情及菜单期间不能使用。携带上限、初始数量、拾取来源与死亡保留规则见T3。

普通敌人奖励与剧情固定掉落遵守T2，不实现随机战利品系统。

## 6. 死亡重来与镜头

生命归零 → 1秒倒地 → 死亡动画 → 死亡菜单 → 选择返回检查点 → 满生命复活 → 3秒复活无敌 → 重新挑战。

死亡后非Boss敌人重置；非负可能性保留50%（向下取整），负数清零，永久上限不扣减；已完成的NPC事件、剧情、成长与已获得物品不回滚。复活无敌不会因主动攻击提前解除。具体规则见T3第10节。V0.1只实现基础复活功能，不加入12的完整死亡叙事。

镜头动态跟随玩家，大型战斗允许拉远，以保证多人战场可读性。具体镜头参数由实现验证确定。

## 7. 设计验收与待定事项

以下是冻结的验收要求，尚需游戏实现后运行验证：

- 核心玩法闭环：只依靠已冻结操作，即可完成探索 → 遭遇 → 战斗/互动 → 获得可能性 → 恢复/成长 → 继续探索。
- 操作无缺口：荒地、田野、逆时战场均有明确可执行操作，不依赖墙体能力或其他后期能力；闪避（含空中闪避）不作为必经通行条件。
- 资源边界：必经地形不要求消耗可能性的闪避，避免因资源不足造成地形通行软锁。

速度、前后摇、判定范围、无敌时长与容错实现由灰盒测试确定，资源与死亡经济见T3，UI表现由T7细化。
