# 《末日前31天》V0.1 策划案：T0 范围冻结

版本：V0.1｜状态：设计范围已冻结｜整理日期：2026-10-07

## 1. 版本目标与起止点

V0.1 从玩家高空坠落开始，到逆时战场首次大战胜利结束。胜利后播放阶段结束反馈与结局剧情，进入 Demo 结束状态。范围内不继续推进到钉锤营地，不新增 Boss。

本版验证的体验曲线为：恐惧 → 安定 → 反抗。

完整玩家流程：

高空坠落 → 荒地逃生 → 田野恢复 → 理解可能性 → 接触7 → 遇见逃亡战士 → 进入逆时战场 → 学习真正战斗 → 10登场 → 第一次大战胜利 → Demo结束。

## 3. 已接受的范围收束

### 3.1 时间框架

完整游戏为31天，V0.1只验证3天框架。Day 1荒地、Day 2田野、Day 3逆时战场仅为缩小测试的示例，不冻结“一个区域等于一天”。时间推进方式、区域与日期关系及具体可见影响留到T4。

### 3.2 货币

若逆时战场已需要货币奖励，可保留货币；若没有实际消费用途，只在数据结构保留货币，V0.1不做完整货币玩法。当前不据此新增商店、完整经济系统或平衡工作。是否存在实际用途与相应UI显示仍需明确。

### 3.3 死亡复活

V0.1只实现功能闭环：HP归零 → 死亡与短暂倒地反馈 → 返回检查点 → 恢复基础状态 → 重新挑战。T1进一步冻结复活后3秒无敌、敌人重置和损失部分当前可能性；具体资源恢复量与损失比例留到T3。

完整版本再用“背后的拥抱”的回溯包装机制；V0.1不实现12、破碎镜面、死亡记录等完整叙事表现。

### 3.4 成长与可能性

核心资源为生命、可能性。击杀敌方单位及特定NPC互动获得可能性，可能性用于恢复与闪避；帮助NPC形成正反馈，7的注视提高可能性上限。具体成本、收益、成长条件和次数由T3确定。10的生命上限成长不在V0.1正式开放。

## 5. 冻结状态与后续边界

T0范围、T1核心玩法与玩家操作、T2战斗系统均已完成设计冻结。这不表示游戏实现或运行测试已经完成。

| 检查项 | 冻结结论 |
| --- | --- |
| 起点与终点 | 高空坠落；逆时战场首次大战胜利 |
| 地图、主要角色、基础NPC、敌人 | 三张地图；7/10；幸存者/濒死战士；三类敌人 |
| 玩家基础能力、核心玩法、战斗流程 | 已冻结，详见T1、T2 |
| 核心资源与成长方向 | 生命/可能性；7提高可能性上限 |
| 对话、死亡复活、UI、完整流程 | 已纳入 |
| 时间系统 | 3天框架已纳入，T4详细设计 |
| 操作参数与数值 | 规则已冻结，未给出的帧数、速度、伤害、消耗、收益等留到后续设计与灰盒验证 |

后续任务为T3可能性/基础属性/成长/死亡、T4时间系统、T5地图结构、T6内容最低配置、T7 UI/存档、T8技术基线。后续细化应遵守已冻结范围。
