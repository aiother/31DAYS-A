# 《末日前31天》V0.1 策划案：T0 范围冻结

版本：V0.1｜状态：设计范围已冻结｜整理日期：2026-10-07｜现行版更新：2026-10-19

本文是现行规格：正文只写当前有效的范围，历次修订已并入对应章节，来源见第7节变更记录。

## 1. 版本目标与起止点

V0.1 从玩家高空坠落开始，到逆时战场首次大战胜利结束。胜利后播放阶段结束反馈与结局剧情，进入 Demo 结束状态。范围内不继续推进到钉锤营地。

本版包含两个已确认的 Boss 房间：荒地的“渴望俯视”与“寄生同伴者”（配置见T5.3）。最终战不增加额外Boss，除这两个房间外不新增其他Boss。

本版验证的体验曲线为：恐惧 → 安定 → 反抗。

完整玩家流程：

高空坠落 → 荒地逃生 → 田野恢复 → 理解可能性 → 接触7 → 遇见逃亡战士 → 进入逆时战场 → 学习真正战斗 → 10登场 → 第一次大战胜利 → Demo结束。

## 3. 已接受的范围收束

### 3.1 时间框架

完整游戏为31天，V0.1只验证3天框架。Day 1荒地、Day 2田野、Day 3逆时战场仅为缩小测试的示例，不冻结“一个区域等于一天”。时间推进方式、区域与日期关系及具体可见影响见T4。

### 3.2 货币

货币在后续版本有实质用途，并会在HUD中显示。V0.1中货币不能获取、没有消费用途、不在UI显示，只在数据结构中保留；V0.1不做完整货币玩法，不据此新增商店、完整经济系统或平衡工作。

### 3.3 死亡复活

V0.1只实现功能闭环：HP归零 → 死亡与短暂倒地反馈 → 死亡菜单 → 返回检查点 → 恢复基础状态 → 重新挑战。复活后满生命、3秒无敌、非Boss敌人重置；非负可能性保留50%（向下取整），负数清零。具体规则见T1、T3。

完整版本再用“背后的拥抱”的回溯包装机制；V0.1不实现12、破碎镜面、死亡记录等完整叙事表现。

### 3.4 成长与可能性

核心资源为生命、可能性。击杀敌方单位及特定NPC互动获得可能性，可能性用于恢复与闪避；帮助NPC形成正反馈，7的注视提高可能性上限（10 → 12 → 13 → 14 → 15）。成本、收益、成长条件和次数见T3。

V0.1另开放以下永久成长，均为固定来源、每个存档槽只获得一次，具体规则见T2、T3：

- 攻击范围：击败渴望俯视后近战攻击范围永久+20%；四颗珍珠各+5%；与前者加算，全部获得为基础范围的140%。
- 闪避速度：击败寄生同伴者后，地面/空中闪避速度永久提高。

应急药包是可携带的消耗品，不属于永久成长。10的生命上限成长不在V0.1正式开放。
