# 初页 · 12 帧冲刺跑步

依据用户确认的无光晕步行形象制作。12 个连续姿势覆盖前脚掌落地、承重蹬地、蹬离、分腿腾空、后跟回收、屈膝前摆及下一次落地准备；角色前倾、屈肘摆臂，披风与袖口向后展开，保持原有纸面分片与白发造型。

**右腿＝橙色圆点、亮色外侧/近景；左腿＝蓝色双线、暗色内侧/远景。** 每条腿经过全部 12 个相位，左右相差 6 帧；腿的位置前后改变不交换身份或明暗。灰色腿始终在白色腿内侧，衣物和双臂依侧面视角自然遮挡。单根呆毛、翻领、菱形扣、三片披风、短衣短裤和两只翻口靴保持造型。

## 动态与导出

第 1、2 帧右腿落地承重，第 7、8 帧左腿落地承重，地面统一为图像轮廓下界 y=488；第 3–6、9–12 帧为蹬离后的腾空阶段。12→1 接回右腿落地。保持头部周期性起伏，避免原生成图按行排版引入的垂直跳位。

角色图像由 **image_gen 内置工具** 生成并修正标识、明暗及局部腿姿。后处理只对整张生成图作一次统一尺寸转换，再固定切格、平移角色根位置，并统一增加左右各 32 像素留白；没有对某一帧单独缩放，也没有插值生成中间姿势或拉伸关节。背景为均匀灰色，无光晕和速度线；速度感由前倾、后蹬、跨步、腾空和衣料摆动体现。

骨骼文件是控制方案，不等于对生成成图每个关节的精确测量。自动验证约束控制骨长与身份、实际标识与落地位置、画幅、循环衔接和编码一致性；形象、衣料结构及前后遮挡同时经过目视审查。
