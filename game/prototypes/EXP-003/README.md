# EXP-003 主界面与存档选择探索原型

只用于比较和挑选，不进入正式游戏；不改正式场景、共享脚本、`project.godot`、输入映射或存档，数据全是模拟的。视觉沿用 EXP-002 样张二与 UI-001 样式模块（只读引用）。任务卡：`codexandclaude/tasks/EXP-003/task.md`。

## 启动

双击本目录的 `run_preview.cmd`，或在项目根目录执行：

```powershell
& "D:\DMyself\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe" --path game res://prototypes/EXP-003/preview.tscn
```

画面右上有按键说明，按 H 隐藏。截图见 `screenshots/`。

## 按键

| 按键 | 作用 |
| --- | --- |
| 1 / 2 / 3 | 主界面方案 A / B / C（在主界面时立即切换） |
| 4 / 5 | 存档选择方案 1 / 2（在存档选择界面时立即切换） |
| N | 切换“没有任何存档”（主界面隐藏“继续游戏”） |
| B | 切换槽三为“无法读取” |
| R | 重置模拟存档 |
| 方向键 / 手柄十字键 / 鼠标 | 移动焦点；Enter / Space / 手柄 A 确认；Esc 返回 |
| 游戏中：Esc / K / F / T | 暂停 / 模拟死亡 / 模拟通关（夕阳将至）/ 模拟最终战超时（未来已失） |

## 模拟存档

槽一：第2日、游戏时长 1:23:45、生命 4、可能性 6/12、珍珠 2、最后检查点“沟壑入口”。槽二：已通关（第3日）。槽三：空（B 键切换为无法读取）。

## 主界面三个方案

共同点（T7-A）：标题“末日前31天”位于中上方、占画面约 1/3；菜单为新游戏、继续游戏（没有任何存档时不显示）、设置、退出游戏；有存档时默认焦点在“继续游戏”；退出需确认；“设置”在原型里是占位提示（第五批接 SYS-007）。

| | A · 黄昏远景 | B · 纸页水墨 | C · 朦胧战场 |
| --- | --- | --- | --- |
| 背景 | 黄昏天空渐变、低垂的太阳与光晕、两层残破城市剪影、飘尘 | 整屏随黄昏着色的纸页、水墨勾勒的废墟、缓慢游移的光斑 | 灰盒战场（平台、角色、敌人）经模糊与暖色去饱和，斜射光束与暗角 |

| 与 T7“朦胧滤镜与打光的颓废背景” | 打光强，颓废感来自剪影 | 偏书卷气，朦胧感最弱 | 最贴近“朦胧滤镜”，以后可直接换成真实游戏画面 |

## 存档选择两个方案

共同点（T7-A、T7-E1、A-013）：三个槽横向排列，左右键选择；每槽显示标题、游戏时长、角色属性（生命碎片、可能性、珍珠）、最后检查点；继续游戏时选进行中的槽进入，选已通关的槽提示“游戏已通关”并停留，空槽与无法读取的槽说明原因；新游戏时选空槽确认开始，选有进度的槽提示“将覆盖此槽现有进度”，确认框默认焦点在“返回”。

| | 1 · 书签 | 2 · 黄昏卡片 |
| --- | --- | --- |
| 形态 | 三条竖长书签并排，下端燕尾，选中的升起 | 三张横向卡片，上半是该槽当日的天空与太阳位置 |
| “天数”的表达 | 书签纸色随该槽的黄昏程度变化 | 天空条的黄昏程度与太阳位置 |
| 已通关 | 朱红圆印“已通关” | 金色双边框与“已通关 · 夕阳将至” |
| 空槽 / 无法读取 | 淡色书签“空” / 划痕与“无法读取” | 虚线框“＋ 新的开始”或“空槽” / 灰色天空与说明 |
| 信息量 | 竖排，行距宽，较疏 | 横排，信息更紧凑 |

## 返回标题

原型用一个“游戏中”占位画面演示所有回到主界面的路径：暂停（正式暂停菜单见 UI-003，主界面完成后加“返回标题”）、死亡（A-014：从检查点继续、返回标题、设置、退出游戏）、V0.1 结束“夕阳将至”（游玩时长、返回标题；该槽记为已通关）、最终战超时“未来已失”（A-011：游玩时长、重试、返回标题）。
