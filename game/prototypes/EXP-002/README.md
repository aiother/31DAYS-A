# EXP-002 UI 整体视觉基调探索

只用于比较和挑选，不进入正式游戏。布局与交互沿用用户已选定的 EXP-001 方案四，本原型只回答“长什么样”。任务卡：`codexandclaude/tasks/EXP-002/task.md`。

不修改正式场景、共享脚本、`project.godot`、输入映射、存档或 `game/prototypes/EXP-001/`；只读复用 EXP-001 的模拟状态（`hud_state.gd`）与透支失真 shader。

## 启动

双击本目录的 `run_preview.cmd`，或在项目根目录执行：

```powershell
& "D:\DMyself\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe" --path game res://prototypes/EXP-002/preview.tscn
```

画面顶部显示当前样张、第几日、黄昏程度与“随天数变化”开关；右侧是按键说明（H 隐藏）。

## 按键

| 按键 | 作用 |
| --- | --- |
| 1 / 2 | 样张一（手札为主）/ 样张二（黄昏为主） |
| 5 / 6 / 7 | 跳到第1日 / 第2日 / 第3日，看黄昏逐日加深 |
| 8 / 9 | 最终战：开战时第3日还余25分钟（加速演出后定格15:00，A-016 一①）/ 只余9分12秒（直接显示真实剩余与朱红警示，A-016 二③） |
| 0 | 开关“随天数变化”；关闭时固定为中等混合，便于对照 |
| Esc | 暂停菜单：左侧选项、右侧时钟与三天进度；设置或保存并退出的二级页盖住时钟；Esc 逐级返回 |
| K | 通用对话框与按钮状态样式（常态、悬停、选中、按下、不可用） |
| Q / E / F | 受伤 / 尝试恢复 / 尝试闪避（不足时环发红） |
| A / S / D | 消耗1（透支时画面失真）/ 获得1 / 获得3（光点飞入环） |
| G / Z / X / C / V | 成长外圈 / 珍珠 -1 / +1 / 药包显示 / 药包数量 |
| T / Y / U | 时间 +1分钟 / 换日前3分钟提示 / 立即换日（中上部纸签） |
| L / 空格 / R | 时间 ×1/×30 / 暂停时间 / 重置 |

## 两个样张

| | 样张一 · 手札为主 | 样张二 · 黄昏为主 |
| --- | --- | --- |
| 底子 | 米黄纸张（`#efe4cc`）、粗糙墨线（宽 2.6、抖动大）、纸纤维 | 同样的纸，但半透明，上面叠紫粉（`#7d4a8c`）到橙金（`#f0a050`）的渐变，像夕阳照透的玻璃 |
| 墨线 | 明显手绘感，转角略出头 | 更细更稳（宽 1.7、抖动小），只作点缀 |
| 光 | 只在可能性环、地平线太阳、倒计时等关键处 | 处处有柔光，随呼吸缓慢起伏 |
| 三天变化 | 小：黄昏最多到 55%，第3日纸色略暖、光变强 | 大：第1日接近白纸，最终战完整黄昏，画面上下边缘被晚霞浸染 |
| 动效节奏 | 慢、稳 | 舒缓的呼吸式脉动 |

**不随天数变化的关键颜色**（两样张相同）：生命朱红 `#b8382c`、可能性青绿 `#2f8f88`（发光 `#9fe6d6`）、成长金 `#d9a03a`、透支暗红 `#6e1f3a`、警示红 `#ff4636`、墨色 `#2b2420`。

## 与规格的关系

- **基调来源**：甲（褪色手札）对应“末日前的个人记录”，丙（黄昏余辉）对应 V0.1 结局临时标题“夕阳将至”与地平线时间的意象。
- **新增表现（T7 未写）**：界面随末日临近染上黄昏；透支时画面失真（EXP-001 已选定）。正式任务需在 T7 中补写。
- **偏离**：T7 中 HUD 元素多为纯图形；这里统一放在纸签上，以保证纸墨风格在深色场景上可读。

## 字体（需要你决定）

原型只用 Godot 自带字体，靠字号、颜色和墨线营造手札感。若想要真正的手写感，推荐 **霞鹜文楷（LXGW WenKai）**：开源字体（SIL Open Font License 1.1），可免费商用、可嵌入游戏。要不要用、是否由我下载接入，请你决定；本任务没有下载任何外部资源。

## 文件

- `preview.tscn` / `preview.gd`：预览场景与按键。
- `style.gd`：色板、黄昏程度计算与纸签面板；`ink.gd`：手绘线条、纸张、光晕。
- `hud_view.gd`：徽记、地平线时刻、换日纸签、三分钟提示、最终战倒计时、边缘晚霞、光点飞入。
- `pause_view.gd`：暂停菜单；`ink_button.gd`：墨迹按钮；`dialog_sample.gd`：通用对话框。
- `tests/smoke_test.gd`：无头冒烟测试；`tests/capture.gd`：生成截图（需要窗口）；`screenshots/`：截图（`.gdignore` 让 Godot 不导入）。
