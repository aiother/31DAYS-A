# EXP-001 HUD 与时间显示探索原型

只用于比较和挑选，不进入正式游戏；不改正式场景、共享脚本、`project.godot`、输入映射或存档。任务卡：`codexandclaude/tasks/EXP-001/task.md`。

## 启动

双击本目录的 `run_preview.cmd`，或在项目根目录执行：

```powershell
& "D:\DMyself\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe" --path game res://prototypes/EXP-001/hud_preview.tscn
```

画面右侧有按键说明，按 H 隐藏。截图见 `screenshots/`（每个方案一张常态、一张高压状态：最后1点生命、透支、发红闪烁、最终战余时不足15分钟）。

## 按键

| 按键 | 作用 |
| --- | --- |
| 1 / 2 / 3 / 4 | 切换方案（4 为第1轮挑选后的组合方案） |
| Esc | 暂停菜单：左侧选项，右侧时钟与三天进度；进入设置或保存并退出的二级界面会盖住时钟，Esc 返回；在主菜单再按 Esc 关闭 |
| Q | 受伤（最低到1点，触发画面边缘红色） |
| E | 尝试恢复：可能性≥3 时消耗3、恢复2；不足时容器发红闪烁（A-018） |
| F | 尝试闪避：1.3 秒内连续闪避的成本依次为 1、2、3，一串最多三次（与正式规则一致，计数不显示）；当前余额不够这次成本时仍可闪避但透支，容器发红闪烁（A-018），例如余额 1 时连闪第二次（成本2）也会发红 |
| A / S / D | 消耗1（可透支到 -9）/ 获得1 / 获得3（光效从右侧敌人位置飞入容器） |
| G | 成长上限 0 / 1 / 2 段（每段 +2，原型假设值） |
| Z / X | 珍珠 -1 / +1（G-02，每颗攻击范围 +5%） |
| C / V | 显示药包数量（G-01，可选建议）/ 切换数量 |
| T / Y / U | 时间前进1分钟 / 跳到换日前3分钟（右下角提示）/ 立即换日（中上部日期展示） |
| O | 最终战，第3日还剩25分钟：时间加速并定格到 15:00，只是视觉表现，第3日多出的时间不被消耗（A-016 一①） |
| P | 最终战，第3日只剩 9:12：直接显示真实剩余（A-016 二③） |
| I | 结束最终战 |
| L / 空格 | 时间流速 ×1 / ×30；暂停时间 |
| Tab | 方案二按住展开完整时间（A-015 ③） |
| R / H | 全部重置 / 显示或隐藏说明 |

## 三个方案

| | 方案一 | 方案二 | 方案三（可选） |
| --- | --- | --- | --- |
| 思路 | 信息集中在左上角，最接近 T7 原文 | 生命与可能性合成一个徽记，屏幕占用最小 | 偏离规格、追求表现力 |
| 生命 | 心形图标，只显示现有数量 | 徽记中心的菱形碎片 | 左侧竖排碎片 |
| 可能性 | 横向斜切格子；成长上限为金色附加格；透支从右端反向变红 | 环形格子，从顶部顺时针填充；成长上限为外圈金色段；透支从顶部逆时针变红 | 不分格的光团，随数值变大；透支时变成向内的红色尖刺 |
| 珍珠与范围 | 格子下方一排珍珠 + “攻击范围 xx%” | 徽记下方四颗珍珠 + “范围 xx%” | 珍珠绕光团旋转，轨道随范围变大 |
| 日内时间 | 右下角常驻：日期、末日倒数、时刻、日照进度条（A-015 ①） | 右下角只显示“xx时”和日晷，按住 Tab 展开日期、时刻、距下一日（A-015 ③） | 横贯底部的地平线，太阳随时间移动（A-015 ①的变体） |
| 正式版工作量（粗估） | 小：形状简单，主要是动效 | 中：环形布局与透支方向需要细调 | 中到大：需要美术配合形状与破裂效果 |

三个方案共用：最后1点生命时画面边缘红色脉动；换日时中上部“第 N 日 / 末日前 N 天”；换日前3分钟右下角提示；最终战倒计时在中上部。

## 方案四：第1轮挑选后的组合（2026-10-20）

用户试玩后的选择：“比较喜欢方案二的思路和方案三的时间显示”。据此组合：

| 部分 | 做法 | 来源 |
| --- | --- | --- |
| 生命、可能性、珍珠 | 方案二的徽记 | 用户挑选 |
| 日常时间 | 方案三的底部地平线，太阳上方显示时刻（如 17:00），右下角小字“第N日 · 末日前N天” | 用户：“更喜欢时刻，但日常游玩时底部地平线更舒适” |
| 可能性不足 | 两种同时存在：尝试恢复或闪避而不足时容器闪烁；可能性低于0时游戏画面蒙上失真滤镜（波动、色散、去色、暗角），透支越多越强，HUD 本身不失真 | 用户第2点 |
| 完整时间与天数 | 不再用 Tab 展开（不需要新增按键，冻结键位表不用改）；改为暂停菜单右侧的时钟：表盘、时刻、第N日与末日倒数、三天进度条、距下一日 | 用户第3点 |
| 暂停菜单 | 左侧：继续游戏、设置、保存并退出；右侧默认是时钟；选择有二级界面的选项（设置、保存并退出确认）时，二级界面盖住时钟 | 用户第3点 |

方案四需要你再看一眼的地方：

- **暂停菜单右侧原本是“当前任务”**：T7 与待办 BL-046 写的是“右侧显示当前任务（无则显示背景）”。方案四改为以时钟为主，当前任务暂时作为一行小字放在时钟下方。若你同意这个方向，正式任务里要同步修订 T7 的暂停菜单描述；若希望任务更显眼，也可以把任务放回右侧上方、时钟缩小。
- **失真滤镜只在方案四开启**，切回 1～3 不会出现，方便对照。
- **设置页和确认页是占位内容**，只演示“二级界面盖住时钟”的布局；正式设置内容见 BL-047。

## 与规格的偏离和待你判断的点（第1轮，已由方案四回答的已标注）

- （已回答：方案四改用暂停菜单时钟，不新增按键）**方案二** 的“按 Tab 展开”使用原型内的临时按键；如果选中，正式任务需要修订 T1 §7 冻结键位表（A-015 ③的已知代价）。
- **方案三** 的偏离：可能性不是“异形容器”而是无格光团，看不出精确数值；生命在左侧竖排而不是左上；最后1点生命时 HUD 出现裂痕；时间改为底部地平线。选中任何一项都需要在正式任务中同步修订 T7 相关描述。
- （已回答：显示时刻，日常用地平线）**日内时间怎么表示**：游戏里一天是 30 分钟真实时间，没有“几点钟”的概念。原型把它映射成 06:00～24:00 的时刻，这是原型的假设；也可以改成“白天进度条”或“距下一日剩余分钟”，请一并判断。
- （已回答：两种同时存在，并加透支失真滤镜）**A-018 发红的触发方式**：原型是“尝试恢复或闪避而不足时闪一下”。另一种理解是“只要不足就持续发红”，若你更倾向后者请告诉我。
- **最终战倒计时**：余时超过15分钟时的“加速到 15:00”只是画面演出，演出期间真实的最终战预算和第3日时间照常流逝；打开暂停菜单时两者与演出一起暂停。
- **成长上限每段 +2** 是原型假设，只影响画面长度，不影响你比较布局。

## 文件

- `hud_preview.tscn` / `hud_preview.gd`：预览场景与按键。
- `hud_state.gd`：模拟状态（数值取自灰盒配置）。
- `variant_base.gd`、`variant_corner.gd`、`variant_emblem.gd`、`variant_fracture.gd`：三个方案。
- `shared_overlay.gd`：各方案共用的提示与倒计时。
- `variant_combo.gd`：方案四（继承方案二，替换时间显示）。
- `overdraft_distortion.gdshader`：透支失真滤镜。
- `pause_menu.gd`、`pause_clock.gd`：暂停菜单与右侧时钟。
- `tests/smoke_test.gd`：无头冒烟测试；`tests/capture.gd`：生成截图（需要窗口）。
