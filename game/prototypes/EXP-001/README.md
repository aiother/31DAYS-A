# EXP-001 HUD 与时间显示探索原型

只用于比较和挑选，不进入正式游戏；不改正式场景、共享脚本、`project.godot`、输入映射或存档。任务卡：`codexandclaude/tasks/EXP-001/task.md`。

## 启动

双击本目录的 `run_preview.cmd`，或在项目根目录执行：

```powershell
& "D:\DMyself\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe" --path game res://prototypes/EXP-001/hud_preview.tscn
```

画面右侧有按键说明，按 H 隐藏。截图见 `screenshots/`（每个方案一张常态、一张高压状态：最后1点生命、透支、发红闪烁、最终战余时不足15分钟）。

| A / S / D | 消耗1（可透支到 -9）/ 获得1 / 获得3（光效从右侧敌人位置飞入容器） |

| Z / X | 珍珠 -1 / +1（G-02，每颗攻击范围 +5%） |
| C / V | 显示药包数量（G-01，可选建议）/ 切换数量 |
| T / Y / U | 时间前进1分钟 / 跳到换日前3分钟（右下角提示）/ 立即换日（中上部日期展示） |
| O | 最终战，第3日还剩25分钟：时间加速并定格到 15:00，只是视觉表现，第3日多出的时间不被消耗（A-016 一①） |

## 三个方案

| | 方案一 | 方案二 | 方案三（可选） |
| --- | --- | --- | --- |
| 思路 | 信息集中在左上角，最接近 T7 原文 | 生命与可能性合成一个徽记，屏幕占用最小 | 偏离规格、追求表现力 |
| 生命 | 心形图标，只显示现有数量 | 徽记中心的菱形碎片 | 左侧竖排碎片 |
| 可能性 | 横向斜切格子；成长上限为金色附加格；透支从右端反向变红 | 环形格子，从顶部顺时针填充；成长上限为外圈金色段；透支从顶部逆时针变红 | 不分格的光团，随数值变大；透支时变成向内的红色尖刺 |
| 珍珠与范围 | 格子下方一排珍珠 + “攻击范围 xx%” | 徽记下方四颗珍珠 + “范围 xx%” | 珍珠绕光团旋转，轨道随范围变大 |
| 日内时间 | 右下角常驻：日期、末日倒数、时刻、日照进度条（A-015 ①） | 右下角只显示“xx时”和日晷，按住 Tab 展开日期、时刻、距下一日（A-015 ③） | 横贯底部的地平线，太阳随时间移动（A-015 ①的变体） |
| 正式版工作量（粗估） | 小：形状简单，主要是动效 | 中：环形布局与透支方向需要细调 | 中到大：需要美术配合形状与破裂效果 |

三个方案共用：最后1点生命时画面边缘红色脉动；换日时中上部“第 N 日 / 末日前 N 天”；换日前3分钟右下角提示；最终战倒计时在中上部。

## 与规格的偏离和待你判断的点

- **方案二** 的“按 Tab 展开”使用原型内的临时按键；如果选中，正式任务需要修订 T1 §7 冻结键位表（A-015 ③的已知代价）。
- **方案三** 的偏离：可能性不是“异形容器”而是无格光团，看不出精确数值；生命在左侧竖排而不是左上；最后1点生命时 HUD 出现裂痕；时间改为底部地平线。选中任何一项都需要在正式任务中同步修订 T7 相关描述。
- **日内时间怎么表示**：游戏里一天是 30 分钟真实时间，没有“几点钟”的概念。原型把它映射成 06:00～24:00 的时刻，这是原型的假设；也可以改成“白天进度条”或“距下一日剩余分钟”，请一并判断。
- **A-018 发红的触发方式**：原型是“尝试恢复或闪避而不足时闪一下”。另一种理解是“只要不足就持续发红”，若你更倾向后者请告诉我。
- **成长上限每段 +2** 是原型假设，只影响画面长度，不影响你比较布局。
