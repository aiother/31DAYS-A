# EXP-005 战斗反馈特效原型

只做原型，不接正式战斗逻辑、存档或输入映射。所有特效用代码绘制，颜色来自 UI-001 样式模块（`DuskStyle`、`InkDraw`），不依赖外部素材。

## 运行

双击 `run_preview.cmd`，或：

```
Godot --path game res://prototypes/EXP-005/preview.tscn
```

## 操作

| 按键 | 作用 |
| --- | --- |
| 1 / 2 / 3 / 4（手柄 LB / RB） | 风格 A 墨迹飞溅 / B 光痕 / C 极简几何 / D 融合（默认） |
| H | 顿帧开关（默认开，0.10 秒，用户定稿值） |
| [ / ] | 顿帧缩短 / 加长（0.04～0.20 秒，每次 0.02） |
| V | 普通命中也震动（默认关；受击始终轻震） |
| A D 或 ← →（左摇杆） | 移动 |
| 空格（手柄 A） | 跳 |
| J（手柄 X） | 攻击；按住 W / ↑ 向上，空中按住 S / ↓ 向下 |
| K（手柄 B） | 闪避 |
| 长按 L（手柄 Y） | 恢复；中途松开即中断 |
| P | 切换“可能性不足”，闪避变为透支闪避 |
| R | 最近的靶子射出投射物；攻击它可弹反 |
| T / Z | 受击 / 复活 |
| G | 八个靶子同时受击，底部显示之后 30 帧的帧时间 |
| F1 | 隐藏说明 |

手柄（只在原型内，正式输入映射不变）：A 跳、X 攻击、B 闪避、长按 Y 恢复、LB / RB 切风格、Back 切换可能性不足、十字键上 投射物 / 左 受击 / 右 复活 / 下 八靶同时受击、Start 顿帧开关、按下左 / 右摇杆 顿帧缩短 / 加长；左摇杆移动与瞄准（上推向上攻击，空中下推向下攻击）。

靶子挨三下被击倒，1.6 秒后复原；每个靶子每 3 秒出现一次红色前摇警示（画在所有特效上层）。左上角的圆盘是 HUD 示意（画在最上层）。

## 三套风格

| 风格 | 笔触 | 时长 |
| --- | --- | --- |
| A 墨迹飞溅 | 纸色干笔弧线、朱红与纸色飞溅点、纸色笔触碎裂；闪避为横向墨痕，透支闪避为朱红断痕 | 最长（命中 0.40 秒，击倒 0.80 秒） |
| B 光痕 | 白芯加暖光的弧线、星形闪光、光点与光晕；闪避为发光残影 | 中等（命中 0.30 秒） |
| C 极简几何 | 细线弧、小叉、方框收缩、虚线圈 | 最短（命中 0.18 秒） |
| D 融合（用户首轮反馈后新增） | 攻击轨迹与命中用 A 的笔触，下面衬 B 的暖光、命中加一下暖光闪、飞溅浅色改为珍珠白；其余特效全部用 B | 攻击与命中同 A，其余同 B |

覆盖的特效：攻击轨迹（水平 / 上 / 下）、命中、靶子受击闪白、向下攻击弹起、投射物弹反、闪避（充足 / 不足）、无敌期间、可能性消耗、可能性获得、恢复（循环与完成）、玩家受击、靶子击倒、复活。

## 手感（用户首轮反馈后调整）

- 顿帧默认 0.10 秒（首版 0.07 秒，第一轮 0.12 秒，用户定稿普通攻击 0.10 秒），可用 [ / ] 现场调整；顿帧期间被打中的靶子左右抖动 4 像素。
- 第二轮：顿帧表现为“刀砍进去被肉卡住”——命中瞬间，这一刀的轨迹停在砍中的位置，与玩家、靶子一起停住，顿帧结束后刀光从卡住处接着扫完；没打中的挥砍不会被卡住。
- 屏幕震动幅度减半（命中 3 像素、受击 5 像素）；普通命中默认不震，留给以后的重攻击等效果，受击仍轻震。
