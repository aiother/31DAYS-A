# EXP-005 战斗反馈特效原型

只做原型，不接正式战斗逻辑、存档或输入映射。所有特效用代码绘制，颜色来自 UI-001 样式模块（`DuskStyle`、`InkDraw`），不依赖外部素材。

## 运行

双击 `run_preview.cmd`，或：

```
Godot --path game res://prototypes/EXP-005/preview.tscn
```

## 操作

| 按键 | 作用 |
| --- | --- |
| 1 / 2 / 3（手柄 LB / RB） | 风格 A 墨迹飞溅 / B 光痕 / C 极简几何 |
| H / V | 顿帧开关 / 屏幕震动开关（默认都开） |
| A D 或 ← →（左摇杆） | 移动 |
| 空格（手柄 A） | 跳 |
| J（手柄 X） | 攻击；按住 W / ↑ 向上，空中按住 S / ↓ 向下 |
| K（手柄 B） | 闪避 |
| 长按 L（手柄 Y） | 恢复；中途松开即中断 |
| P | 切换“可能性不足”，闪避变为透支闪避 |
| R | 最近的靶子射出投射物；攻击它可弹反 |
| T / Z | 受击 / 复活 |
| G | 八个靶子同时受击，底部显示之后 30 帧的帧时间 |
| F1 | 隐藏说明 |

靶子挨三下被击倒，1.6 秒后复原；每个靶子每 3 秒出现一次红色前摇警示（画在所有特效上层）。左上角的圆盘是 HUD 示意（画在最上层）。

## 三套风格

| 风格 | 笔触 | 时长 |
| --- | --- | --- |
| A 墨迹飞溅 | 纸色干笔弧线、朱红与纸色飞溅点、纸色笔触碎裂；闪避为横向墨痕，透支闪避为朱红断痕 | 最长（命中 0.40 秒，击倒 0.80 秒） |
| B 光痕 | 白芯加暖光的弧线、星形闪光、光点与光晕；闪避为发光残影 | 中等（命中 0.30 秒） |
| C 极简几何 | 细线弧、小叉、方框收缩、虚线圈 | 最短（命中 0.18 秒） |

覆盖的特效：攻击轨迹（水平 / 上 / 下）、命中、靶子受击闪白、向下攻击弹起、投射物弹反、闪避（充足 / 不足）、无敌期间、可能性消耗、可能性获得、恢复（循环与完成）、玩家受击、靶子击倒、复活。
