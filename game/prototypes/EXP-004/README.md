# EXP-004 对话界面与敌人介绍卡探索原型

只用于比较和挑选，不进入正式游戏；不改正式场景、共享脚本、`project.godot`、输入映射或存档，数据全是模拟的。视觉沿用 EXP-002 样张二与 UI-001 样式模块（只读引用）。任务卡：`codexandclaude/tasks/EXP-004/task.md`。

## 启动

双击本目录的 `run_preview.cmd`，或在项目根目录执行：

```powershell
& "D:\DMyself\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe" --path game res://prototypes/EXP-004/preview.tscn
```

画面右侧有按键说明，按 H 隐藏。截图见 `screenshots/`。

## 按键

| 按键 | 作用 |
| --- | --- |
| 1 / 2 / 3 | 对话方案 A / B / C（下一次对话生效，对话中按也会立即换样子） |
| 4 / 5 | G-08 呈现：1 对话一句 / 2 短提示 |
| 6 / 7 | 介绍卡方案 1 / 2 |
| T | 与 7 交谈（三句，含主角回应） |
| L | 离开麦秆镇：7 的一句后出现“留下 / 确认离开并放弃救助”，默认焦点在“留下” |
| K | 强制剧情（10 的两句，期间隐藏 HUD 示意） |
| M | 走到已错失救助的地方（G-08） |
| C / B / W | 普通敌人介绍卡 / Boss 名片 / 战场波次提示 |
| E / 手柄 RB | 一次：显示完整句子，再一次：下一句；按住：加快逐字 |
| Esc / 手柄 Start | 暂停（原型示意），对话与介绍卡停在原处，再按返回 |

## 对话界面三个方案

共同点（T7-C）：位于中上部；逐字显示；角色名在左下、白色加粗（B 为纸色字压在朱红名牌上）；E / RB 单击显示完整句子或下一句，按住加速（出现“»»”）；句子显示完后右下出现继续标记；最后一句后自动关闭；强制剧情隐藏 HUD；暂停时保持对话状态（T7-F）。救助离开确认用同一个对话框，两项选择、默认“留下”（A-020：确认后才放弃）。

| | A · 墨夜黑框 | B · 黄昏纸笺 | C · 黑纱纸边 |
| --- | --- | --- | --- |
| 底 | 黑色半透明矩形，底边一条细墨线 | 当日黄昏色纸笺、墨线描边 | 黑纱半透明，上下沿是撕开的纸边 |
| 字 | 纸色字 | 墨色字 | 纸色字 |
| 角色名 | 白色加粗，直接写在框内左下 | 朱红名牌、纸色字 | 小块墨色纸签、白色字 |
| 与 T7“黑色半透明” | 完全一致 | 不一致（选它需同步修订 T7-C） | 一致，多了纸边装饰 |
| 与其他正式界面（纸面、墨线按钮） | 最朴素，和纸面界面对比强 | 最统一 | 介于两者 |
| 在亮场景上的可读性 | 好 | 依赖纸色与背景的对比，最亮的场景略弱 | 好 |

## G-08 错失救助提示两种呈现

| | 1 · 对话一句 | 2 · 短提示 |
| --- | --- | --- |
| 形式 | 走到该处按互动后，对话框出现一句无角色名的旁白（灰一些的字），按键关闭 | 靠近即在原地上方出现小纸签“此处曾有人需要帮助 / 更早到来，或许还来得及”，约 4 秒淡出 |
| 打断操作 | 是（需按键） | 否 |
| 被错过的可能 | 不按互动就看不到 | 路过就能看到 |
| 与现有代码 | 现有临时文本就是走对话框，改动最小 | 需要在会话里加“靠近触发”，或复用 SYS-009 的交互对象查询 |

## 介绍卡两个方案

共同点：右上角，从右侧滑入，停留约 5 秒后滑出；暂停时停住；普通敌人小卡，Boss 名片大一号；**战场波次提示不再借用介绍卡**，改为画面中上一条独立的短横幅（W 键演示），让介绍卡只介绍敌人。

| | 1 · 纸签名片 | 2 · 墨条横幅 |
| --- | --- | --- |
| 形态 | 纸面卡片：朱红小字类别、大字名称、朱红短线、两行要点 | 一道干墨横条写名字，下接半透明说明块 |
| Boss | 朱红双框 | 横条右侧朱红竖印“首领” |
| 与对话方案的搭配 | 与 B 同一套纸面语言 | 与 A / C 的黑框更搭 |
