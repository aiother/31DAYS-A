# 沟壑第三间：清敌救助与珍珠灰盒

2026-10-16追加，制作人确认采用清敌救助灰盒。主场景world/ravine_depth_session.tscn。

## 本轮范围

HD_20001_3为1920×1536的紧凑多层Room，通过HD_20001_2右侧道路进入；有TileMapLayer地面、三段普通跳跃平台、两只既有无色实体（地面混合型及空中远程型）、一个幸存者及一枚珍珠占位。零可能性可以到达珍珠平台，实际攻击、敌人生命13与击杀+2沿用既有规则。仍沿用HD_20001_1_N001检查点，死亡与正常读档返回沟壑入口。

清敌后永久开启返回HD_20001_2与前往HD_20002_1的通路；下一间逃兵营帐尚未制作，仅展示阶段边界。已开启的通路不因敌人重置而关闭；敌人重置后重复击杀仍各+2。

单色实体、陷阱机关、秘密路线、正式美术和珍珠属性强化仍暂缓，火光与门栏仅为视觉占位；门栏通过出口逻辑限制跨Room，不添加未定义伤害。

## 清敌救助与成长

进入NPC可见区域Encounter（x320～1728，覆盖Room高度）记录看到幸存者。已看到NPC且消灭当前Room全部敌人，自动有效帮助该NPC；无需E对话，不扣资源。只剩一只敌人时不完成救助。未看到NPC就清敌，见到NPC后再结算。

本NPC一次奖励+4可能性及注视后的上限+1，不补满余额；先增加上限，再截断+4溢出。两位沟壑NPC都有独立来源，任意一位在注视后可使12→13，两位完成则14。首次注视前救助仅发+4并保存成长待结算状态，首次注视时统一结算12加已完成的独立NPC数；余额保持。上限15的第三位后续NPC仍未交付。

两端通路开启标志gate:HD_20001_3:cleared、救助完成及上限/+4奖励同一快照保存。写盘失败回滚这些变化，已经实际击杀获得的+2仍保留于运行状态；按E/RB或再次请求出口重试。重复结算、回访、死亡和读档均不能重复领取NPC奖励。永久失败后清敌仍能开门和领取敌人奖励，不能再领取NPC+4或成长。

存档版本仍为1，新增工程键rescue:HD_20001_3:seen/completed/failed，不补造正式Node编号。上限14要求注视及两个NPC来源；任一个NPC独立来源允许13；无注视的待结算帮助仍为10。拒绝完成/失败并存、缺少成长来源和未实现的15。兼容此前10/12/13槽，按槽隔离，新游戏重置。

## 撤回、死亡与珍珠

本轮用户明确允许清敌前确认永久放弃本NPC并撤回HD_20001_2，此为两端清敌条件的灰盒例外。取消不离开；确认且保存成功才撤回，保存失败回滚。撤回不会替代清敌永久开启通路，也不会改变麦秆镇或第二间救助；已放弃后仍可撤回。死亡或正常读档返回检查点不算主动放弃。

珍珠使用既有E/RB拾取及持久化组件，键keyitem:HD_20001_3:pearl_01独立于瓦砾塔珍珠。可在清敌前拾取；写盘失败回滚，回访/死亡/读档不重拾。本轮只保存拥有状态，不影响属性、资源、通路或救助条件。
