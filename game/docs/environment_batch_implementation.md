## 互动与持久化

靠近开关按E / RB，沿用现有互动Action；远处、暂停、剧情锁定、攻击中、恢复/闪避忙碌或受击无法控制时不操作。无需清敌、正可能性或额外物品。成功后立即关闭当前预警并停止/清除在途石块，提示“落石已永久关闭”。

每间独立保存`hazard:<ROOM_ID>:disabled`布尔事件，属于实现标识，不虚构T5.4正式Node。写盘成功才关闭，失败回滚事件并保留原活动状态与错误反馈，可再次按键重试。重复完成的开关不再写事务、不授予资源或成长。往返、死亡和正常读档保留；存档槽隔离，新游戏清除。旧槽缺少标记时默认陷阱活动，版本1格式兼容。

环境实际击杀沿原敌人defeated信号发普通收益：无色+2、单色+7、天人+11，不额外发机关奖励；负余额照常偿还，尸体/后续落石不重复发奖。沿用既有受击保护与敌人动作保护。

实现由`WorldRoom`读取可选配置并创建可复用组件，`ExplorationSession`统一绑定目标、交互和保存。组件及石块为`navigation_transients`子树，不向静态追击图添加开关或瞬时石块坐标；实心地图/平台、现有出口与敌种配置保持。全场景追击审计继续运行。
