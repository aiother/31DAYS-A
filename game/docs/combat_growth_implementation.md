## 保存与兼容

击败、BOSS_PASSAGE天窗/通路、HD_10004_1:combat_growth_claimed同次保存，成功后才启用强化、开放通路。失败回滚事件及能力，沿用胜利待存与E / RB重试，包括同帧Boss/玩家死亡优先保存胜利的既有规则。

旧档只要有BOSS_DEFEATED记录且未领取，正常读档或复活时自动补发，任何已开放检查点均适用；有无旧combat_growth_pending均可，成功会消费旧待领取标记。失败不提前授予范围，E / RB或后续保存可重试，不必重打Boss。缺少击败来源的孤立pending不授予强化；claimed必须有击败来源，不能与pending同时存在。仍用版本1的事件字典，旧档无需改数值字段。

死亡、读档、回访保留；换槽按来源重建，新游戏清除。与寄生同伴者闪避强化独立，可同时补发，两者不修改共享Resource。
