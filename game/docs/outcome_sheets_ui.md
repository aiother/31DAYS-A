# 死亡、结束与超时界面，暂停菜单返回标题（UI-005）

BL-050 / BL-051 落地，替换灰盒面板。所有“返回标题”都经 SYS-008 的 `return_to_title()`：先按现有规则保存，保存失败则不离开，错误画在当前纸面上。

## 结构

- `game/ui/menus/outcome_sheet.gd`（`OutcomeSheet`）：居中纸面——标题、说明行、墨线按钮、需要先问的选项（问句 + 确认 / 返回，焦点在“返回”且只在两者间移动）、纸面底部自己的错误行。按钮上下移动到两端停住，纸面外的控件拿不到焦点。每帧写入 `drawn`，标题、说明、问句、错误都取自绘制调用本身。
- `game/ui/menus/life_ui.gd`：死亡界面改为 `OutcomeSheet`（在暂停菜单之下，设置页可以盖在它上面）；`save_failed()` 在死亡纸面或最终战纸面打开时把信息画到纸面错误行，灰盒错误文字隐藏；暂停菜单“存档槽”换成“返回标题”。
- `game/ui/menus/final_battle_ui.gd`：最终战超时、第三日探索超时、V0.1 结局演出与结束都用 `OutcomeSheet`。`message`（隐藏的 Label）仍是会话写入的文字来源（结局保存失败提示），演出时同步到纸面。`slots_requested` 信号保留但不再发出（存档槽与新游戏由主界面提供）。
- `game/ui/menus/pause_menu.gd`：`show_title_confirm()`，确认页写“保存并返回标题？ / 下次从最近的检查点继续。”

## 各界面

| 界面 | 标题 | 说明 | 选项 |
| --- | --- | --- | --- |
| 死亡（A-014） | 你倒下了（朱红） | 满生命复活 · 可能性减半向下取整 · 负数清零 | 从检查点继续 / 返回标题 / 设置 / 退出游戏（先问“保存并退出游戏？”） |
| V0.1 结束 | 夕阳将至 | V0.1 灰盒结束、游玩时长 | 返回标题 |
| 最终战超时（A-011），有预算 | 未来已失（朱红） | 游玩时长、本次可恢复 mm:ss、重试规则 | 确认重试最终战（重新计时）/ 返回标题 |
| 最终战超时，原预算为 0 | 未来已失 | 游玩时长、第三日已结束无预算 | 返回标题 |
| 第三日探索超时（G-03） | 第三日时间已耗尽（朱红） | 返回当前检查点、恢复本日 30 分钟、保留进度 | 确认重试第三日（返回检查点）/ 返回标题 |
| 暂停菜单 | — | — | 继续游戏 / 设置 / 返回标题（先问）/ 保存并退出 |

- 死亡演出（边缘泛白后转暗）不变；纸面出现在全黑之上。死亡界面的“设置”打开正式设置页（UI-006），居中盖在死亡纸面上，返回 / Esc / Back 回到“设置”。
- 超时与结束界面打开时 Esc 不会穿过（沿用原有拦截）。
- 原先这些面板上的“存档槽 / 新游戏”和“保存并退出”移除：返回标题后在主界面选择（任务卡要求2～4）。
