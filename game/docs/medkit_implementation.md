# 应急药包拾取、使用与存档闭环

2026-10-18用户集中确认，接续fb18f80。实现一种固定消耗品，复用Q / Back映射；没有新增完整背包、随机掉落、商店、秘密路线、地形碰撞或敌人配置。

## 已确认规则

- 初始0个，携带上限3；每次消耗1个，立即恢复2生命，按生命上限5截断，满血和零库存不消耗。
- 地面与空中均可使用，不限制普通移动。攻击前摇/判定/后摇、闪避各阶段、L恢复、受击硬直、死亡、剧情、普通对话、离开确认和菜单中禁用。Q与攻击/闪避/恢复同帧输入时优先保留原动作，不消耗药包；长按Q不重复使用。
- 不增加无敌时间，不改变可能性、成长、珍珠、日期或敌人伤害。L恢复仍为原消耗3可能性、2.8秒恢复2生命。
- 四处固定补给各1个，靠近自动领取。背包满时保留现场物品，使用腾出位置后可再领；每槽每处仅领取一次，往返、死亡、读档不刷新已领补给。

## 保存与事务

版本1增加可选整数`medkits`，范围0至3。旧槽缺字段按0读入，不补发；新游戏为0。领取记录用`supply:<Room>:medkit_01`，四处独立。数量与记录分槽保存，死亡保留数量，不重复补给。已有珍珠与永久成长键不变。

领取先准备数量+1与领取事件，同次保存成功才隐藏物品；失败回滚数量与事件，原物品保留，停留范围内每0.5秒自动重试。使用先准备数量-1和恢复后的生命，屏蔽生命变化自动保存，完成一次统一写盘；失败还原生命、数量及HUD，须再次按Q / Back重试。满血、不满足状态或无数量时不写盘。错误沿用现有存档提示，成功后清除旧错误。

HUD徽记右侧药包纸签显示“× 数量”，操作提示纸签含“Q / Back 药包”（UI-002 起；此前为文字行“药包 数量 / 3 · Q / Back 使用”）；拾取/使用沿用已有进度通知，满包时现场提示“药包已满”。采用清楚的红白药包占位视觉，没有新增正式美术资源。
