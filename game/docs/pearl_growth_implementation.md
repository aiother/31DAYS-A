# 四处珍珠：永久近战范围强化

修订标记：2026-10-18，用户确认本版灰盒。覆盖此前四处珍珠“只拾取保存、不强化属性”的阶段记录。

## 效果与操作

沿用四个既有Room与E / RB手动拾取，每颗永久增加基础近战范围的5%。珍珠数量0/1/2/3/4对应100%/105%/110%/115%/120%；与渴望俯视的20%加算，全部获得为140%，不按1.2×1.2相乘。

左右、向上、空中向下共用倍率；攻击矩形尺寸及相对胸口(0,-48)的中心偏移一起缩放。四颗加Boss时左右112×72→156.8×100.8，偏移76→106.4；上下80×100→112×140，垂直偏移64→89.6。身体碰撞、物理移动不改变。

弹反共用扩大后的判定，左右/向上可弹反、向下不可弹反。占位攻击视觉沿用实际形状。每次起手取当时倍率，当前动作的形状保持；下次攻击读取新的永久来源，不修改共享Resource。

伤害仍5、前后摇/活跃时间、跑攻时序、0.5秒连击窗口、击退和下攻击弹起为最大跳高一半均保持。珍珠不增加生命、可能性、上限或日期，不需要Q使用；使用道具的输入仍只是预留映射，未追加消耗品、完整背包、武器成长、地图或收集点。

HUD徽记下方显示珍珠颗数、右侧纸签显示“范围 n%”（UI-002 起；此前为文字行“珍珠 n / 4 · 近战范围 n%”），拾取后反馈实际总倍率。`AttackConfig.pearl_range_bonus=0.05`为可调Resource参数，Boss原`enhanced_range_multiplier=1.2`保留。
