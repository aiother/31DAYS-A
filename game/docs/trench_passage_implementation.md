# 堑壕第二间与落石通道

修订标记：2026-10-16，制作人确认本轮灰盒规则。接通NSZC_10002_2；主场景world/trench_passage_session.tscn；Region_NSZC / Region_NSZC_Scene_10002。中心战场NSZC_10003_1仍为阶段边界，未增加NPC、成长或奖励系统。

## 场景与检查点

1920×2304纵向Room，下层入口(224,2048)自动记录正式检查点NSZC_10002_2_N001，写入失败回滚原检查点并支持旗帜旁E / RB重试。七段模块平台通向上层(896,944)，折返平台留足头顶净空；负9可能性也可普通跳跃上行。入口返回门在清敌状态成功保存前有实体碰撞，且出口逻辑再次检查条件。

两只单色实体（地面/空中各一）和两只天人战士（下层/上层各一）复用正式灰盒AI与进攻名额。击杀仍各+7/+11，环境击杀也通过同一奖励入口保存并按当前上限截断。往返、死亡和读档重置普通敌人，重复击杀仍有奖励，已保存的通路条件不因敌人重生撤销。

## 落石规则

RockfallConfig Resource配置三列固定落点x=1024/1248/1472；上层玩家进入区域后依次轮换，预警0.6秒，相邻生成间隔1.4秒（包含预警，不是额外再等1.4秒）。落石从y=600以700速度下落；地面y=944，列间和入口/末端保留安全等待点。落石不追踪玩家，走跳或等待即可通过，滑步不是必需能力。

FallingRock做32px宽扫掠碰撞，命中玩家/敌人扣1，碰墙或平台立即销毁；落石不可弹反，不可用普通攻击清除。伤害沿用玩家保护及敌人受击体系，垂直命中不被天人正面水平格挡。每颗只处理一次碰撞，多个落石不绕过玩家无敌保护。暂停冻结预警、下落与冷却；离开通道、玩家死亡或卸载Room会清理落石，不留延迟伤害。

必须先实际经过通道起点再到末端，才获得通过状态；从末端直接进入、跌落后绕路不算。清敌与穿越可按任意先后完成，二者都保存后碎石堆才允许受击。通过状态保存失败时保留本次已通过记录，可E / RB重试；死亡或卸载会丢弃尚未保存的临时记录。

## 碎石与永久保存

碎石堆10生命，使用Godot CombatHurtbox承受真实攻击，两次5伤害普通攻击可打碎。360px实体高度避免普通跳跃绕过；前路出口还会检查已保存标记。E / RB不替代攻击。部分受损生命不保存，未完成时读档/重置恢复10；打碎已保存后永久移除阻挡。

三项独立永久键：gate:NSZC_10002_2:cleared（返回通路）、gate:NSZC_10002_2:challenge（通道已通过）、gate:NSZC_10002_2:forward（碎石打碎并开启前路）。每次写入失败回滚事件；打碎请求保存失败时保留待保存状态，实体墙仍关闭且不重复计伤，E / RB可重试，无需再攻击。成功保存后才移除墙体。清敌保存失败同样可重试，不重复发击杀奖励。

返回第一间使用上层安全位置(1504,848)，不会立即回传。正式第二间检查点支持死亡满生命、可能性减半向下取整及3秒保护；正常读档无复活保护。第3日、首见、珍珠和待领取Boss成长按现有规则保持，不发通关额外奖励。
