# 沟壑第二间救助灰盒

2026-10-16追加。制作人确认本轮救助、成长与离开规则。主场景world/ravine_rescue_session.tscn。

## 空间与范围

HD_20001_2为1920×1280的小型多层Room，从HD_20001_1右上门进入；地面与三段平台可在零可能性下普通跳跃到达上层幸存者。按T5.3不放普通敌人，沿用入口HD_20001_1_N001检查点，返程落在入口上层安全位置。右侧HD_20001_3仍为阶段边界。未制作陷阱、机关、秘密路线、收集、额外敌人或新检查点。

## 救助与奖励

进入幸存者可见区域（Encounter：x320～1728，覆盖Room高度）记录见到NPC。靠近上层幸存者E / RB打开临时两句救助对话，玩家可移动，走远取消；暂停冻结文字。攻击/闪避/恢复中不能靠交互取消动作。完成对话免费救助，零/负可能性可用，不改变玩家生命。

同一NPC只发一次+4可能性。已有7的注视时上限12→13，先增加上限，再按新上限截断+4溢出；增长本身不补满余额。未获注视时先保存救助及+4，保持上限10；以后完成首次注视时，首次+2和本NPC待结算+1一起保存，上限10→13，余额不补满。重复救助/注视不重复发奖。本轮只开放这一位后续NPC成长，14/15仍未实现。

完成标记、上限和余额同一快照写入；失败回滚并保留末句重试。首次注视补发失败恢复旧上限及注视状态，保留此前独立完成的沟壑救助。运行值与共享基础Resource仍分离，死亡、正常读档、回访保留，槽位隔离，新游戏重置。

画面验证同步修复沟壑和麦秆镇幸存者的运行时多边形顶点格式：使用Vector2数组构建四角形，避免标量数组导致人物图形退化。受伤40px、站立80px及名字提示保持原设计，新增顶点回归。

存档版本仍为1，新增工程状态键rescue:HD_20001_2:seen/completed/failed；这些不是新编的正式Node编号。上限13要求已有首次注视及沟壑完成来源；拒绝完成与失败并存、无来源的13、未结算来源与上限矛盾、未实现的14/15。旧10/12上限槽兼容。

## 永久失败

见到NPC且未救助时，主动返回入口先显示永久放弃确认并锁定移动；取消恢复控制，确认并保存成功后才实际离开。保存失败回滚失败标记并保留确认。返程永久放弃只影响沟壑NPC，不改变麦秆镇任务。之后回来仅普通对话，无奖励或补救。

死亡和正常读档返回入口不算主动放弃。未实现的HD_20001_3边界不发生实际离开，因此也不放弃；待后续Room接通后，相同规则会覆盖该方向。
