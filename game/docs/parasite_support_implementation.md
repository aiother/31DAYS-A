ParasiteConfig参数：首次开战2秒后尝试、生成预警0.6秒，后续间隔6秒，最多同时存活2只。固定出生在玩家相对较远一侧、地面上方192px；紫色提示在出生前出现。支援立即感知玩家并追近，不在初始感知范围外待机；使用共享攻击名额，原13生命/击杀+2保持。

支援不是额外奖励：实际击杀才+2并自动保存，同一死亡实例不重复奖励；留出存活名额后可再次补充。只计算活着的无色实体，尸体和投射物不占生成名额。支援自己的普通投掷物保持原行为，不使Boss吸血。

暂停冻结预警和生成。首次演出、Boss击败、玩家死亡时不生成；死亡和胜利立即取消待生成、禁用支援Hurtbox并清理支援/投射物，不结算假击杀。重试从空场重新开始，Boss死亡后不再补充。Boss原连发/吸血/弹反、持久胜利、第3日及待领取强化保持。

test_parasite_support.gd覆盖默认参数、预警与暂停、飞行/远程/即时追击、存活上限、+2持久化及重复禁止、击杀后补充、死亡禁用/无奖清理/重试、胜利无奖清理与禁止再生成、首见阶段不生成。使用私有配置副本加速计时测试，不修改共享Resource或玩家存档。
