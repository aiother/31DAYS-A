# 10救场与协同战斗灰盒

修订标记：2026-10-16，用户确认“采用这版救场与协同灰盒”。主场景 `world/rescue_battlefield_session.tscn`，沿用 NSZC_10003_1，不增加地图或检查点。上一轮 `world/battlefield_session.tscn` 保留作首段独立回归。

## 三种触发共享一次救场

- 在入口安全区开战后，玩家首次即将受到有效致命伤：在扣血和死亡状态之前拦截，不消耗当前生命，不执行死亡结算。普通受击保护/闪避无敌先判断，无效命中不触发救场。
- 两批共2名幸存者均已到达，存活数严格低于50%：两名均倒下才触发；只有一名到达时不计算，1/2存活不触发。
- 前两种条件均未发生时，首段清空并等第二名幸存者到达后，生成2名天人+1只单色实体作为第二波兜底，立即触发救场。

友军损失检查延至当帧物理结束，允许同帧致命命中优先拦截。三种条件共用一个运行状态及永久事件 `NSZC_10003_1_N002`，不重复召唤10。`PlayerLife.hit_interceptor` 是可选的场景回调，默认无效，在既有无敌检查后、伤害与死亡结算前调用；离开中心战场即移除，不改旧Room受击规则。

## 演出与保存

10赤红占位、镰刀/锤几何视觉从天而降0.8秒，临时两句对话（E / RB继续、长按加速），随后全屏斩击/破碎线条0.35秒。对话和登场时间可在 `data/dialogue/ten_rescue.tres` 调校。正式美术、台词及播片尚未制作。

演出期间锁玩家控制并停止物理，终止现有敌人攻击/防御/闪避与投射物，冻结友军，暂停本场景的已玩秒数；菜单暂停也冻结演出。剧情清场直接击杀全部当前敌人，可覆盖闪避无敌、格挡及重击保护；它是显式剧情行为，不实装或模拟失衡值，也不放宽普通命中的打断规则。

演出完成时，将一次性事件和可能性补至当前上限作为同一保存事务。生命不恢复，不额外添加救场无敌。剧情清场不单独发击杀可能性，统一以这次补满结算，避免在事件提交前产生可重复奖励。保存失败则回滚事件与余额、保持冻结状态，显示E / RB重试；成功后才解锁并进入协同测试。演出完成前主动保存退出仍从原检查点加载、未完成演出可重播。

救场后刷新一轮2名天人+1只单色实体，与10共同战斗。幸存的原友军继续参与；本轮不额外生成未授权的新支援。正常敌人击杀沿用+11/+7与余额上限；清空只显示“10协同阶段完成”，保存当前资源，不写最终胜利、不开放最终返回门、不发成长。
