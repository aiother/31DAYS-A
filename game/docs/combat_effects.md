# 战斗反馈特效接入说明（FX-001）

正式战斗反馈按用户在 EXP-005 定稿的风格（2026-10-23，“D · 融合”）实现：攻击轨迹与命中用墨迹飞溅的画法，下衬暖光、命中处一下暖光闪、飞溅浅色为珍珠白；其余特效用光痕画法。全部由代码绘制，不依赖美术资源。规则依据 T2 §14（命中顿帧与屏幕震动）。

## 组成

| 文件 | 作用 |
| --- | --- |
| `game/effects/combat_effects.gd`（`CombatEffects`） | 画特效。每个特效一条记录：种类、位置、方向、寿命；循环特效（恢复中、无敌）在停止前一直存在。所有图元都经记录型辅助函数绘制，`drawn` 记录上一帧实际画出的内容，供测试核对 |
| `game/effects/combat_effect_director.gd`（`CombatEffectDirector`） | 挂在玩家场景 `Player/EffectDirector` 下，只读玩家与敌人的状态和信号，决定何时放哪种特效，并负责顿帧与屏幕震动 |
| `game/effects/hit_stop.gd`（`HitStop`） | 顿帧计数。被顿住的角色在自己的 `_physics_process` 开头调用 `HitStop.held(self, delta)`，为真时跳过本帧 |
| `game/effects/combat_effect_config.gd` + `default_combat_effects.tres` | 可调参数集中处：顿帧时长 0.10 秒、目标抖动 4 像素、普通命中震动 0、受击震动 5 像素、震动 0.2 秒 |

## 特效与触发

| 特效 | 触发（实际事件） |
| --- | --- |
| 攻击轨迹 `swing` | `PlayerCombat.attack_started`，按实际方向（水平 / 上 / 下）；跟随玩家 |
| 命中 `hit` | `PlayerCombat.hit_confirmed`，画在目标处，沿攻击方向飞溅 |
| 下攻击弹起 `bounce` | 向下攻击命中（每次攻击一次） |
| 投射物弹反 `reflect` | `hit_confirmed` 的目标是投射物，沿弹回方向 |
| 闪避 `dodge` / 透支闪避 `poor_dodge` | `PlayerPossibility.dodge_serial` 变化，按 `poor_dodge` 区分 |
| 无敌 `invuln`（循环） | 闪避无敌或受击 / 复活保护期间 |
| 可能性消耗 `spend` | 闪避或开始恢复 |
| 可能性获得 `gain` | `PlayerPossibility.gained`，画在来源位置（如击败的敌人）。余额被直接赋值不会触发 |
| 恢复中 `heal_loop`（循环）/ 恢复完成 `heal_done` | 进入恢复状态；完成且生命实际增加时收尾，中断只收起循环 |
| 玩家受击 `hurt` | `PlayerLife.damaged` |
| 敌人受击 `enemy_hurt` | 敌人受击区收到有伤害的攻击（任何来源） |
| 敌人击倒 `enemy_death` | 普通敌人的 `defeated`（任何来源） |
| 复活 `revive` | `PlayerLife.respawned` |
| 出招提示 `windup`（循环） | FX-002，G-07 视觉：无色、单色普通攻击、天人非重击进入前摇；珍珠白圈快速脉动 + 暖光短笔划指向出招方向 |
| 重击出招提示 `windup_heavy`（循环） | 单色强力攻击、天人重击、两场 Boss 进入前摇；朱红双圈 + 墨点 + 长笔划，Boss 按 2.5 倍绘制 |
| Boss 击败 `boss_death` | 两场 Boss 的 `defeated`；比普通击倒更大、更久（1.2 秒），朱红墨圈与大量珍珠碎片 |
| 增援入场 `arrival_enemy` / `arrival_ally` | 敌人或幸存者战士在所在 Room 已经运行后才加入（新波次、末波援军、保底实体）；敌方朱红、友方可能性青；Room 加载时就有的单位不播 |

可能性不足的提示由 HUD 的发红负责（A-018），世界里不再重复画；透支闪避本身用朱红残影表现。

玩家占位外观中被取代的灰盒反馈已移除：获得可能性的绿色扩散圈、闪避与恢复时整体着色、攻击判定框矩形。保留：受击变红、保护期闪烁、落地反馈、倒地与复活动作。

### 出招提示的时机（FX-002）

- 普通敌人的提示在 `attack_started` 信号上开始，和 SYS-011 的前摇提示音用同一个信号，因此同一帧出现；强 / 普通的判断与提示音一致（`strong_attack`、`attack_kind == HEAVY`）。
- Boss 没有该信号：导演的物理步排在角色之后（`process_physics_priority = 200`），每帧检查 Boss 是否进入前摇，于是在提示音的同一物理帧出现。
- 前摇一结束（进入判定、被打断、死亡、被移除）提示就收起；暂停与顿帧期间提示停在原处。
- 灰盒时代 `*_visual.gd` 中的前摇变色、方向线、强力圈，以及寄生同伴者的红色半透明圆已移除；渴望俯视落点上的橙色地面标记保留——它标出的是落点位置，不是“要出招了”的提示。

### 日期推进、最终倒计时与低生命

T6-D1 的这三项由 UI-002 的正式 HUD 负责，FX-002 核对后不重复做：换日纸签“第N日 / 末日前N天”与换日前 3 分钟提示、最终战中上部倒计时（加速与朱红警示）、最后 1 点生命的画面边缘朱红脉动（`game/ui/hud/formal_hud.gd`）。

## 顿帧

- 普通攻击命中敌人（三类普通敌人、两场 Boss）时，玩家与每个被命中的敌人各自开始一次 0.10 秒的顿帧；同一次攻击命中多个敌人，玩家只停一次（已在停时不重新开始、不延长）。
- 停住期间角色跳过自己的物理步：身体不动、所有动作计时不走，结束后从原处继续，不缩短也不重复任何阶段。命中当帧设下的速度（击退、下攻击弹起）保留到停止结束后生效。
- 这一下的攻击轨迹停在命中处，玩家与目标一起停住，目标原地抖动 4 像素，结束后放回原位、刀光接着扫完。
- 停住期间的按键不丢失：攻击进入攻击缓冲（相当于在命中那一刻按下）；闪避立即取消攻击，停止结束后执行；跳跃在停止结束后的第一帧生效。
- 不影响：其他敌人、友军、投掷物照常行动；日内时钟与最终战计时照常流逝（会话按物理帧计时，不经过角色）；暂停菜单打开时没有物理帧，顿帧一并冻结。
- 未命中、只弹开投掷物、命中碎石堆等非角色目标时不停。

新的角色类型如需顿帧，在 `_physics_process` 开头加 `if HitStop.held(self, delta): return`，并在 `CombatEffectDirector._is_enemy()` 中登记。

## 屏幕震动

- 普通命中不震（`hit_shake = 0`）；玩家受击震 5 像素、0.2 秒内衰减，偏移长度不超过设定值，结束后相机偏移恢复原值。
- 以后重攻击等大型战斗效果需要震动时，调用同一入口并定幅度；设置开关不在本任务范围内。

## 换成美术特效

每种特效是 `CombatEffects` 中的一个 `_种类名(entry, t)` 函数，`t` 为 0～1 的寿命进度。换成粒子或逐帧资源时，保留 `spawn()` / `hold()` / `stop()` 接口和触发表不变，只替换对应函数的画法；若改为子节点资源，仍需把实际显示的内容写进 `drawn`，测试依靠它核对。

## 验证

- 自动测试 `game/tests/test_combat_effects.gd`：真实玩家与敌人场景、真实输入和物理帧，覆盖触发、方向、顿帧时长与只停一次、计时冻结不缩短、其他敌人照常、暂停冻结、日内时钟照常、震动幅度、余额直接赋值不出获得特效、全部有限特效按时结束。
- 实机验收：`game/tests/acceptance/fx001_effects.gd`（通用 G4 启动器）。
