## 本次可试玩内容

- `debug/enemy_lab.tscn`是新的默认开发场景；同一种无色实体的地面/空中实例分别验证地面追击和空中远程攻击，不占用正式地图编号。
- 无色实体13生命，玩家普通攻击每次5，3次命中可击败；受击会短硬直、打断当前前摇/判定并实际击退。空中实体按命中方向移动。
- 感知范围与地形遮挡决定首次发现；发现后持续追击，直到目标离开当前场景。地面实例不跳跃，靠近悬空边缘会停止；空中实例可自由接近不同高度目标。
- 【2026-10-15 AI修复】混合型地面实体近身主动近战；投掷后有4秒冷却，间隙继续逼近，不再停在射程内连续投掷。取消近战等待玩家前摇/判定结束的门槛；玩家命中仍会打断敌人。纯远程配置保留原有出招节奏及射程内站位，不变成近战。不读取玩家精确生命值。闪避/恢复尚未实现，相关AI应对留到后续接入。
- 攻击有闪烁、方向线和占位提示音；前摇不命中，活跃帧开启实际判定，后摇不命中；同次近战对同一受击框仅命中一次。
- 非子弹投掷物沿出手时方向飞行；左右/上攻击可反弹，下攻击不反弹。反弹后反向飞行并受重力影响，短时间内落地/超时消失；对敌伤害5，不再伤害玩家；一次物体只反弹一次。
- 同时进入前摇/活跃攻击的敌人数有名额限制；灰盒暂设1，受击打断、死亡或进入后摇释放，未获得名额的敌人等待。
- 死亡保留简化碎块，无伤害/碰撞/AI；灰盒尸体上限6，超过上限的新死亡实例消失。重置场景清除尸体。

## 阶段边界

阶段记录更新（2026-10-15）：后续玩家生命/死亡阶段已接入实际扣血、受击硬直/保护及死亡重新挑战，见`player_life_implementation.md`。此前“仅命中计数”的阶段现已结束；计数只统计通过受击保护判断的有效命中。

敌人死亡仅发出一次`defeated(reward=2)`事件，可能性尚未记账，没有显示或发放实际资源；后续可能性系统订阅该事件。当前没有随机掉落、自动复活或生成波次。

`ColorlessConfig`为Resource；13生命、1点轻伤害、2点击杀收益事件来自T3。速度120、感知700、近战距离92、远程距离420、前摇约0.433秒、活跃0.12秒、后摇0.75秒、受击硬直0.30秒、投掷速度300以及攻击名额/尸体上限均为可调灰盒值，不新增策划冻结数值。

**2026-10-15前摇调校标记**：按制作人要求，近战与远程前摇均从0.65秒缩短1/3，采用原时长的2/3（约0.433秒，60Hz约26帧）。活跃判定、后摇、伤害和混合型投掷冷却不变。默认参数的实际状态转换测试分别覆盖两种攻击，允许一物理帧浮点边界误差。
