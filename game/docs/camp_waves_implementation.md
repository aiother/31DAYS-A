# 逃兵营帐第二间：多波次灰盒

2026-10-16追加；制作人确认采用本轮可调规则。主场景world/camp_waves_session.tscn。

## 范围与规则

HD_20002_2为1920×1536的小型多层场地，平地、两段模块化平台及营帐占位组成战斗空间。3波既有无色实体，数量2/2/3：首波两只地面混合型，第二波一地面一空中远程，第三波两地面一空中远程。13生命/伤害1/击杀+2与攻击名额1、尸体上限6沿用已有配置。

入口安全区不会开始波次；越过Encounter左边界x432（按玩家碰撞边缘检测）后，先以0.6秒橙色生成点预警，再生成首波。本波全部敌人被击杀后，间隔1秒，再预警0.6秒进入下一波。剩余敌人数只计算活着的ColorlessEntity，尸体和投掷物不阻止推进。动态敌人立即知道玩家位置，使用同一攻击协调器。波次结束清除残留投掷物；最终完成不额外发奖、不发成长、不永久记录清场。

数量/间隔/预警及三处生成点由CampWaveConfig Resource与data/world/camp_waves.tres配置。预警、波间计时和敌人均受现有暂停控制；玩家死亡后停止推进和待生成敌人。一次Room实例不会重复触发波次。

## 检查点、连接和保存

入口自动记录正式检查点HD_20002_2_N001，位置(224,1280)。不补充生命/可能性，不推进日期。写盘失败回滚选中检查点和旗帜显示，保留错误提示；靠近按E/RB重试。正常读档或死亡在此进入安全区。

【2026-10-17用户追加修订】两端改为本次三波全部完成后才能离开，覆盖原先“无条件通行”。从进入Room起（含入口安全区尚未开战）、生成预警、波次战斗和波间空场均封锁；左侧x112与右侧x1776各有贯穿可通行高度的实体屏障，同时会话层拒绝出口请求。最后一波最后一名敌人死亡进入COMPLETE后，两端一起开放：向左返回HD_20002_1的安全落点(2752,1280)，向右进入已接通的寄生同伴者。没有永久清场标记，回访后需要重新打完三波。

往返、死亡、正常读档均从首波之前重新开始，不保存波序、剩余敌人或计时。击杀得到的+2仍实时保存，允许重试/回访重复获取。死亡继续满血、非负余额减半向下取整/负数清零及3秒保护；正常载入保留资源、无保护。先前珍珠、救助、成长和日期不回滚。存档版本仍为1，只扩展合法检查点白名单；换槽隔离，新游戏重置。
