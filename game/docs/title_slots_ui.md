# 正式主界面与存档选择（UI-004）

用户在 EXP-003 选定的方案落地：主界面 **A · 黄昏远景**，存档选择 **1 · 书签**，每张书签上部加入方案 2 的**天空条**。替换此前启动时的灰盒选槽面板。数据与流程来自 SYS-008（`show_title()` 请求、`has_any_save()`、`slot_summaries()`），样式来自 UI-001（`game/ui/style/`），按钮沿用 UI-003 的 `InkButton`。

## 结构

- `game/ui/menus/menu_screen.gd`（`MenuScreen`）：两块全屏界面的共同部分。居中确认纸页（默认焦点在“返回”，打开时其余按钮不可聚焦）、底部一行提示、Esc / 手柄 Back / Start 返回、浅色墨线按钮 `LightInkButton`。每帧写入 `drawn`（实际绘制记录）供测试读取。
- `game/ui/menus/title_screen.gd`（`TitleScreen`）：黄昏天空、低垂的太阳与光晕、两层残破城市剪影、飘尘；标题“末日前31天”在上方 1/3 内居中；菜单在标题带之下居中。
- `game/ui/menus/slot_select.gd`（`SlotSelect`）：三条竖长书签并排，选中的升起 36 像素。四种状态各有样式（见下表）。
- `game/ui/menus/sky_strip.gd`（`SkyStrip`）：按槽的第几日与当日进度画天空渐变与太阳位置；只改心情色。
- `game/ui/menus/life_ui.gd`：`show_title()` 打开主界面；`show_slots(mode = "continue")` 打开书签（名称与无参数调用保留，暂停菜单“存档槽”与结束面板仍可调用）。两块界面在 LifeUI 最上层，打开时游戏暂停。

## 主界面

| 项 | 行为 |
| --- | --- |
| 新游戏 | 打开存档选择（新游戏模式），在选槽后确认 |
| 继续游戏 | 只在 `has_any_save()` 为真时出现，并且默认焦点在它 |
| 设置 | 打开正式设置页（UI-006，见 `settings_page_ui.md`），居中在变暗的主界面上；返回 / Esc / Back 回到主界面“设置” |
| 退出游戏 | 确认纸页“退出游戏？”，默认焦点在“返回”；确认后直接退出（没有会话需要保存） |

有会话时调用 `show_title()` 会走 SYS-008 的 `return_to_title()`（先保存再重载场景）。

## 存档选择

| 状态 | 书签 | 继续游戏 | 新游戏 |
| --- | --- | --- | --- |
| 进行中 | 天空条（当日黄昏与太阳位置）、纸色随日期；末日前31天、第几日与末日倒数、游戏时长、生命碎片（实心 / 空心到上限）、可能性与上限、珍珠、最后检查点 | 经 `start_slot` 进入 | 确认“将覆盖此槽现有进度” |
| 已通关 | 同上，天空为最深黄昏，盖朱红“已通关”印 | `start_slot` 拒绝（A-013），提示“游戏已通关”并停留 | 同上，覆盖确认 |
| 空 | 淡色书签、浅色空天空条、“空”与“没有存档 / 新的开始” | 提示“槽X是空的，请从主界面选择新游戏” | 确认（无覆盖提示，按钮为“开始”） |
| 无法读取 | 灰色天空条、划痕、朱红“无法读取”与说明 | 提示“槽X无法读取，可在新游戏中覆盖” | 覆盖确认 |

- 焦点：继续模式落在第一个进行中的槽，新游戏模式落在第一个空槽，都没有时落在槽一。左右键 / 十字键 / 鼠标悬停选择，Enter / 空格 / A 确认，向下到“返回主界面”。
- 关键色（生命朱红、可能性青、已通关印、日期朱红）是 `DuskStyle` 常量，不随槽的日期变化；只有天空条与纸色随日期变化。`drawn["cards"][i]["keys"]` 记录实际使用的关键色。
- 从游戏中打开（暂停“存档槽”、结束面板）时，返回按钮为“返回当前游戏”。

## 提示与错误

`LifeUI.save_failed()` 仍是唯一入口：主界面或存档选择打开时，信息画在界面底部的提示纸条上（书签之下、返回按钮之上），灰盒错误文字同时隐藏，不在书签后面露出；界面关闭后恢复原位置显示。说明“空槽 / 无法读取”的提示也用这条。1280×720 与 1920×1080 下，书签（含升起）、标题区、提示与返回按钮互不重叠且都在窗口内（`test_title_slots.gd` 逐一检查三个焦点位置）。
