# 区域名称与场景交互提示（UI-007）

BL-045、BL-049（A-019）落地。只读 SYS-009 的 `interaction_targets()` 与 Room 配置，不在会话脚本里加 UI 调用，不改交互范围与判定。

## 结构

- `game/ui/hud/area_banner.gd`（`AreaBanner`）：区域名称。
- `game/ui/hud/interact_prompt.gd`（`InteractPrompt`）：交互提示。
- `game/ui/menus/life_ui.gd`：在保存纸签之后挂载两者（位于所有菜单页之下，暂停、主界面、死亡与结束纸面都会盖住它们）。
- `game/world/items/room_pickup.gd`：关键物品高亮（`key_item()`、`highlight()`，与 SYS-009 的 `key_item` 同一规则：`keyitem:` 开头的拾取）。

两个节点每帧写入 `drawn`，测试读取。

## 区域名称

- 进入 `RoomConfig.scene_id` 与上一个 Room 不同的 Room（含读档后的第一个 Room）时，在画面正中显示 `display_name`：“ · ”之前为大字区域名（下有朱红墨线），之后为小字房间名；没有“ · ”时整串作大字。淡入 0.3 秒、共 2.6 秒、淡出 0.6 秒，底下一条半透明暗带。
- 同一区域内换房不显示。
- **等待**（尚未显示时）：暂停、普通对话（含离开确认）、剧情（`intro_active` 或剧情控制锁）、玩家暂时不可控制（受击硬直、倒下）、HUD 换日纸签显示、或名字会盖住可见的保存失败提示时，名字等待，条件解除后再显示。
- **让位**（已经显示时）：只有对话、剧情或新出现的、会被名字盖住的保存失败提示会让名字立即消失，且不再补显示；受击、换日纸签不打断已显示的名字。暂停时名字停在原处，返回后继续。
- **替换**：显示途中又进入另一个区域，直接换成新区域名。
- 没有存档会话（主界面）时不显示。

## 交互提示

- 从 `interaction_targets()` 中取 `available` 且 `in_range` 的对象，按与玩家的距离取最近一个（`unlimited` 视为距离 0）。暂停、普通对话、剧情锁中查询本身就报不可用，所以提示随之隐藏；只有 `retry_available` 的剧情保存重试不显示提示（它们有自己的文字）。
- 内容：朱红细框里的“E / RB”加动作名（拾取、交谈、开启……），一条细墨线指向对象。按键同时写键盘与手柄（现有代码没有“最近使用设备”的信号）。
- 位置：对象的世界坐标经相机换算到屏幕；玩家在对象右边就放在对象右上，在左边就放在左上（A-019“靠玩家一侧”），纸签底边在对象上方 120 像素，避开玩家头部。`unlimited`（如 Boss 成长补领）放在玩家头顶正上方。
- 避让：依次尝试“靠玩家一侧的上方 → 另一侧上方 → 靠玩家一侧的下方 → 另一侧下方”（不限距离对象：玩家头顶 → 玩家脚下），每个位置先限制在窗口内（边距 16），再核对不与以下任何一项相交：HUD 当帧实际画出的徽记、操作提示、底部地平线、余时警告、最终战倒计时、换日纸签，区域名称暗带，以及可见的保存失败提示。第一个都不相交的位置胜出；都不行时提示**让位不显示**，绝不盖住 HUD 或错误信息。
- 反色（A-019）：取场景底色的亮度——Room 提供 `base_color()` 时用它，否则用项目默认清屏色。暗场景用纸色底墨字，亮场景用墨色底纸字。现在所有 Room 都是暗色灰盒，所以显示纸色纸签；以后正式美术的 Room 只要提供 `base_color()` 即可自动切换。

## 关键物品高亮

`keyitem:` 开头的拾取物在地图上有金色光晕与呼吸圆环（帧时间驱动，暂停时随场景停住）；拾取后物体隐藏，高亮随之消失。普通拾取物不变。光晕与圆环由同一次绘制调用记录到 `RoomPickup.drawn`（`glow`、`ring`），测试读取。

## 已知与后续

- 灰盒自带的提示仍在：拾取物上方“E / RB · 拾取××”、落石开关提示、药包补给提示，以及右上角说明文字。它们由其他脚本绘制，且有旧断言依赖，本任务不动；正式提示与它们同时出现，后续可另立小任务统一移除。
- 部分 Room 的 `display_name` 仍是灰盒名（如“瓦砾塔Room2”“瓦砾塔Room3”），区域名称照实显示；改名属数据整理。
