## 第三日剩余与最终计时

本轮增加第三日剩余计时，不补做第一、二日自然半小时流程。旧档无记录时从本轮起按1800秒初始化，不倒推 `play_seconds`。最终战正式开战时取 `min(900秒, 第三日剩余)` 为本次预算；第三日已剩余不足15分钟时不会被延长。

可游玩且存活时扣时（开始后的最终计时也包含往返检查点的路程）；菜单暂停、剧情、倒地/死亡菜单不扣。普通死亡与读档不回补计时。常规资源保存、菜单读档/退出和死亡结算携带最新时钟；游玩中每0.5秒额外保存一次，不计算程序关闭期间的现实时间，异常中止最多可能丢失最近一次定时保存后的少量进度。

新字段 `day3_remaining`、`final_remaining`、`final_budget` 为有限非负数字，范围1800/900/900；剩余不得大于预算。JSON版本仍为1，可选字段兼容旧档。N004启动事件与预算保存为事务，失败锁住双方并E / RB重试，不提前开战。胜利与超时事件互斥；结局要求胜利对话，胜利对话要求胜利，最终战启动要求救场已保存。

最终时钟在本场景物理优先级-20推进、房间-10、角色0。按2026-10-19用户裁决A-012（DOC-006写入规格，SYS-003实施），归零和清波回调统一在当前物理帧末结算：只有最后一波已清场且原有两批增援到齐时，才优先保存胜利并清除超时标记。归零先处理或最后一击先处理结果一致；帧末检查真实敌人生命，覆盖房间先扫描、角色随后击杀的顺序。第一、二波同帧清场与归零仍为超时，不推进下一波。上一帧已经保存并显示的超时及读档恢复的超时不能由后续击杀改判；探索超时规则不变。

## 超时与明确重试

超时进入失败菜单并保存0剩余，不判胜利；正常读档仍显示失败。只有点击“确认重试最终战（重新计时）”才恢复本次开战预算并重置整场，第三日剩余至少恢复到该预算所需窗口；保留生命、可能性和成长，不重复救场或补满。重试保存失败不解锁、不改预算。明确重试直接进入中心战场入口，普通死亡仍返回堑壕第二间检查点。若开战预算本来就是0，不虚构新时间，只提供选槽/新游戏及退出。

## 永久胜利、对话与结束

三波清空（包括与归零同帧的最后清场，不含此前已判超时）→保存N005胜利；成功后停止两时钟、永久开放唯一返回路。失败保留等待状态，E / RB重试，未保存不开门；同帧零余量胜利保存失败也保持待重试胜利，不转为超时。真实回到堑壕及回访均保留胜利，不再刷最终敌人。

靠近10按E / RB执行标记为临时稿的胜利对话，完成保存N001后进入3秒文字/幕布占位演出。N006保存成功后显示V0.1结束屏，游戏控制锁定，可选槽/新游戏或保存退出。保存失败可E / RB重试；已完成结局的存档加载直接恢复结束屏，不重复奖励或开放自由操控。正式美术、镰刀锤动作、幸存者欢呼、夕阳伸手播片未制作，此处只验证流程。

## 2026-10-18实施修订：三日自然计时（用户已确认）

主入口接入每天30分钟自然流逝，第一日归零进入第二日、第二日归零进入第三日；物理时间推进，不计算离线时间。剧情事件取较晚日期，仅真正跨日时初始化新一天；自然日期已到达后，沟壑入口、寄生同伴者胜利、回访与重复检查点均不重复补时或倒退。菜单、剧情、普通对话、救助放弃确认、死亡动画/菜单停表；普通战斗和不锁操作的敌人首见卡片照常计时。

第三日尚未正式开战就耗尽时，显示独立探索超时反馈，明确确认后保存并返回当前检查点、恢复本日30分钟；保留当前生命、可能性和永久进度，不补满、不发死亡奖励，普通敌人重置。若最终战已经开始，继续原min(15分钟,第三日剩余)预算及既定重试规则，不赠送30分钟；死亡/读档不回补，最终胜利停表。超时/结束界面的Esc与通用继续入口不能绕过明确重试。

版本1存档增加可选day_remaining，day3_remaining和最终预算字段继续兼容。旧第一/二日档从本版采用时获得当前日30分钟，不倒推历史play_seconds；已有第三日/最终战计时原样保留。每0.5秒及跨日、检查点、资源、死亡、正常选槽/退出保存。剧情跨日事务失败回滚时钟；探索重试保存失败继续保持超时与0余量。

自然日期不会自动判NPC死亡/失救，不新增或强化敌人。NPC窗口、随日敌人变化与环境变体仍需具体规则，不能将当前时钟交付表述为这些内容全部完成。HUD显示日期/分秒，跨日中上部提示。本条覆盖先前“第一、二日自然计时尚未实现”的阶段记录。实施、字段和边界详见game/docs/day_clock_implementation.md；test_day_clock.gd与test_day_clock_session.gd已纳入全套验证。
