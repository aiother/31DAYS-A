## 当前体验

F5进入 `world/start_room_session.tscn`，选择槽的新游戏并确认。玩家从高处坠落，期间完全失控；落地后占位角色侧倒并起身，随后恢复操作。生命/可能性仍是3/3，坠落不额外扣血。起身后短暂显示移动/跳跃按键引导；玩家可自由操作。

场地按冻结配置为小型、开阔/垂直、平地，无敌人、NPC、平台挑战、隐藏物或能力门。灰盒只用地面、边界、简单岩壁和裂缝轮廓；正式美术、Spine、音效演出尚未制作。

`HD_10001_1_N001`（出生）、`N002`（移动引导）、`N003`（起始检查点）使用正式ID。出生和引导完成标志持久保存，正常读档及死亡复活不重播。菜单暂停同时冻结坠落/起身与引导计时。起身的1秒、提示的5秒是RoomConfig灰盒调校值，不新增策划冻结时长。

起始检查点自动记录位置，不补资源；死亡继续沿用满血、50%可能性向下取整（负数清零）、3秒保护。普通读档保留资源、从检查点进入且无保护。首次演出尚未完成时退出，再继续会从高处重新演出，资源不重复扣除。

向右的平地路线可以步行/跑步到达裂缝，不要求跳跃、滑步或资源。Connection目标仍为 `HD_10002_1`，无条件、可回访。本阶段只交付第一个Room，出口到达后显示阶段结束面板，返回可继续在本Room走动，往返出口可再次触发；未加载或伪造第二Room，右侧实体边界防止走入未交付空间。

## 工程与存档

- `world/rooms/hd_10001_1.tscn` 是可实例化的模块化Room，内部包含TileMapLayer地面、边界、检查点和出口。`RoomConfig` Resource记录身份、边界、目标Room与演出参数；检查点复用CheckpointConfig。
- `StartRoomSession` 复用既有玩家与检查点会话，子Room通过信号请求检查点或出口操作，后续可替换房间实例。单Room阶段尚未实现相邻Room异步预加载/卸载与跨Room切换，不声称已有完整分块地图系统。
- 正式Room试玩使用 `user://room_saves` 下3个槽；此前测试场地仍使用 `user://saves`，文件原样保留，F6运行 `debug/checkpoint_lab.tscn` 可继续。两类存档不自动互相转换。正式Room会拒绝不存在于本场景的检查点，避免错误传送。
- 出生/引导标志存于当前槽的events；未把其他Room、NPC任务、时间或成长算作已实现。
