# 寄生同伴者灰盒

2026-10-16追加，制作人确认本轮可调战斗参数。主场景world/parasite_session.tscn。

## 场景与战斗

HD_20003_1为1920×1792的纵向监牢，入口、三段普通跳跃平台及上方木板破洞形成通路。正式检查点HD_20003_1_N003自动记录入口(224,1536)，失败回滚并可E/RB重试。未击败时两端Boss锁；胜利保存后永久开启。下一地图NSZC_10001_1仍为阶段边界。

Boss使用ParasiteConfig Resource：80生命；连续3枚可弹反投射物，0.45秒前摇、每枚间隔0.12秒，后摇0.35秒后短暂移动换位（0.6秒、360px/s）再攻击。投射物速度380px/s，实际命中玩家扣1；仅生命真正减少时回复Boss3，不超过80。玩家受击/复活保护或闪避无敌、未命中、撞墙及弹反均不吸血。

左右/向上攻击沿用既有弹反，反弹命中Boss造成5伤害；下攻击不能弹反，同一枚仅反弹一次。通用投射物只增加可覆写的命中交付方法，默认行为保持；寄生投射物比较玩家命中前后生命，避免把Hurtbox接受通知误作实际伤害。回调保留Node2D类型引用，避免Boss与投射物脚本资源互相持有导致退出泄漏。

Boss没有血条，视觉仍独立占位。未增加接触伤害、抓取、回血以外的战斗系统或普通单色实体。Boss受击不打断既定连发，死亡立即禁用受击、隐藏视觉并清除投射物；玩家死亡也清除投射物，重试恢复Boss满血。

## 登场与持久胜利

HD_20003_1_N001首次进入播放5秒受限灰盒演出：Boss啃食姿态、尸体甩飞、轻微画面颤抖，T7沿用右侧滑入名称卡，不显示Boss生命条。演出前先保存检查点和首次标记；失败不启动，E/RB重试。首次标记死亡/读档保留，未击败重试直接开战。

击败后HD_20003_1_N001:defeated、通路HD_20003_1_N002、闪避强化待领取HD_20003_1:dodge_growth_pending及day=max(原日期,3)同次写盘。成功才显示木板落下、破洞及两端开放；失败回滚这些永久变化，保留内存胜利待重试，E/RB/保存或死亡结算可再次尝试。持续失败时阻止重新挑战丢失唯一胜利。双方同帧死亡的两种顺序均保留Boss胜利与已有死亡资源结算。

不额外发放可能性、属性、上限或直接修改闪避。强化具体效果未定义，本轮仅待领取标记；普通日期事件不实现自动倒计时。正常读档、回访、死亡保留已保存胜利和第3日，不重复推进日期。换槽隔离，新游戏仍从原起始区开始。
