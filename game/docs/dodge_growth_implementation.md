# 寄生同伴者：永久闪避强化

修订标记：2026-10-17，用户确认采用本版可调灰盒效果。覆盖此前“闪避强化仅待领取”的阶段记录。

## 效果与领取

击败HD_20003_1寄生同伴者并成功保存胜利后，自动永久获得闪避强化：地面/空中闪避速度720→900（+25%）。持续0.2秒不变，理想无阻挡主动位移144→180像素，实际仍受碰撞约束；资源不足滑步也使用强化速度，其较长前摇与较短无敌保留。其他前后摇、正常/资源不足无敌时间、连闪1/2/3成本、1.3秒重置、最多三连、-9下界、攻击取消与恢复取消规则保持原值。空中不悬浮、不重置跳跃，继续重力和正常落地。

PossibilityConfig新增enhanced_dodge_speed=900，保留dodge_speed=720。PlayerPossibility只保存本角色的dodge_upgraded运行时标记，速度取对应配置，不直接修改共享Resource或反复乘倍率。新游戏和未获得的槽始终使用720。

## 持久化与旧档

胜利、通路、第3日和HD_20003_1:dodge_growth_claimed同次写入；成功才启用强化并开门，失败回滚事件/日期和运行时能力，沿用原胜利E/RB重试。消费旧HD_20003_1:dodge_growth_pending标记，不与已领取同时保留。存档仍为版本1，以既有事件字典记录，不新增属性数值字段。

正常载入或死亡恢复时，具有Boss已击败记录且尚未领取的旧槽自动补发一次，在任何已开放检查点都适用；不要求返回Boss房间，不额外回血、补可能性或推进日期。补发保存失败仍使用720，保留原待领取/击败记录，E/RB重试或后续正常保存成功后启用900。重复读档、保存、回访不叠加速度，死亡保留；换槽/新游戏根据该槽记录重建能力。没有击败记录的孤立待领取标记不能授予能力。存档校验拒绝无Boss胜利的已领取记录，以及同时待领取/已领取的矛盾记录。

## 当前边界与验证

闪避强化阶段的能力门占位已由2026-10-17后续尖刺救助交付覆盖：80像素尖刺要求一次强化闪避，门内NPC救助可达上限15，详见outskirts_implementation.md。渴望俯视攻击范围强化已于2026-10-17后续交付，见combat_growth_implementation.md。
