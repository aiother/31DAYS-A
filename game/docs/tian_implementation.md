# 天人战士首轮灰盒

修订标记：2026-10-16，制作人确认先补天人战士，再实施堑壕第二间；本轮加入堑壕第一间两只战士及已编号首见介绍，不新增地图。主场景world/tian_session.tscn。

## 参数

| 项目 | 灰盒规则 |
| --- | --- |
| 生命 / 击杀收益 | 31 / +11，T3冻结值 |
| 普通移动 / 冲刺 | 300 / 600；冲刺0.16秒、冷却1.2秒，可受伤且无接触伤害 |
| 连击 | 2段与3段交替；每击1伤害，首段前摇0.25秒、后续0.16秒、每击判定0.12秒，整套后摇0.65秒 |
| 长距离重击 | 3伤害，前摇1.1秒、判定0.12秒、后摇1.2秒；最大选招距离180，独立扩展Hitbox |
| 远程投掷 | 1伤害、前摇0.4秒、弹速420、后摇0.55秒，沿用既有弹反5伤害与墙体碰撞 |
| 短瞬移 | 最远180、预警0.2秒、冷却4秒；检查整个墙体路径、沿途地面及落点；预警时可受击打断，落点再次验证 |
| 格挡反击 | 正面水平攻击可格挡一次，格挡0.25秒、冷却2秒；成功后尝试前摇0.35秒的1伤害反击，待反击标记最多0.9秒 |

数值由TianConfig Resource集中配置，攻击模式和Hitbox均为实例独有。轻、重、投掷按距离及固定节奏选择；近战连击数量2/3交替。每个连击段独立命中登记，但不绕过玩家受击保护。前摇锁定本段攻击方向，玩家可移动、跳跃、滑步规避；重击期间与后摇不能临时格挡。未新增霸体、削韧、破防成长或接触伤害。

格挡仅针对可见来源的正面水平攻击，在待机/追击/连击前摇中可尝试；上下攻击、背后攻击、重击或投掷前摇、判定、后摇及受击硬直均留下可攻击窗口。冷却与已格挡窗口内不能重复挡下新一击。格挡本身返回未命中，不通过扣血后回填伪装防御。【2026-10-16后续修订】普通命中仍扣血，但不再清除防御/待反击及反击动作；致死或未来显式失衡打断才清理，详见enemy_interrupt_revision.md。

## 群战与移动安全

两只战士分配相反侧站位，等待攻击名额时实际移动到玩家两侧；仍只共用现有1个进攻名额。连击前摇/判定期间持有名额，整套结束进入后摇时释放，另一只可接手。格挡取消连击前摇时释放名额，反击必须重新申请；名额占用时只能等待/调整站位，不能强制抢攻。决策不读取玩家精确HP；玩家死亡时取消动作、待反击并释放名额。

冲刺依靠CharacterBody2D碰撞移动；瞬移预警后对完整位移做形状扫掠，地面每不超过24像素采样，路径有墙或地面落点不安全则拒绝。预警中受击取消，不能借瞬移穿墙。没有新增自由传送、穿地或飞行单位。
