# 任务纸签与中央提示（UI-010）

## 左侧任务纸签

- 脚本：`game/ui/hud/quest_slip.gd`（`QuestSlip`，`LifeUI._quest_slip`）。
- 位置：左侧中部偏上 `(40, 450)`，宽 380，在 HUD 操作提示之下；可见的保存失败提示若与它相交，纸签移到其下方 12 像素。
- 内容：朱红小标题“救助”（取 `quest_state().title`），下面是当前目标（`objective`，去掉开头重复的“救助：”）；已完成 / 已放弃 / 已过期时标题右侧写状态（完成为成长金，放弃 / 过期为朱红）。
- 数据：读档（会话 `data` 换成新字典）或换 Room 时重新读 `quest_state()`，之后随 `quest_changed` 更新。进行中一直显示；三种结束状态显示约 6 秒（`SETTLED_SECONDS`，只在纸签可见时计时）后收起；无任务不显示。
- 隐藏：对话打开、剧情（HUD 被隐藏、`intro_active`）、暂停、死亡、未选槽。
- 暂停菜单的“当前任务”仍读 `quest_status_text()`，与纸签的 `objective` 同源（SYS-009 保证两者相同）。

## 中央提示

- 脚本：`game/ui/hud/center_notice.gd`（`CenterNotice`，`LifeUI._center_notice`）。
- 来源：
  - `quest_changed(kind, state)`：标题“救助开始 / 救助进展 / 救助完成 / 已放弃救助 / 救助已过期”，下行为目标文字。
  - `item_obtained(kind, display_name)`：标题“获得 · 名称”，名称与类别不同时下行写类别（珍珠、拾取、药包、成长）。
  - `FieldDialogue.show_notice(text)`：按“ · ”拆成标题与下行。
- 颜色（顶部色条与标题）：完成、获得为成长金，放弃、过期（及“失去”）为朱红，其余为墨色。标题用成长金时略加深，便于在纸上阅读；记录中的 `bar.color` 为原色。
- 表现：画面中上 560 宽纸签，淡入 0.25 秒、显示共 2.5 秒、淡出 0.5 秒。一次只显示一条，多条按到达顺序排队。
- 等待：对话、剧情、暂停、死亡时不显示，计时停住，之后接着显示。位置依次试 y = 236 / 380 / 500 / 640，取第一个不与 HUD 绘制矩形、对话纸笺、区域名称、交互提示、介绍卡、战场横幅、任务纸签、可见保存失败提示相交的位置；都不行时等待，不覆盖。
- **去重规则**：
  1. 1.5 秒内标题与下行都相同的第二条丢弃（同一事件不重复）。
  2. 1.5 秒内，`show_notice()` 文字与信号描述同一事件时合成一条：任务结束信号（完成 / 放弃 / 过期）与包含同一个词的文字；获得信号与以“获得”开头且含该名称的文字。合成后标题与颜色取信号，下行取文字的细节（如“可能性 +1 · 返回7”“可能性上限12”）。
  3. 其余各自成条，例如回 7 结算时的“救助进展”与“获得 · 泥粪中的理想家的注视”。
- 读档不补发：提示只来自读档之后的信号与文字。SYS-009 恢复时不发历史信号，界面也不在读档时根据 `quest_state()` 生成提示。
- 保存失败不出：获得信号只在写盘成功后发出。

## 接管灰盒

- `FieldDialogue.quest` 与 `notice` 两个 Label 保留为数据（会话照常写入，旧测试照常读取），放在隐藏的 `GrayboxModels` 节点下，不再显示。
- `show_notice()` 行为不变（含 UI-008 的暂停语义），另发 `noticed(message)` 信号给中央提示。

## 避让

- 任务纸签与中央提示加入 `LifeUI._protected_rects()`：区域名称、交互提示与 G-08 纸签让开它们。
- 战场横幅避让中央提示；中央提示避让战场横幅与任务纸签。
