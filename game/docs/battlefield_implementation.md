# 中心战场首段混战灰盒

修订标记：2026-10-16，制作人确认“先做这版首段混战”。主场景为 `world/battlefield_session.tscn`。从堑壕第二间已打开的出口进入 NSZC_10003_1，越过入口安全区（x=400）才启动敌人。

- 首段固定2名天人战士（31生命、击杀+11）、1只单色实体（21生命、击杀+7），复用现有AI、共享1个敌人攻击名额，以及重击/闪避/防御/反击保护和未来失衡打断接口。
- 第一名天人阵亡时立即加入1名幸存者，1秒后第二批再加入1名；仅触发一次，即使其余敌人快速清空，也等待第二批到达后才完成首段。暂停冻结间隔。
- 幸存者10生命、每次5伤害，实际寻敌、移动、攻击和受击；倒下后退出索敌，不发可能性。友军击杀敌人仍按原规则给玩家可能性并保存，不额外发通关奖励。
- 敌人接敌时在玩家及存活友军中选择最近目标；攻击已发动时保留方向，目标阵亡后重新选择，普通受击不因此获得打断重击的权限。玩家死亡时双方停止，清除飞行中的敌方投射物并取消待到达增援，防止死亡后继续刷资源。
- 友军受击层为64，敌人近战/投射物可以命中；玩家攻击查询敌人层16，跳过友军。友军攻击同样只结算敌人演员，不能击中玩家、友军或自动弹反投射物；受击入口额外拒绝玩家/友军来源。

可调参数：`data/allies/survivor.tres`，默认移动220、前摇0.3秒、后摇0.65秒、接敌距离90；增援间隔为 Room Inspector 的 `reinforcement_gap`，默认1秒。上述时序为本轮灰盒调校值，生命10/伤害5来自本轮明确授权。VisualRoot与GameplayRoot分离，当前绿色几何占位，后续可替换视觉。

首段完成显示阶段提示和场内文字；保存失败时按E / RB重试资源保存，成功后才确认提示。完成状态仅本次尝试有效，不写最终胜利、10救场、最终波次、时限、结局或成长事件。返回路仍保持完整战斗胜利门槛，首段不提前开放。可通过暂停菜单保存退出，读档或死亡回到既有 `NSZC_10002_2_N001`，敌人及增援重新开始；不新增检查点、NPC互动、道具或其他地图。

专项测试 `tests/test_battlefield.gd` 共36项：真实相邻Room进入、安全区、阵容/攻击名额、首名天人增援/暂停/去重、友军寻敌攻击、敌人实际打伤友军、友军死亡与重选目标、双方无友伤、重击保护、友军击杀收益、失败保存重试、阶段提示与最终事件隔离、正常读档与死亡复活。全量验证和交付包验证结果见随包报告。
