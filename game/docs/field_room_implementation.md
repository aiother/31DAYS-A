## 剧情、对话与奖励

TY_10001_1_N002：首次入场播放2秒可调短镜头，限制玩家动作、隐藏普通HUD，展示麦田和7；随后自动进入临时剧情对话。黑色半透明文字框位于中上部，角色名位于左下；文字逐字出现，E / RB推进，长按加速当前句显示。最后一句推进后自动结束，不另设关闭步骤。Esc可暂停，镜头、麦田、文字与进度都停止，恢复后接续。

完成剧情时将可能性补至当前上限10，生命与属性不变；剧情完成和TY_10001_1_N004恢复教程标记与资源写入同一存档。写盘失败回滚资源及标记，保持最后一句和受限状态供重试；成功后才恢复控制、相机和HUD，并自由显示6秒L / Y恢复提示。若剧情未完成即退出/死亡，重进可重播，但不会预先领取奖励。已完成后往返/死亡/读档均不重播、不重复补满。

TY_10001_1_N001：靠近7后E / RB主动交谈，普通互动保持自由控制；离开交谈范围自动收起对话。暂停不推进，完成互动保存记录，可重复交谈但没有额外奖励。DialogueConfig Resource管理临时稿、字符速度、首见时长及交互距离，全部台词明确标注为临时稿，未伪称正式剧情完成。
