# 营帐围攻封锁与敌人平台追击

修订标记：2026-10-17，制作人追加要求。

## 围攻完成前不可离开

HD_20002_2从进入起锁住两端，入口安全区、0.6秒生成预警、战斗及1秒波间空场都不例外；必须清完既有2/2/3三波才同时开放。实体屏障覆盖房间高度，不能从上层绕过；会话层也检查完成状态，不能单靠触发出口跳过。死亡、读档、回访仍重置本次围攻并重新封锁，检查点与击杀收益保留原规则，没有增加通关奖励或永久清场存档字段。

## 单色实体与天人战士跳跃平台追击

两类地面单位复用 `EnemyPlatformPursuit`。已发现目标且目标高于自身时，扫描本次跳跃范围内的实体平台顶面，选择接近目标的可达落点；落地后重新规划下一跳，因此可经中间平台逐级追上高处目标。视线受挡后沿用既有发现状态，不隔墙发现新目标。飞行单色实体保持原二维移动方式。

每个落点要求中心及左右27像素均有平整支撑，并通过完整角色碰撞体的逐步抛物线扫掠。头顶有实心平台挡住时，会尝试沿连续地面走出遮挡再起跳；高墙、过低顶板、过宽断崖或缺少落脚处会拒绝该路线，保留原碰撞与边缘保护。起跳后使用CharacterBody2D速度/重力/碰撞移动，保持落点方向直到落地，不用瞬移替代跳跃。普通受击/失衡或死亡清除追击计划，仍按既有打断保护规则处理；跳跃不会取消已开始的重击、防御或闪避来强行追击。

可调Resource参数：单色跳速850→950、天人新增跳速950，两者起跳冷却1秒；重力1900，理论跳高约237像素，并预留离散步进安全余量。可覆盖当前常见144～192像素台阶。单色240、天人300的基础水平速度及既有冲刺、攻击伤害、前后摇、格挡、闪避、共享攻击名额、生命与击杀奖励保持原规则。探测重规划间隔0.25秒，使用有限局部候选，不实现跨Room追踪或任意全地图寻路；没有连续可达平台时不会凭空升空。

## 验证

`test_platform_pursuit.gd`分别验证两类敌人真实落地到中间及目标平台、按实际物理步数检查实体连续移动、跳跃中暂停冻结位置/冷却、到达后留在平台、正上方实心平台的绕行起跳，以及高墙与不可达断崖保护。`test_camp_waves.gd`更新出口封锁/波间锁定/完成开放/死亡读档重置回归；原寄生同伴者测试也改为先完成围攻再进出Boss房间，原单色、天人、打断及最终战专项测试继续执行。连续新游戏主线测试也继续经过围攻，确认清完三波后仍能进入后续Boss与结局。

## 2026-10-17追加修复：下行追击

用户反馈敌人只会上行追击，玩家移到低处后仍停在高台。原因是原平台规划只接受高于自身的目标，低处目标沿用禁止越过边缘的普通移动逻辑。

本次给单色地面实体、天人战士增加安全下落路线：已发现目标低于自身48像素时，预测向两侧走到平台边缘、自然受重力下落和第一次落地的完整碰撞路径，优先选择更靠近目标的安全落点。需要时尝试较慢的水平移动以落到较窄平台；只在确认落点支撑后允许越过边缘。落到中间平台后继续规划，可逐层下降；玩家在正下方时会走出当前平台，低顶板也无需先向上起跳。保持CharacterBody2D碰撞，不穿透实心平台，不用瞬移/冲刺跨过断崖。

两类Config新增pursuit_max_drop=320像素（可调），单次下降超过上限、没有落脚处、路径撞墙或落点会明显低于目标时拒绝路线；每次落地重新计算，原上行能力及无效落点保护保留。地面尚未离开平台时，目标回到同层/高处会取消下行计划；受击/失衡/死亡继续使用既有打断接口。活动路线加3.5秒超时，避免环境变化后长期维持旧计划。暂停冻结移动与超时。飞行单位、战斗数值、共享进攻名额、奖励和地图不变。

新增test_platform_descent.gd，实际验证两类敌人的左右分层下降、正下方目标/低顶板、无瞬移连续位移、落地后恢复追击/战斗、暂停、无落点/过深落差、目标回同层取消、活动路线失衡打断，以及单独调整落差上限后的重新规划。原单色/天人测试不再把“存在安全低处地面时仍站在边缘”视为正确，改为验证自然下降与禁用不安全瞬移/冲刺；原上行测试继续回归。
