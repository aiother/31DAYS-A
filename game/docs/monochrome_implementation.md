# 单色实体首轮灰盒

修订标记：2026-10-16，制作人确认先补单色实体并放回已开放的堑壕第一间，不新增地图。本轮实现独立AI、配置、投射物和紫色视觉占位；复用既有物理碰撞、受击及攻击名额基础。主场景仍为world/trench_session.tscn。

## 参数与动作

| 项目 | 本轮值 |
| --- | --- |
| 生命 / 击杀收益 | 21 / +7，T3冻结值 |
| 追击 / 短冲刺速度 | 240 / 480 |
| 轻攻击 | 1伤害，前摇0.3秒、判定0.12秒、后摇0.45秒 |
| 强力攻击 | T3中等伤害2点，前摇0.8秒、判定0.12秒、后摇0.8秒 |
| 节奏 | 轻、强力交替；近身近战，距离合适则投掷 |
| 闪避 | 0.2秒，冷却2秒；自身生命严格低于1/3时冷却1秒 |
| 短冲刺 | 持续0.18秒、冷却1.4秒；冲刺本身可受伤、不造成接触伤害 |
| 地面跳跃 | 起跳速度850、冷却1秒，用于追击已发现的高处目标或越过矮墙 |
| 投掷物 | 速度380；轻/强力分别扣1/2；左右或上攻击弹反5伤害，下攻击不能弹反 |

21生命和+7收益不变，其余为可调Resource参数。2点攻击命名为“强力攻击（中等伤害）”，不改写T3重伤害3点的档位。角色每次攻击独立结算，同一攻击不重复伤害同一玩家。

## 防御与应对

观察实际玩家攻击起手信号：180范围内、垂直差不超过100、视线可见且攻击朝向本体时，在待机/追击/前摇中尝试后撤。可取消自身前摇并释放攻击名额；判定期、后摇、受击硬直和冲刺中不能用闪避取消。受击后仍可被压制；观察不到的攻击、朝向别处的攻击不会触发。决策不读取玩家精确HP。

闪避期间拒绝受击，结束恢复可受击；冷却从实际闪避发动时计算。预计退路碰墙或在地面越过平台边缘，则放弃闪避且不授予原地无敌。空中实例保留高度后撤。普通追击也会检查地面边缘；飞行实例可二维追击和短冲刺。没有额外闪避次数、削韧或成长系统。

沿用共享EnemyAttackCoordinator的1个攻击名额；前摇取消、受击、死亡和卸载会释放名额。每个实例复制攻击配置，长短前摇切换不会污染其他敌人或共享Resource。玩家死亡后停止进攻，暂停冻结动作与冷却。
