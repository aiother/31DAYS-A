首次清空当前Room敌人后永久开启返回通路；清敌后靠近开关按E / RB，永久开启前路。沿用入口检查点HD_10002_1_N002。该操作是本轮确认的灰盒机关，不增加谜题、道具需求或额外奖励。

未清敌时两条通路均拒绝通过；单独清敌不会开启前路。开关使用现有interact输入，距离88px内操作，暂停、攻击、闪避/恢复、受击或出生演出期间拒绝操作。平台与普通跳跃可达，不要求可能性消费。

持久键`gate:HD_10003_1:return`、`gate:HD_10003_1:forward`是工程实现标识，不伪称已冻结的正式Node编号。写盘成功后才算永久开启；失败回滚相应内存标志、保留关闭状态并显示保存错误，之后可重试。清敌保存失败时可重触返回口或在开关重试。

开启后往返、死亡、正常载入均保留。即使敌人重置仍可使用已经打开的通路。敌人照常重置，每次击杀仍奖励+2可能性，单个死亡实例不会重复结算。未开启的开关必须清除本次重置的敌人后才能操作。
