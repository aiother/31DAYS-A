# 玩家生命 / 受击 / 死亡阶段

2026-10-15，接续无色实体阶段。采用T3冻结数值；对照已填写T7的当前阶段死亡效果和菜单选项实施，不修改策划工作簿。

## 已实现

- PlayerLifeConfig Resource：生命上限5、开场3。敌人近战/投掷命中均通过PlayerHurtbox扣血；轻/中/重的1/2/3伤害以及环境1–2伤害沿用同一入口。
- 普通受击短硬直、轻微水平击退；硬直期间拒绝重复命中，不重复扣血、重置保护或叠加击退。灰盒硬直/保护时长0.25秒、水平击退上限180为调校值，非新增冻结数值。
- 受击被动打断当前攻击并清除连击与输入缓冲；这是受击中断，不开放主动跳跃取消攻击。受击硬直期间不响应移动、跳跃、攻击。
- 生命降至0后立即锁定操作，停止攻击判定，只处理必要下落；死亡只触发一次。无色实体停止攻击已死亡玩家。
- 1秒倒地，期间占位角色倒下、画面边缘泛白；之后0.4秒转黑，完成后显示死亡选项。0.4秒是灰盒表现参数，不替代冻结的1秒倒地时间。
- 按T7当前阶段选项提供重新挑战/退出。尚无正式检查点，按钮明确标为“重新挑战（灰盒出生点）”，避免把临时出生点称为存档点。
- 重新挑战重载本测试场景，敌人/尸体/投掷物重置；玩家出生位置复原、生命5、保护3秒、旧速度/攻击/硬直清除。保护期间主动攻击不解除保护。3秒后正常接受伤害。
- Esc暂停可在正常游戏和倒地阶段打开，暂停物理与死亡计时；设置提供音量、窗口尺寸和全屏，死亡菜单同样能响应鼠标/键盘/手柄UI导航。
- 实时生命数字、低生命颜色、受击闪色与保护闪烁反馈。视觉变形不改变物理碰撞体。
