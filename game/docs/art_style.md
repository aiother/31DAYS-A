# 风格说明（V0.1 M3）

ART-001。所有美术、音频素材都按本说明生产和验收；规格数值见 [asset_spec.md](asset_spec.md)。依据：`Words/T6_素材来源与规格决定.md` 第 3 节（画风方向，用户 2026-10-25 决定）、UI 样张二（`game/ui/style/dusk_style.gd`）、FX-001 / FX-002 特效。对照样张：`codexandclaude/tasks/ART-001/style_sheet.png`（由 `game/tools/art_style_sheet.gd` 绘制）。

状态：草稿，待用户定稿。

## 1. 一句话

**墨迹、纸色、黄昏暖光**：手绘墨线勾出的平涂形象，站在纸色的废土上，被一侧的低角度暖光照亮。

## 2. 线条

- 深墨色（`#2b2420`）轮廓，略带手绘抖动，起笔、收笔与转折处粗细有变化；不用等宽、干净的矢量线。
- 外轮廓比内部结构线粗约一倍（1080p 下外轮廓约 3 px、内部约 1.5 px，交付图按 2 倍画）。
- 远景几乎不勾线，中景细线或只勾上沿，近景与角色完整勾线——越近线越重。

## 3. 上色

- 平涂为主，每个色块最多一层亮面、一层暗面；少量水墨晕染（边缘渗开）与纸纹，只用在衣物大块面与背景。
- 不做厚涂、不做写实光影、不做渐变高光。
- 角色固有色饱和度低（取色板里的纸色、墨色、灰褐），只在标志处用强调色（见第 6 节）。

## 4. 光

- 主光：黄昏低角度暖光，固定从画面**左侧**来（与样张一致；角色镜像时边光跟着形象一起镜像，不另做）。
- 亮面带一条**暖色边光**（日光 `#f4b860`），宽约轮廓线的 1～2 倍。
- 暗部偏**冷紫**（黄昏顶 `#7d4a8c` 低透明叠在固有色上），不用纯黑压暗。
- 田野白日场景光更平、边光更弱；逆时战场有远处战火的暖红补光。

## 5. 色板与明度

色板与 `DuskStyle` 一致（样张右上）：

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨 INK | `#2b2420` | 轮廓、暗部 |
| 珍珠白 PEARL | `#fbf6ec` | 高光、飞溅浅色 |
| 白日纸色 | `#efe4cc` | 田野、日间底色 |
| 黄昏纸色 | `#f0cfb6` | 荒地、黄昏底色 |
| 黄昏顶 | `#7d4a8c` | 天空上部、冷暗部、单色实体 |
| 黄昏底 | `#f0a050` | 天空下部、暖光 |
| 日光 | `#f4b860` | 边光、暖高光 |
| 生命红 | `#b8382c` | 生命相关；角色上只用于小面积标志 |
| 可能性青 | `#2f8f88`（光晕 `#9fe6d6`） | 只给可能性；角色与场景不用 |
| 成长金 | `#d9a03a` | 成长、奖励、天人装饰 |

- **明度分离**：角色整体比所在背景暗至少两档（轮廓深、远景浅而淡），战斗中一眼能把角色从背景里分出来；远景对比度最低。
- 生命红、可能性青、朱红警示属于 UI 与特效的信号色，不做角色或场景的大面积底色，以免与特效、HUD 混淆。

## 6. 角色形象要点

各角色一眼可分，并与 FX-002 的敌人特效语言一致（用户 2026-10-25：敌人表现要体现各自特性，不借用玩家的样子）。

| 角色 | 形象要点 | 标志色 |
| --- | --- | --- |
| 玩家 | 人形，纸色衣物、深墨轮廓；一条红色围巾尾（唯一的生命红大面积用法，用作玩家识别）；初始武器为单刃短刀 | 纸色 + 围巾生命红 |
| 7（泥粪中的理想家） | 人形，200%；劳作者，衣物沾泥，纸色偏暖褐 | 暖褐 |
| 10（镰刀与锤的抗争者） | 人形，200%；战士，持镰刀与锤，姿态挺拔 | 墨 + 珍珠白高光 |
| 幸存者、幸存者战士 | 人形，80%；破旧纸色衣物，战士多一件简单武器；同一母版换色与配件 | 灰褐 |
| 无色实体 | **没有自己的颜色**：墨块剪影，边缘渗墨下滴，形体不稳定；只有一点珍珠白的“眼” | 墨 + 珍珠白一点 |
| 单色实体 | 瘦长、棱角，适合冲刺；墨色躯体只用**一种**强调色（黄昏顶紫）勾边或作纹路 | 紫 |
| 天人战士 | 有甲胄感的墨色人形，**金色装饰**（冠、护肩），持长兵器 | 墨 + 成长金 |
| 渴望俯视（Boss） | **悬空的巨眼**：墨色团块中间一只眼，生命红虹膜，下方垂落墨丝；250% | 墨 + 生命红虹膜 |
| 寄生同伴者（Boss） | 以**口与触须**为标志的寄生体，暗红（`#6e1f3a`）与墨色；会吸取可能性；250% | 暗红 + 墨 |

- 可选附加骨骼：玩家用 `cloth_1…3`（围巾尾）；10 用 `cloth_1…2`（衣摆）；其余不用。
- 同一角色的所有图以**已确认的设定图**为参考（见 asset_spec.md 第 6 节一致性检查）。

## 7. 场景

| 区域 | 天空 | 地面 / 主体 | 远景 | 情绪 |
| --- | --- | --- | --- | --- |
| 荒地 HD | 黄昏顶紫 → 黄昏底橙 | 黄昏纸色地面，灰褐瓦砾 | 淡紫废墟剪影 | 荒凉、余温 |
| 田野 TY | 淡蓝 → 白日纸色 | 白日纸色，麦金色田块 | 远山淡蓝灰 | 平静、短暂的喘息 |
| 逆时战场 NSZC | 低饱和暗红褐 → 战火橙 | 灰褐地面，烟尘灰 | 远处战火暖光与烟柱 | 压迫、混乱 |

- 背景分远、中、近三层视差；远景低对比、几乎无线，中景细线，近景与地面完整勾线。
- 地形瓦片由代码绘制：墨线上沿 + 纸色填充 + 区域主色，与样张地面一致。

## 8. 音频风格

- 整体：干燥、近距离、少混响；废土的空旷感来自环境音而不是给每个音效加大混响。
- **可能性音效**是标志音色：清亮的玻璃 / 风铃质感，带轻微倒放尾音，与可能性青呼应；获得上行、消耗下行、不足为闷住的短音。
- 战斗音效：短、干、有木 / 金属质感，命中比挥空重；敌人前摇提示保留 SYS-011 的音高区分（强力 / 重击更低更长）。
- 环境音：荒地 = 风声、碎石、远处低鸣；田野 = 麦浪、虫鸣、远处风铃；逆时战场 = 远处炮火、人声嘈杂、金属撞击。
- 音乐：废土、黄昏、东方墨色，少量民族乐器（如二胡、埙、古琴拨弦）；探索舒缓、普通战斗有推进感、大型战斗加打击与合唱感。
- 响度与格式见 asset_spec.md 第 5 节。

## 9. 不做什么

- 不做像素风、赛璐璐厚涂、写实材质。
- 不给敌人用玩家的配色或特效语言；不让可能性青出现在可能性以外的地方。
- 不重做 FX-001 / FX-002 的特效。
