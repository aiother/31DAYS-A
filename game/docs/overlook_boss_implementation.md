## 本轮用户确认的可调规则

60生命、命中扣1，循环纵跳落击和高空悬停。落击前0.6秒显示地面范围，落点在提示开始时锁定，不持续追踪玩家；落地只结算一次范围攻击。命中走现有玩家Hurtbox/Life，滑步无敌、受击保护和复活保护继续生效。没有额外接触伤害、投射物、削韧或吸血。

悬停时召唤3层固定平台，普通跳跃可达，能够跳跃攻击高空Boss；同一场战斗不累积召唤数量，平台保持至战斗重置，避免平台消失使玩家掉落。战斗重置清除召唤平台；胜利后重新进入保留通路所需平台。悬停8秒、落击后摇1.2秒、飞行速度与平台坐标均为本轮可调灰盒参数，非最终平衡数值。数值由OverlookConfig Resource管理。

占位身体240px高，为96px玩家视觉高度的250%，符合T6比例。不显示Boss血条（T7明确要求），受击闪白，不擅加普通敌人的+2奖励。视觉在VisualRoot，战斗判定、状态、移动由Godot代码控制，未来可替换Spine。

## 登场、检查点与连接

入场自动激活正式编号HD_10004_1_N003，保存失败回滚检查点并允许E / RB重试。首次登场先保存观看标记，再限制玩家操作；镜头向高空、回到玩家、Boss落下后开战，末段轻微震动，随后清除相机偏移。名称名片从右侧中上部滑入，展示5秒，沿用T7的最新呈现要求。暂停冻结演出与战斗。

玩家死亡而Boss未击败，回到本Room入口，Boss恢复60生命、召唤平台清除；首次演出不重播。普通载入同样重置未击败战斗，但保留玩家实际资源且不授予死亡保护。正常跨Room不改写玩家资源。

未击败时前后两连接均锁定。胜利保存击败状态、HD_10004_1_N002通路事件及战斗成长待领取标记，开启头顶天窗与金光、永久开放前后连接。成长本轮仅记录，不修改属性、不提供领取界面、不伪称成长系统完成。Boss不重复生成或发奖，死亡/读档/回访都保留胜利。

玩家与Boss同帧死亡也保存Boss胜利：待写入胜利与死亡结算写入同一快照。写盘失败不显示永久开放，保留待重试状态；E / RB、再次保存、死亡重试或保存退出会重试，持续失败时阻止重载丢失内存中的胜利，退出菜单也不会关闭游戏。恢复写盘后再开放通路。存储版本仍为1，仅扩大合法检查点白名单，旧槽兼容。
