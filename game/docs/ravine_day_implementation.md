# 沟壑入口与第二日事件灰盒

2026-10-15追加；制作人确认“采用这版入口灰盒”。主场景为world/ravine_session.tscn。

## 本轮范围

从麦秆镇右侧悬崖实际进入HD_20001_1（荒地巢都·沟壑入口），可双向往返。2560×1536的Room使用TileMapLayer地面、中央高台和模块化上行平台；低处提供现有无色实体供下攻击弹起练习，上层复用空中纯远程配置。两只均为既有13生命/+2可能性规则，重载后可重复击杀领奖。主路不要求消耗可能性或依赖敌人弹起。右上通往HD_20001_2的门仍是阶段边界，不生成后续地图。

入口自动记录正式检查点HD_20001_1_N001，位置(224,1280)。死亡从此复活，生命、可能性减半向下取整及保护遵循现有规则。检查点写盘失败时不点亮旗帜，保留原检查点，靠近按E/RB可重试。

## 日期和存档

存档新增整数day（1～3），版本仍为1；旧槽缺少字段时按第1日载入。HUD显示当前日期，不显示尚未实现的倒计时。

激活沟壑检查点时，若7的首见剧情已完成（TY_10001_1_N002），日期取max(当前日期,2)。重复激活不加天、不重复写盘；第3日不回退；未完成剧情只记录检查点而不推进日期。检查点、Node事件和日期同一快照写入，失败全部回滚。正常读档、死亡和回访均保留日期；新游戏从第1日开始。与上限12的注视成长、分槽隔离和旧槽兼容。

未救助时，从麦秆镇进入沟壑同样先显示永久放弃确认。取消不改变任务；确认且保存成功后才离开，写盘失败保留确认。死亡/读档仍不算主动放弃。麦秆镇对话范围检测已排除离开确认，避免确认框被自动关闭。

test_ravine_day.gd覆盖真实跨Room连接、零可能性平台跳跃、实际下攻击伤害/弹起、重置敌人重复奖励、死亡/读档、日期幂等及单调、旧槽、非法日期、事务回滚与E重试、实际离开确认、永久成长和新游戏。测试只使用隔离目录。

本轮没有自动半小时计时、超时结算、离线时间或日期敌人强化；这些仍需规则落实。单色实体、陷阱/机关、正式美术/Spine及HD_20001_2后续内容未制作。橙色火光仅视觉占位，无伤害判定。

## 2026-10-18实施修订：三日自然计时（用户已确认）

主入口接入每天30分钟自然流逝，第一日归零进入第二日、第二日归零进入第三日；物理时间推进，不计算离线时间。剧情事件取较晚日期，仅真正跨日时初始化新一天；自然日期已到达后，沟壑入口、寄生同伴者胜利、回访与重复检查点均不重复补时或倒退。菜单、剧情、普通对话、救助放弃确认、死亡动画/菜单停表；普通战斗和不锁操作的敌人首见卡片照常计时。

第三日尚未正式开战就耗尽时，显示独立探索超时反馈，明确确认后保存并返回当前检查点、恢复本日30分钟；保留当前生命、可能性和永久进度，不补满、不发死亡奖励，普通敌人重置。若最终战已经开始，继续原min(15分钟,第三日剩余)预算及既定重试规则，不赠送30分钟；死亡/读档不回补，最终胜利停表。超时/结束界面的Esc与通用继续入口不能绕过明确重试。

版本1存档增加可选day_remaining，day3_remaining和最终预算字段继续兼容。旧第一/二日档从本版采用时获得当前日30分钟，不倒推历史play_seconds；已有第三日/最终战计时原样保留。每0.5秒及跨日、检查点、资源、死亡、正常选槽/退出保存。剧情跨日事务失败回滚时钟；探索重试保存失败继续保持超时与0余量。

自然日期不会自动判NPC死亡/失救，不新增或强化敌人。NPC窗口、随日敌人变化与环境变体仍需具体规则，不能将当前时钟交付表述为这些内容全部完成。HUD显示日期/分秒，跨日中上部提示。本条覆盖先前“第一、二日自然计时尚未实现”的阶段记录。实施、字段和边界详见game/docs/day_clock_implementation.md；test_day_clock.gd与test_day_clock_session.gd已纳入全套验证。
