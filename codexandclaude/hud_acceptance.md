# HUD-001 人工验收（约 3 分钟）

在正常 PowerShell 中粘贴下面一条命令。工作目录和工具均使用明确绝对路径，不需要打开 Godot 编辑器，也不需要制造真实磁盘错误：

```powershell
& 'D:\DMyself\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe' --path 'D:\31days\codexandclaude\worktrees\codex-review\game' --script 'D:\31days\codexandclaude\worktrees\codex-review\codexandclaude\tools\capture_hud_preview.gd' --rendering-method gl_compatibility -- --interactive
```

这是独立验收预览：使用真实游戏 UI，但固定恢复中状态以便观察五行 HUD。角色不移动、恢复计时不前进是预览的设计，不是游戏故障。橙色“存档写入失败”是模拟提示；自己的测试存档关闭时清理，不使用玩家正式存档。

按下面检查：

1. 初始 1280×720：五行白色 HUD 和橙色提示均完整可读，彼此不重叠，长提示会换行。
2. 按 Esc 打开暂停菜单，用鼠标点击“设置”。在“窗口尺寸”中选择 1920×1080，点“返回”，再点“继续游戏”；观察文字仍完整、不重叠。若屏幕放不下该窗口，直接使用下一项全屏检查并如实记录本项限制。
3. 再按 Esc → 设置，勾选“全屏”，返回并继续；观察文字没有被裁切、遮挡或挤在一起。之后回到设置取消全屏，确认能正常返回窗口。
4. 再用键盘方向键/Tab 移动菜单焦点，Enter 激活；检查暂停、设置和返回可操作。音量或窗口选项不应导致卡死。此项是在验收既有菜单能否继续使用，不要求新增导航功能。
5. 如有手柄，用 Start 暂停、十字键/摇杆选择、确认键进入和返回；如无手柄，记录“无设备，未测试”，不能记为通过。
6. 关闭验收窗口即可结束。不需要在存档槽新建存档，也不需要进行战斗或修改工程。
