# SYS-011：音效事件框架与占位音

状态：待批准（2026-10-23 起草）｜级别：L｜实现：Codex｜审查：Claude
工作区：worktrees/codex｜基线：本任务卡合入后的 master 最新提交（实现者在交付记录中写明完整 SHA）｜依赖：无（不需要正式音频资源）；与 FX-001 并行（见“与 FX-001 的分工”）

## 目标

完成待办 BL-066 的系统部分：建立统一的音效与音乐接入层，让游戏里需要声音的动作都经同一个入口发出事件。先用程序生成的占位音跑通，以后用户提供正式音频时，只需替换资源文件，不改玩法代码。同时补上 G-07 中“敌人攻击前提示音”这一半。

## 依据

- 待办 BL-066。
- T6-D2 音效音乐表：
  - 移动、战斗、受击、死亡、交互音效为 C 级，允许临时占位；可能性音效为 A 级。
  - 三个 Region（荒地、田野、逆时战场）各有环境音，均为 A 级；探索、战斗、大型战斗音乐为 B 级，剧情音乐为 C 级。
  - T6-E：同类行为优先复用音效。
- T7-D：基础 UI 音效方案；T7 核对表 G-07：T2 §14 的“攻击有闪烁特效与音效提示”。
- A-017 设置：效果音与背景音分开调节；总线已有 `Master`、`效果音`、`背景音`（`game/default_bus_layout.tres`，SYS-007）。

## 现状（起草时核对 master@f6de02f）

- 没有外部音频资源。
- 占位声音只有两处：`game/core/utilities/graybox_audio.gd` 的警示音，和 `game/player/placeholder_visual.gd` 由 `combat.hit_confirmed` 触发的命中音（`_hit_sound`）。
- `game/systems/audio/` 目录为空。
- 没有音乐与环境音，也没有 UI 音效。

## 要求

1. **事件入口**：一个全局可用的音效服务（例如 `AudioEvents.play(&"event_id", position)`），事件名到音频资源的映射集中在一个资源里。缺资源时静默或退回占位，不报错。同类行为可以共用一个资源（T6-E）。
2. **事件清单**：至少覆盖以下事件，并接到现有信号或状态上。只读现有状态与信号，不改判定、数值与时机。
   - 移动：跳跃、落地、重落地；脚步可选。
   - 战斗：挥击、命中、投射物弹反、天人格挡。
   - 受击：玩家受击、敌人受击。
   - 死亡：玩家倒地、普通敌人击倒、Boss 击败。
   - 可能性：获得、消耗、不足、恢复开始、恢复完成。
   - 交互：对话推进、拾取（珍珠、药包）、机关与门。
   - 敌人攻击前提示音（G-07）：三类普通敌人进入前摇时发出，与现有灰盒视觉警示同时；Boss 若有前摇警示也接入。
   - UI：焦点移动、确认、返回。
3. **音乐与环境音**：
   - 按区域切换环境音槽：荒地、田野、逆时战场。
   - 按状态切换音乐槽：探索、战斗、大型战斗（Boss 与逆时战场）、剧情。
   - 切换做淡入淡出。
   - 本任务不要求占位音乐，槽位为空时静默；切换规则用测试证明。
4. **总线与设置**：音效走 `效果音`、音乐与环境音走 `背景音`，均受设置中的音量控制；暂停时游戏音效停止或暂停，UI 音效照常；场景切换不留残音。
5. **占位音**：为 C 级事件提供程序生成的短占位音，可沿用 `graybox_audio.gd` 的做法；A、B 级事件留槽位，可以静默。现有警示音与命中音迁入新入口，迁入后不重复发声。
6. **文档**：`game/docs/` 新增音频接入说明：事件清单、映射资源格式、文件命名与格式建议、如何替换为正式音频，供用户准备素材。
