# UI-001：正式视觉基础与手写字体接入

状态：已完成（用户授权合并，审查与 G2 + G3 均通过）｜级别：M｜实现：Claude｜审查：Codex
工作区：worktrees/claude｜基线：本任务卡合入后的 master 最新提交（实现者在交付记录中写明完整 SHA）｜依赖：无（可与 SYS-005 并行）

## 目标

完成待办 BL-112，并为 UI-002 及之后的正式界面建立共用的视觉基础：把 EXP-002 样张二的纸墨绘制、色板与“黄昏随末日临近加深”的计算整理为正式模块，接入霞鹜文楷。**本任务不改变任何现有界面的外观**，只提供后续界面使用的基础。

## 依据

- EXP-002 交付记录“G4 用户选定”：样张二（黄昏为主）、保留随天数变化、手写字体、最终战光晕减弱 30%。
- EXP-002 原型 `game/prototypes/EXP-002/`（`style.gd`、`ink.gd`）与其 README 中的色板。
- 待办 BL-112；`game/prototypes/EXP-002/fonts/README.md`（来源、SHA256、OFL 1.1）。

## 要求

1. **样式模块**：在 `game/ui/style/` 下提供正式版的色板（关键色固定）、黄昏程度计算、纸签面板、手绘线条与光晕。黄昏程度改为从真实计时数据计算（第几日与日内进度、是否最终战；数据接口由 SYS-005 提供，本任务先以可注入的参数形式实现，不依赖 SYS-005 合入）。只保留样张二一种样式，不再保留样张切换。
2. **最终战光晕**：最终战时光晕强度为同等黄昏程度下的 70%（用户 G4）。
3. **字体**：把 `LXGWWenKai-Regular.ttf` 放到 `game/assets/fonts/`（与原型中的同一文件，SHA256 一致）；下载并附上 OFL 授权文本（用户 2026-10-21 已同意下载 OFL.txt），在说明中记录来源与哈希。原型目录中的字体文件保留不动（原型仍可运行）。
4. **字体裁剪（可选，需另行同意）**：当前环境没有 fontTools；裁剪需要安装 fontTools（从 PyPI 下载）。默认不裁剪，V0.1 先用完整字体；若用户另行同意安装，再按游戏实际用字裁剪，并保留可重复的裁剪脚本与字符清单。
5. **主题**：提供一个 Godot 主题资源（字体、字号层级、墨迹按钮的常态/悬停/选中/按下/不可用样式），供 UI-002、UI-003 使用；**本任务不把它设为项目默认主题**，现有灰盒界面不变。
