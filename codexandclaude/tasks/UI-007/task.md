# UI-007：区域名称与场景交互提示

## 目标

完成待办 BL-045（进入新区域时画面正中动画展示区域名称）与 BL-049（场景交互提示与关键物品高亮，A-019），沿用已选的样张二视觉，直接正式实现。

## 依据

- 待办 BL-045、BL-049；T7-A“场景交互提示”、T7-B 区域名称；T7-C“NPC互动”；裁决 A-019（所有可交互对象，含 NPC，靠近时显示提示，提示在交互点靠玩家一侧，与场景基调反色）。
- EXP-002 样张二、UI-001 样式模块；UI-002 HUD 布局（提示不得遮挡 HUD）。
- SYS-009 提供的交互对象只读查询。

## 现状（起草时核对 master@2183e77）

- 区域名称：进入 Room 时 `TwoRoomSession` 用 `_notify(room.config.display_name)` 写进灰盒说明行，并把“荒地 / ”+ `display_name` 写进 `$Instructions/Title`；没有居中动画。`RoomConfig` 有 `region_id`、`scene_id`、`display_name`（如“无顶深谷 · 起始区”）。
- 交互：E / RB 的交互散在约 17 个会话脚本里（营帐旗帜、开关、珍珠拾取、NPC 7 / 10、Boss 成长补领等），靠近时没有提示，只靠灰盒说明文字写“E / RB 拾取”等；拾取物在 `room_pickups` 组。

## 要求

1. **区域名称**：进入与上一个 Room 不同区域（`scene_id` 改变，含读档进入）时，在画面正中以纸签或墨字动画展示“区域 · 房间”名，约 2～3 秒淡出；同一区域内换房不重复；剧情锁定、对话、暂停时延后或不显示（交付记录写明规则）。不遮挡 HUD、错误提示与对话框。
2. **交互提示**：玩家进入 SYS-009 报告的可交互范围时，在交互点靠玩家一侧显示提示（按键 E / RB 的图示 + 动作名，如“拾取”“交谈”“开启”），颜色与所在场景基调反色（A-019）；离开范围、对象不可用、剧情 / 对话 / 暂停时隐藏；多个对象同时可用时只显示最近的一个。
3. **关键物品高亮**：SYS-009 标为关键的拾取物（如珍珠）在地图上高亮闪烁，拾取后消失；不改变拾取判定与范围。
4. 键盘与手柄的按键图示随最近使用的设备切换（如现有代码无可用的设备信号，以键盘 E / 手柄 RB 并列显示，交付记录说明）。
5. 文字使用 UI-001 主题字体；关键色不变。
