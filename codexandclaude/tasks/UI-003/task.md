## 目标

完成待办 BL-046（暂停菜单）与 BL-052（存档反馈）：用用户选定的方案（交互：EXP-001 方案四；视觉：EXP-002 样张二）替换现在的灰盒暂停面板。

## 依据

- EXP-001 交付记录“方案四”（暂停菜单：左侧选项，右侧默认时钟，二级界面盖住时钟）；EXP-002 交付记录（样张二与暂停页样张）。
- 待办 BL-046、BL-052；T7-A“暂停菜单”、T7-D（暂停布局、继续、设置、返回主菜单、退出确认、菜单输入、操作说明）、T7-E1“保存反馈”；T7 核对表 T7-A、T7-D 各行。

- UI-001 的样式模块与主题；UI-002 的 `FormalHud` 与 SYS-005 `ui_time_state()`。

## 要求

1. **布局**：部分覆盖；左侧纵向选项：继续游戏、设置、存档槽（暂留）、保存并退出。右侧默认是时钟：表盘与时刻、第N日与末日倒数、三天进度、距下一日（最终战时显示最终战剩余），下方一行当前任务（会话已有 `quest_status_text()` 时显示，没有时不显示）。
2. **二级界面**：选择“设置”或“保存并退出”时，二级界面盖住右侧时钟；返回或 Esc 回到时钟。设置页先沿用现有三项（音量、窗口尺寸、全屏），换成正式样式；新设置项（分开音量、帧率、按键列表、保存设置）在第五批接 SYS-007。
3. **保存并退出**：需确认；确认后保存当前进度并退出游戏（下次从最近检查点继续，规则不变）；保存失败沿用现有错误提示，不退出。
4. **输入**：方向键 / 手柄十字键移动焦点，Enter / Space / 手柄 A 确认（冻结键位表），鼠标悬停与点击；焦点用 UI-001 主题约定的墨线下划线与标记。Esc / 手柄 Back 打开与关闭，二级界面中先返回上一级。
5. **保存反馈（BL-052）**：检查点或手动保存成功时，在不遮挡 HUD 的位置短暂显示“已保存”纸签；失败仍走现有错误提示。
6. **不变的部分**：死亡菜单、存档槽界面、最终战超时与结束面板维持灰盒（第五批）；`LifeUI` 现有公开方法（`show_pause`、`resume_game`、`show_settings`、`show_slots`、`confirm_quit`、`save_failed` 等）的行为与调用方式不变；暂停时计时与进度照常停止。
7. **T7 同步**：在 T7 核对表把 T7-A“暂停菜单”的“右侧显示当前任务”改记为方案四（右侧时钟，下方一行当前任务），注明用户选定日期与来源；T7 原件不改。
