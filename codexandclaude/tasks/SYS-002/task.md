## 目标

在五场强制战斗中实现“残存可能性实体”保底：玩家可能性不足时，周期性生成无伤害的空中无色实体，击杀后获得可能性，保证玩家不会因资源耗尽而在强制战斗中被困死。

## 依据

- T3 §11 残存可能性实体规则表（DOC-003 写入），待决事项总表 A-002（用户 2026-10-19 裁决）：

| 设计项 | 规则 |
| --- | --- |
| 适用战斗 | 营帐围攻、渴望俯视与寄生同伴者两场Boss战、中心战场救场与最终战；不含堑壕 |
| 触发条件 | 当前可能性余额低于当前可能性上限的50%（含负数） |
| 生成节奏 | 满足触发条件时，每10-15秒生成1-2个 |
| 存活上限 | 场上同时最多3只 |
| 击杀奖励 | 与普通无色实体相同，+2可能性 |

- T3 §11：无伤害的空中无色实体；不扩大为随处刷新或无限刷资源的系统。

## 灰盒初值（2026-10-19 用户批准任务卡时确认：按本卡执行）

T3 §11 规定以下三项“由灰盒确定”。为了让实现有据可依，本任务先采用下列初值，均做成可调参数：

| 项目 | 灰盒初值 |
| --- | --- |
| 生成位置 | 玩家上方 160～240 像素、水平随机偏移 ±240 像素，限制在当前战斗区域边界内，不生成在实体碰撞内 |
| 每次生成数量 | 随机 1 或 2 个，但不超过“3 − 当前在场数” |
| 余额回到50%以上 | 停止新的生成计时；已在场的实体保留，直到被击杀或战斗结束 |

另外几项 T3 没有写、但实现必须确定的行为，本任务按下列方式处理，同样请用户确认：

| 项目 | 处理方式 |
| --- | --- |
| 计时起点 | 条件成立时开始计时，经过 10～15 秒（每次随机）后生成；条件不成立时计时重置 |
| 暂停与剧情 | 暂停、剧情、死亡菜单期间计时冻结 |
| 生命值 | 13，与第1日普通无色实体相同，不随日期变化 |
| 行为 | 不攻击、不造成接触伤害、不占用进攻名额；在空中缓慢漂移，可被所有玩家攻击命中 |
| 战斗结算 | 不计入任何波次或胜利条件，不阻止战斗结束；战斗结束、玩家死亡、胜利或离开时无奖励清除 |
| 与现有召唤物 | 与寄生同伴者的飞行支援、渴望俯视的无色召唤分开计数、互不影响 |

## 接口与影响

- 新组件需要读取玩家当前可能性余额与当前上限；只读，不改变资源结算规则。
- 涉及五个 Room/战斗的运行逻辑；每处接入都不得改变原有波次、胜负、奖励、检查点、存档与计时规则。
- 不新增存档字段：保底实体不保存，死亡、读档、重进按战斗重置。

## 完成标准

1. 五场强制战斗中，余额低于上限50%时按规则生成，余额不低于50%时不生成新的；堑壕及其他非强制战斗不生成。
2. 同时在场不超过3只；每次生成1～2只且不超过剩余名额；生成间隔在10～15秒之间。
3. 击杀奖励+2，受当前上限截断；每个实体只结算一次；负余额时可正常偿还。
4. 保底实体不伤害玩家、不占进攻名额、不阻止波次或战斗结束；战斗结束、死亡、胜利、离开时无奖励清除。
5. 暂停、剧情、死亡菜单期间计时冻结。
6. 现有战斗相关测试全部通过，证明原有规则未被改变。
