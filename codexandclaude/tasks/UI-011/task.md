## 目标

游戏镜头改为 ×1.875、站立脚底在画面 88% 后，HUD 的时间轴（太阳横线、时刻标签与日期标签）仍画在画面底边，正好压在玩家脚下仅剩的 12% 画面上，挡住视野。把它挪到画面顶部。

## 依据

- 用户 2026-10-31（SYS-013 实机验收时）：“时间轴有些碍事，会挡视野，考虑挪个位置，挪到顶上去吧？”

- 待办 BL-127 的 HUD 部分；UI 整体将由美术重新设计（BL-130），本任务只是过渡调整，不改风格。

- `codexandclaude/tasks/UI-011/`、`codexandclaude/BOARD.md`（登记本任务）。

## 完成标准

1. 时间轴画在顶部：从徽章及其标签右侧（x = 470）起到右边缘，日期标签收在线的右端之外，时刻标签挂在线下方；整条带子的底边在敌人介绍卡（顶边 100）之上，不与徽章相交。
2. 太阳走到一天末尾也不会钻到日期标签下面。
3. 最终战倒计时框下移到时间轴下方，底边不超过新一日横幅的顶边（190），两者不相交。
4. 其余避让时间轴的界面（交互提示、任务条、对话、敌人介绍卡、中心提示、战场横幅）沿用 HUD 发布的矩形，不需要改代码；对应测试全部通过。
