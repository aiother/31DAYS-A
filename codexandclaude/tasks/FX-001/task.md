## 目标

完成待办 BL-065 的战斗反馈部分：把用户在 EXP-005 定稿的风格 D · 融合做成正式游戏特效，挂在 SYS-010 的动画状态与现有信号上，替换玩家灰盒外观中对应的临时反馈（奖励光圈、闪避与恢复着色等）。同时落实定稿的顿帧与屏幕震动规则。

## 依据

- 待办 BL-065；T6-D1（视觉特效清单）；T2 §14（战斗反馈）。
- [EXP-005 交付记录](../EXP-005/delivery.md)的“用户定稿”与“给正式实现的说明”：
  - 风格 D：攻击轨迹与命中用墨迹飞溅，下衬暖光与命中暖光闪；其余特效用光痕。
  - 普通攻击命中顿帧 0.10 秒，表现为“刀被卡住”：轨迹停在砍中处，玩家与目标一起停住，目标原地抖动，结束后刀光扫完；未命中不卡。
  - 普通命中不震屏；受击轻震 5 像素。
- 原型代码 `game/prototypes/EXP-005/effects.gd`（四套风格的画法与记录型绘制辅助）、`preview.gd`（顿帧与震动的实现参考）。原型只读参考，正式代码不引用原型目录。
- SYS-010 动画接入说明 `game/docs/character_animation.md`；现有信号：`PlayerCombat.attack_started` / `hit_confirmed`、`PlayerPossibility.gained` / `balance_changed` / `shortfall`、`PlayerLife.damaged` / `respawned`、`ColorlessEntity.attack_started` / `defeated`。

## 现状（起草时核对 master@f6de02f）

- `game/player/placeholder_visual.gd`：可能性增加时画绿色扩散圈（`_reward_flash`），受击变红，无敌闪烁，闪避与恢复整体着色，攻击判定框半透明矩形，命中音 `_hit_sound`。
- 敌人 `*_visual.gd`：攻击前摇灰盒警示；没有命中、击倒特效。
- 没有顿帧与屏幕震动。
- 已知灰盒缺陷（SYS-010 G4 观察）：余额被直接赋值时，`_last_balance` 不更新，之后第一次减少会误触发获得光圈。正式实现改为只响应 `gained` 一类的明确事件。

## 要求

1. **特效清单**（风格 D，按 EXP-005 定稿画法）：
   - 攻击轨迹：三方向、两段连击，跑攻与普通攻击同一画法。
   - 命中：墨迹飞溅加暖光闪；击退、向上攻击、下攻击弹起各自可辨认。
   - 投射物弹反：弹反瞬间的光痕。
   - 闪避：可能性充足与不足（`poor_dodge`）两种外观，加无敌期间的表现。
   - 可能性：获得（含来源位置）、消耗、不足提示。不足提示与 HUD 已有的发红（A-018）不冲突，不重复画同一信息。
   - 恢复：循环中与完成两种；中断时收起。
   - 玩家受击、敌人受击、敌人击倒、玩家复活。
2. **顿帧**：
   - 普通攻击命中有效目标时，玩家与被命中的目标同时停住 0.10 秒（时长做成可调配置），刀光停在命中位置，之后接着播完；同一帧命中多个目标只停一次；未命中不停。
   - 停住期间，玩家与目标的动作计时一起冻结，结束后从原处继续，不缩短也不重复任何阶段；其他敌人、友军、投射物照常运行。
   - 日内时钟与最终战计时不受影响，照常走：T4 只规定暂停、剧情与死亡菜单不扣时，顿帧不在其中。
   - 存档与暂停规则不变；暂停菜单打开时顿帧计时冻结。
3. **屏幕震动**：普通命中不震；玩家受击轻震 5 像素。幅度可调，入口集中，供以后的重攻击使用；本任务不加设置开关（EXP-005 说明第 3 条）。
4. **替换灰盒反馈**：去掉 `placeholder_visual.gd` 中被正式特效取代的部分（奖励光圈、闪避与恢复的整体着色、判定框矩形），保留角色占位形象本身与 SYS-010 的动画驱动。受击与无敌的可读性不能下降。
5. **规格同步**：T2 §14 补写顿帧与震动规则（普通攻击命中顿帧 0.10 秒，玩家与命中目标同停，未命中不停，不影响计时；普通命中不震，受击轻震），并在 T2 §16 变更记录加一行，来源写“用户定稿（EXP-005，2026-10-23）”。
6. **文档**：`game/docs/` 新增特效接入说明：特效清单与触发事件、顿帧与震动的配置入口、以后换成美术特效资源的方法。

## 完成标准

1. 自动测试使用真实玩家与敌人场景、真实输入和真实物理帧，覆盖以下几组：
   - **触发**：每种特效由真实动作触发，记录取自实际绘制，不由外层补齐，沿用 EXP-005 审查 R1 的做法；按真实轨迹判断攻击方向；有限特效在上限帧数内结束且不留残余。
   - **顿帧**：命中才停，停 0.10 秒；多目标只停一次；玩家与目标的阶段计时冻结且不缩短；其他敌人照常走；日内时钟与最终战计时照常走；暂停冻结顿帧。
   - **震动**：普通命中不震，受击震 5 像素。
   - **获得光圈**：余额被直接赋值后再闪避，不出现获得光圈，即 SYS-010 G4 的观察不再出现。
2. 现有全部测试通过，旧断言不改；若必须改，交付记录逐条说明。玩法相关套件（玩家、战斗、三类敌人、Boss、战役）结果不变。
3. 变异检查，以下每项都要有测试失败：未命中也顿帧、多目标停多次、顿帧期间时钟停走、顿帧期间其他敌人也停、普通命中也震屏、余额直接赋值后误放获得光圈。
4. 性能：特效全开的实机帧时间不明显上升，交付记录写明测量条件。
5. G2 + G3 通过；G4（用户）：用验收入口实机试玩，确认手感与 EXP-005 定稿一致。
