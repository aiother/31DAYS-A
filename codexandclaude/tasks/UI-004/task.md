# UI-004：正式主界面与存档选择

状态：已批准（2026-10-21 用户批准）｜级别：L｜实现：Claude｜审查：Codex
工作区：worktrees/claude｜基线：SYS-008 与 UI-003 合入后的 master 最新提交（实现者在交付记录中写明完整 SHA）｜依赖：SYS-008（流程与摘要）、UI-003（墨线按钮与暂停菜单）

## 目标

完成待办 BL-040（主界面）与 BL-041（存档选择）：按用户在 EXP-003 选定的方案，替换现在启动时的灰盒选槽界面。

## 依据

- 用户 2026-10-21 选定（EXP-003 交付记录“G4 用户选定”）：主界面 **A · 黄昏远景**；存档选择 **1 · 书签**，每张书签上部加入 **2 的天空条**。沿用推荐流程：有存档时默认焦点在“继续游戏”，新游戏在选槽后确认。
- 原型 `game/prototypes/EXP-003/`（`title_dusk.gd`、`slots_bookmark.gd`、`slots_cards.gd` 的天空条）。
- 待办 BL-040、BL-041；T7-A、T7-E1、T7-F；裁决 A-013；SYS-004 审查建议（已通关槽直接做成已通关样式）。
- SYS-008 的 `show_title()` 请求、`has_any_save()`、`slot_summaries()`；UI-001 样式模块；UI-003 的 `InkButton`。

## 要求

1. **主界面**（方案 A）：黄昏天空、低垂的太阳与光晕、两层残破城市剪影、飘尘；标题“末日前31天”在中上方、约占画面 1/3；菜单为新游戏、继续游戏（`has_any_save()` 为假时不显示）、设置、退出游戏；有存档时默认焦点在“继续游戏”；退出需确认。“设置”打开现有设置页（UI-006 合入前沿用 UI-003 暂停菜单里的三项设置）。
2. **存档选择**（书签 + 天空条）：三条竖长书签并排、选中的升起；每张书签上部是该槽当日的天空与太阳位置（取自摘要的第几日与当日进度），下面是标题、第几日与末日倒数、游戏时长、生命碎片、可能性与上限、珍珠、最后检查点；已通关的书签盖朱红“已通关”印；空槽与无法读取的槽有各自样式。左右键 / 十字键 / 鼠标选择，Enter / A 确认，Esc / Back 返回主界面。
3. **继续游戏**：进行中的槽进入游戏（经 `start_slot`）；已通关的槽提示“游戏已通关”并停留（A-013）；空槽、无法读取的槽说明原因。
4. **新游戏**：选空槽确认开始；选有进度或无法读取的槽提示“将覆盖此槽现有进度”；确认框默认焦点在“返回”。
5. 存档写入失败等错误提示沿用现有 `save_failed()`，不被主界面或书签遮挡。
6. 文字使用 UI-001 主题中的霞鹜文楷；关键色不随槽的日期变化（只有天空条与纸色随日期变化）。
