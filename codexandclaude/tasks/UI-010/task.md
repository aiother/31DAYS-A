完成待办 BL-044：进行中的任务目标与完成状态显示在左侧中部偏上；任务开始、进展、完成、放弃、过期以及“获得××”时在画面中央做短暂的动画提示；暂停菜单可查看（已由 UI-003 提供，保持一致）。完成后 M2-c 收尾。

## 现状（起草时核对 master@6591165）

- 左侧任务：`FieldDialogue.quest`（灰盒 Label，(64, 490)）由各会话每帧写 `quest_status_text()`；暂停菜单右侧在时钟下显示“当前任务”（UI-003，读 `quest_status_text`）。
- 中央提示：`FieldDialogue.show_notice(text)` 灰盒 Label 3 秒淡出，用于救助完成 / 放弃、7 的注视获得、沟壑换日等；拾取与成长的获得只写灰盒说明行。
- SYS-009 已提供结构化状态与信号，尚无界面使用。

## 要求

1. **左侧任务纸签**：`quest_state().state` 为进行中时，在左侧中部偏上（HUD 操作提示之下、不压错误提示）显示“救助”标题与当前目标一句；已完成 / 已放弃 / 已过期时显示状态并在约 6 秒后收起；无任务时不显示。读档或换房后先读 `quest_state()`，之后随 `quest_changed` 更新。对话、剧情、暂停时隐藏。
2. **中央提示**：`quest_changed` 的开始、进展、完成、放弃、过期，以及 `item_obtained` 的珍珠、拾取、药包、成长，各在画面中央偏上出现一条纸签（标题 + 一句，如“救助完成”“获得 · 珍珠”），约 2.5 秒淡出；多条依次排队、不重叠；同一事件不重复。颜色：完成 / 获得用成长金，放弃 / 过期用朱红，其余用墨色。
3. **接管灰盒**：`FieldDialogue.quest` 与 `show_notice()` 改由本任务的正式节点显示（保持方法可调用，灰盒 Label 不再出现）；`show_notice()` 的文字作为中央提示的一条（与信号同一事件只显示一次，交付记录写明去重规则）。
4. **避让**：中央提示与左侧纸签不压 HUD（含地平线）、对话框、区域名称、交互提示、介绍卡与横幅、可见的保存失败提示；放不下时排队等待或让位，不覆盖（UI-007 审查 R1 的做法）。
5. 暂停菜单中的“当前任务”保持现有显示，文字与左侧纸签同源。
