## 目标

完成待办 BL-047：用 SYS-007 的设置接口，把暂停菜单（以及 UI-004 合入后的主界面）里的设置页做成完整的正式设置界面。

## 依据

- 裁决 A-017（设置项两表合并：总音量、效果音、背景音分开，分辨率，全屏 / 窗口，帧率，按键列表；自定义按键推迟到 V0.1 之后）；T7-D“设置”“操作说明”；T1 §7 冻结键位表。
- 用户 2026-10-21 决定：设置保存到单独文件（SYS-007）。
- EXP-002 暂停页样张中的设置页排版；UI-003 的暂停菜单二级页。

## 要求

1. 设置页项目：总音量、效果音、背景音（三条滑条）；分辨率（1280×720 / 1920×1080）；全屏 / 窗口；帧率上限（30 / 60 / 120 / 不限制）；按键列表（只读，按冻结键位表顺序显示键盘与手柄键位，标注“自定义按键将在后续版本提供”）；恢复默认（需确认）。
2. 所有项都经 SYS-007 接口读写，改动立即生效并保存；界面不直接读写文件或总线。
3. 暂停菜单与主界面（UI-004 合入后）打开的是同一个设置页；从哪里打开就返回哪里。
4. 方向键 / 十字键在各项间移动，左右键调整滑条与选项，Enter / A 切换开关，Esc / Back 返回；鼠标可直接操作。
5. 按键列表较长时可滚动，不超出纸面。
