## 标准三视图

![初页标准三视图](player_a_turnaround_v1.png)

这张图用于看清结构，因此用清楚的轮廓替代大面积光晕；柔光在后续视觉层独立添加。初态服装、皮肤、头发与饰扣均保持白色，浅灰五官不作为新的角色身份色。

层序数字越大越靠前，是常态站立的制作建议；攻击时手臂跨过披衣前方，可按动作调整前后层。近远肢体分开绘制，纯白设定下仅通过中性灰明度与遮挡区分，沿用同一套白色材质。

部件格中的大小服务于结构展示，实际装配比例以三视图为准；尤其菱形扣、发束等小件不能按格子大小直接拼接。本张为带编号的拆分设定图，关节余量是后续独立素材的制作要求，并非已装配的骨骼资产。

头部、前后发与翻起发束分别处理，便于眨眼、转头和轻微发束滞后；披衣后片与两片前片分开，便于跑跳时抬起、收拢。领口与菱形扣独立，避免披衣变形把饰扣一起拉长。腕部留有武器挂点的骨骼约定，本次不新增武器设计。

## 染色与发光

- 初始绘图统一为白色。轮廓柔光作为独立效果叠加，保留清楚的身体边界。
- 同伴带来的颜色优先落在披衣的独立前片与局部衣角，后续可使用独立颜色遮罩，维持面部与胸前留白。
- 素材规划不预先绑定同伴的颜色、剧情顺序或新玩法。光晕与染色遮罩是后续制作层，不混入关节接合区。
